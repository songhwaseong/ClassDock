# 만능파일교실

**여러 형식의 파일을 한곳에서** 열어 보고 다루는 올인원 오프라인 도구입니다. PDF에 **서명·텍스트·날짜·체크**를 올려 저장하고, **Word·Excel·PowerPoint·이미지·HWP는 미리보기**로 열며, **코드 보기와 파이썬 실행**, 어떤 열린 문서든 참고 화면으로 고정해 작업 문서와 나란히 두고 필요할 때만 잠그는 **분할 작업**까지 지원합니다.
**여러 파일을 동시에 열어** 왼쪽 사이드바에서 전환할 수 있습니다.
파일은 외부 서비스로 업로드되지 않습니다. HTML 버전은 브라우저 안에서 처리하고, EXE 버전은 내 PC의 `127.0.0.1` 로컬 서버·Python·PowerPoint만 선택적으로 사용합니다. Pyodide 런타임·패키지를 처음 받을 때는 프로그램 파일만 CDN에서 내려받으며 사용자의 문서와 코드는 전송하지 않습니다.

## 실행 방법 (3가지 중 택1)

| 방법 | 파일 | 설명 |
|------|------|------|
| **앱 실행파일** | `manneung-classroom.exe` | 더블클릭 → 콘솔창 없이 로컬 서버가 뜨고 브라우저가 자동으로 열림. 자동 복원·로컬 Python·정확한 PPT 변환 같은 **로컬 연동 기능 지원** |
| **오프라인 HTML** | `manneung-classroom-offline.html` | 더블클릭 → 브라우저에서 바로 열림. 문서 뷰어 라이브러리가 내장되어 **일반 열기·편집은 인터넷 불필요** |
| **온라인 HTML** | `manneung-classroom.html` | 가장 가벼운 원본. 라이브러리를 CDN에서 받으므로 **첫 실행 시 인터넷 필요.** |

> PDF·Office·이미지 보기와 브라우저 안 편집을 간단히 공유하려면 `manneung-classroom-offline.html` 한 파일이 편합니다. 자동 복원, 로컬 Python 대화형 실행, pip, Python·Excel의 권한 팝업 없는 로컬 저장, 설치된 PowerPoint를 이용한 정확 변환이 필요하면 EXE를 사용하세요.
> 오프라인 HTML도 Pyodide로 Python을 처음 실행하거나 새 패키지를 불러올 때는 인터넷이 필요합니다. EXE는 설치된 로컬 Python을 우선 사용하며, Python이 없을 때 오프라인 Pyodide를 쓰려면 EXE 옆 `vendor/pyodide/` 코어 파일이 필요합니다.
> EXE는 서명되지 않은 빌드라 Windows SmartScreen 경고가 뜰 수 있습니다(실행 시 “추가 정보 → 실행”).

> **⚠ 꼭 알아두세요 — 폴더 저장 방식:** 원본 `.py`에 바로 저장하려면 **열기 → 폴더 열기** 또는 `Ctrl+Shift+O`로 폴더를 열고 쓰기 권한을 허용하세요. 폴더를 화면으로 **드래그**하면 브라우저 보안상 원본 쓰기 권한이 없어, EXE는 **설정 → 일반 → 자동 저장 폴더**에 편집본을 저장하고 일반 HTML은 별도 파일/다운로드 사본으로 저장합니다. 이 경우 원본은 변경되지 않으며 앱이 실제 저장 위치를 안내합니다.

### Windows 작업 표시줄에 고정

`manneung-classroom.exe`를 자주 실행한다면 사용자가 직접 작업 표시줄에 고정할 수 있습니다.

1. 파일 탐색기에서 `manneung-classroom.exe`가 있는 폴더를 엽니다.
2. 파일을 마우스 오른쪽 버튼으로 클릭합니다.
3. Windows 11에서는 **더 많은 옵션 표시**를 누른 뒤 **작업 표시줄에 고정**을 선택합니다. Windows 10에서는 해당 메뉴를 바로 선택합니다.
4. 이후 작업 표시줄의 아이콘을 누르면 앱이 실행되고 브라우저가 열립니다.

> Windows 정책상 앱이 스스로 작업 표시줄에 강제 고정할 수는 없으므로 이 과정은 사용자가 직접 해야 합니다. 실행 파일을 다른 위치로 옮기거나 삭제하면 고정된 아이콘이 동작하지 않을 수 있습니다.
> 아래의 **즐겨찾기로 항상 켜두기**를 사용하는 중에는 작업 표시줄의 exe를 다시 실행하지 마세요. 이미 실행 중인 서버와 중복될 수 있으므로, 상시 실행 방식에서는 브라우저 즐겨찾기 사용을 권장합니다.

### 즐겨찾기로 항상 켜두기 (exe를 매번 안 눌러도 됨)

매번 `manneung-classroom.exe`를 누르기 번거로우면, 로컬 서버를 **고정 포트(17645)** 로 백그라운드에 띄워두고 **브라우저 즐겨찾기**로 바로 접속할 수 있습니다(exe 기능 전부 그대로).

1. `desktop/start-server-hidden.vbs` 실행 — 콘솔창 없이 서버가 뜹니다(브라우저는 자동으로 안 열림).
2. 브라우저에서 **`http://127.0.0.1:17645/`** 를 즐겨찾기(`Ctrl`+`D`). 이후엔 즐겨찾기 클릭만으로 바로 열립니다.
3. 그 스크립트를 **시작프로그램 폴더**(`Win`+`R` → `shell:startup`)에 복사해 두면 **로그인 시 자동으로** 서버가 떠 즐겨찾기가 항상 동작합니다.
4. 끄려면 `desktop/stop-server.cmd` 실행(또는 작업관리자에서 `manneung-classroom.exe` 종료).

> 백그라운드 서버가 17645를 쓰는 동안엔 **exe를 직접 더블클릭하지 말고 즐겨찾기**를 쓰세요(직접 누르면 중복 인스턴스가 뜸). 17645가 다른 프로그램에 점유돼 있으면 **랜덤이 아니라 고정 후보 목록(18645 → 19645 → 27645 → 37645 → 47645)** 으로 결정적으로 폴백하고 그 포트를 기억해, 같은 PC에서는 재실행 때마다 같은 포트를 재사용합니다(브라우저 설정·탭 순서가 origin별로 유지됨). 이때는 즐겨찾기 주소도 실제로 뜬 포트로 다시 저장하세요.

## 2026-07-17 업데이트

- **오프라인 한국어 맞춤법 검사**: 메모 글·이미지 설명, TXT·Markdown 편집기, 노트북 마크다운 셀에서 **맞춤법** 버튼을 누르면 외부 서버로 글을 보내지 않고 자주 틀리는 표현과 기본 띄어쓰기를 검사합니다. 오류별 설명과 교정 후보, 이전·다음 이동, 이번만 무시, 사용자 사전 추가·초기화를 지원합니다. 긴 문서는 선택 영역 또는 현재 위치 주변만 검사해 편집이 멈추지 않게 하며 한글 조합 중에는 재검사하지 않습니다.
- **코드 속 한국어 검사**: Python·JavaScript 등 코드 파일에서는 실행 코드와 변수명을 건드리지 않고 **주석과 문자열 안의 한국어만** 검사합니다. Markdown의 코드 펜스와 인라인 코드도 검사에서 제외합니다.

- **Excel 편집기 확장**: 수식 자동완성·자동합계·채우기 핸들, 글꼴/색/정렬/테두리/표시 형식, 병합, 목록 드롭다운, 조건부 서식, 시트 추가·복제·이름 변경·순서 변경, 차트와 미니 피벗을 추가했습니다. 선택 범위는 이미지로 만들어 메모에 보낼 수 있습니다.

- **픽셀 펫과 집중 모드**: 설정에서 작은 픽셀 펫(1~12마리)을 켜고 붙잡아 던질 수 있습니다. 대사와 나만의 펫을 만들 수 있으며, 집중·휴식 타이머는 앱을 다시 열어도 이어집니다. 라이트 모드에는 쿨 그레이·웜·민트·라벤더·스카이 배경 프리셋을 제공합니다.

- **메모 창 닫힘 보정**: 메모는 `Esc`, 메모 버튼 또는 닫기 버튼으로 닫을 수 있고, 바깥 클릭·`Ctrl+W`로는 닫히지 않습니다. 복사·붙여넣기 중 실수로 닫히는 일을 막았습니다.

- **임시 메모**: 헤더의 **메모** 버튼 또는 `Ctrl+M`으로 탭 메모를 열고 닫을 수 있습니다. 글과 이미지를 블록으로 함께 배치하며 입력 내용과 이미지가 이 컴퓨터에 자동 저장됩니다.

## 사용법

> **여러 파일 동시 열기** — 왼쪽 **사이드바**가 열린 파일 목록입니다. 클릭으로 전환하고 닫기 버튼으로 닫을 수 있습니다. 하단 **열기** 버튼에서 **파일 추가** 또는 **폴더 열기**를 선택해 계속 추가합니다. 상단 툴바는 **선택한 파일에 맞춰 자동 전환**됩니다(PDF=서명·다운로드 / 그 외=인쇄).
> 사이드바 상단의 **칩**에 열린 파일 **총 갯수·총 용량**이 뜨고, 클릭하면 **전체·확장자별 갯수**(.py·.pdf·.png …)가 펼쳐집니다. 현재 필터와 관계없이 메뉴에서 다른 확장자나 전체 파일로 바로 전환할 수 있습니다.
>
> **확장자 색상·탭·포커스** — 사이드바의 확장자 배지·파일명과 상단 파일명이 **종류별 색**으로 표시됩니다(PDF=빨강·PPT=주황·Excel=초록·이미지=보라·파이썬=금색 등). 파일을 2개 이상 열어 전환하면 **헤더 아래 탭**으로 쌓여 빠르게 오갈 수 있습니다. 많은 탭은 활성 탭 주변만 보여주고 나머지는 **`+N` 검색 메뉴**에 모아 둡니다. 탭은 **좌우로 드래그해 순서를 변경**할 수 있고, **우클릭하면 오른쪽·왼쪽·다른 탭을 한 번에 정리**할 수 있습니다. 닫기 버튼으로 탭만 닫아도 파일은 사이드바에 유지됩니다. 전환할 때 **사이드바가 해당 파일로 스크롤**되며 접힌 폴더는 펼쳐집니다.
>
> **최근 작업공간 자동 복원** — 선택한 파일·ZIP·폴더는 최대 256MB까지 기억됩니다(EXE는 앱 전용 저장소, 일반 브라우저는 **이 브라우저의 IndexedDB**). 더 큰 묶음도 열 수 있지만 메모리 보호를 위해 자동 복원 저장은 생략합니다. 다음 실행 때 자동으로 다시 열리며 **열려 있던 탭의 순서와 활성 탭까지 복원**됩니다. 사이드바 하단 **더보기 → 최근 작업공간 지우기**로 삭제할 수 있습니다. 브라우저 저장분은 같은 브라우저·같은 파일(HTML)로 열 때 복원됩니다.

1. 파일을 화면에 **드래그&드롭**하거나 사이드바 하단 **열기 → 파일 추가/폴더 열기**를 선택 — 한 번에 여러 개도 가능
2. **PDF면 편집 모드:**
   - 서명(그리기 / 이미지 업로드 / 최근 서명 재사용) · 텍스트 · 날짜 · 체크
   - 드래그(이동) · 더블클릭(텍스트 수정) · 모서리(크기) · `Delete`(삭제) · 선택 시 글자 크기/색상
   - **다운로드** → `원본이름_signed.pdf` 저장 (원본은 그대로 둠)
   - **페이지** → 썸네일 이동·다중 선택·추출·삭제·순서 변경·90도 회전
   - **PDF 합치기** → 현재 편집본 뒤에 선택한 PDF들을 이어 붙여 새 파일로 저장

   - 서명은 최근 8개까지 보관되며 현재 페이지·선택 페이지·모든 페이지에 일괄 배치 가능

   - 이미지는 회전·뒤집기·자르기·PNG/JPG/PDF 저장을 지원하며, `되돌리기`/`다시`로 편집을 되돌릴 수 있음
   - Agile 방식으로 암호화된 `.docx`·`.xlsx`·`.pptx`는 **암호 입력창**에서 복호화

### 빠른 작업

- 사이드바의 **파일명·내용 검색**(`Ctrl+F`)은 열린 폴더·압축 안의 파일 이름을 즉시 필터링하고, 텍스트·코드 파일의 내용도 잠시 뒤 자동으로 검색합니다.
- 사이드바의 **새로 만들기**에서 빈 Python 코드·빈 Excel 표·**화이트보드(설명용 칠판)** 를 만들 수 있습니다. 일반 업로드 폴더는 우클릭해 해당 위치에 새 Python 코드를 만들고 폴더 전체를 새로고침할 수 있습니다.
- 폴더의 펼침 화살표를 `Alt+클릭`하면 같은 단계의 형제 폴더를 한 번에 접을 수 있습니다. ZIP 이름 옆 `ⓘ`를 누르면 원본 덮어쓰기·용량·Python 실행 제한을 다시 볼 수 있습니다.
- 기본 단축키는 `Ctrl+O` 파일 열기 · `Ctrl+Shift+O` 폴더 열기 · `Ctrl+S` 현재 PDF/Python 저장 · `Ctrl+W` 현재 파일 닫기 · `Ctrl+M` 메모 · `Ctrl` 두 번 Python 편집기 포커스 · `Alt+←` / `Alt+→` 왼쪽 사이드바 숨기기/보이기 · `Alt+N` 새 파이썬 코드입니다. 주요 단축키는 **설정 → 단축키**에서 변경할 수 있습니다.
- `Ctrl+←` / `Ctrl+→`로 같은 ZIP·폴더 안의 이전·다음 수업 파일로 이동합니다. 확장자 필터 사용 중에는 해당 확장자 파일만 이동하며 Python 편집기 안에서도 동작합니다. 검색창·메모장 등 일반 입력칸에서는 기본 커서 이동을 유지합니다.
- 헤더의 **메모** 버튼으로 텍스트·이미지·노트북 셀 통합 메모를 열고 닫습니다. `Ctrl+M`은 메모를 열고, 메모 편집 중 다시 누르면 닫습니다. 글/이미지/셀 블록과 배치가 자동 저장되며 `Esc`로 닫을 수 있고, 바깥 클릭·`Ctrl+W`로는 닫히지 않습니다.
- PDF 편집은 `Ctrl+Z`로 되돌리고 `Ctrl+Shift+Z` 또는 `Ctrl+Y`로 다시 실행할 수 있습니다(최대 50단계).
- 설정의 **화면 글자 크기**는 앱 전체 UI를 즉시 확대합니다. **메모리 절약**은 현재 페이지는 고화질로 유지하고 주변 페이지만 낮은 해상도로 미리 렌더하며, **최고 화질**은 넓은 범위를 3배 품질로 유지합니다.
- 페이지 삭제·이동·회전도 같은 Undo/Redo 기록에 포함되며 회전은 화면에 즉시 반영됩니다.
- 이미 열린 파일을 다시 추가하면 중복 탭 대신 기존 파일로 이동합니다. 상단 `?`에서 전체 단축키를 확인할 수 있습니다.
- PDF에 배치한 서명·텍스트·날짜·체크는 자동 저장되며, 같은 PDF를 다시 열면 복원 여부를 묻습니다.

### PDF 교재로 Python 공부하기

1. 교재 PDF를 연 뒤 상단 **학습 화면**을 누릅니다.
2. 왼쪽 사이드바에서 실습 `.py` 파일을 선택하면 PDF와 코드 편집기가 나란히 표시됩니다.
3. EXE에서 실행하면 결과 창에 `input()`의 안내 문구와 입력 커서가 나타납니다. 값을 입력하고 Enter를 누르면 다음 `input()`까지 계속 실행됩니다.
4. 브라우저 Pyodide 실행에서는 코드가 `input()`을 쓸 때만 뜨는 **input() 입력** 칸에 값을 호출 순서대로 한 줄씩 미리 적습니다.
5. 출력·Matplotlib 그래프·**실행이 만든 파일**(저장/열기)을 확인하고, **.py 저장**으로 편집본을 저장합니다(EXE는 `내 문서\만능교실 저장` 폴더에 권한 팝업 없이 바로 저장하고 경로를 편집기 위에 표시, 그 외 환경은 다운로드). 코드를 망쳤으면 **원본** 버튼으로 처음 코드로 되돌릴 수 있어요.

> `numpy`·`pandas`·`matplotlib` 같은 Pyodide 공식 패키지는 브라우저 실행에서도 자동으로 받아옵니다. 그 밖의 순수 Python 패키지는 PyPI에서 자동 설치를 시도하며, **Faker는 EXE에 wheel을 내장해 오프라인에서도 바로 실행**됩니다. 바이너리 확장이 필요한 미지원 패키지는 일반 `.py`의 로컬 Python 실행을 안내합니다.
>
> **에디터 편의** — **현재(커서) 줄 배경 강조**와 들여쓰기 가이드, Enter 시 **자동 들여쓰기**(`:` 다음 한 단계 추가), **A− / A+**(또는 `Ctrl` `+`/`−`)로 **코드와 결과 문자 크기** 조절, 설치된 고정폭 **코드 글꼴 선택**을 지원합니다. 선택한 단어는 `F3` / `Shift+F3`으로 다음·이전 위치로 이동하고, 함수 이름은 `Ctrl`을 누른 채 올리면 밑줄로 표시되며 `Ctrl+클릭`으로 정의로 이동합니다. 파일을 안 열어도 사이드바의 **새 파이썬 코드** 버튼(또는 시작 화면의 **새 파이썬 코드로 시작**)으로 빈 코드를 바로 작성·실행할 수 있어요.
>
> **자동완성** — 문자를 입력·삭제·붙여넣기만 해도 Python 키워드·내장 함수와 현재 파일의 변수·함수·클래스 이름을 제안합니다. `Ctrl+Space`로 전체 후보를 직접 열 수도 있고 `↑`/`↓`로 선택한 뒤 `Enter` 또는 `Tab`으로 적용하며, `Esc`로 닫습니다. 자동으로 붙은 따옴표·괄호 앞에서는 `Tab`이 공백을 만들지 않고 닫는 문자 밖으로 이동합니다. `파일변수 = open(...)` 뒤에서 Enter를 누르면 작업 줄과 `파일변수.close()`를 함께 만들며, `with open(...)`은 제외합니다.
>
> **열(블록) 동시 편집** — `Alt`를 누른 채 마우스로 **세로로 쭉 드래그**하면 여러 줄의 같은 열에 커서가 생깁니다. 그 상태로 입력하면 **모든 줄에 동시에 삽입**되고, 폭을 잡아 드래그했다면 그 범위를 **한 번에 교체**합니다(`Backspace`·`Delete`도 동시 적용). `Esc`·일반 클릭·화살표로 종료. (고정폭 글꼴 기준이라 들여쓰기는 공백으로 맞춰야 정렬됩니다. 한글 IME 입력은 이 모드에서 제외.)
>
> **되돌리기/다시실행** — 코드 편집기는 자체 히스토리를 써서 일반 타이핑은 물론 **열 편집·`Tab`·자동 들여쓰기까지** `Ctrl+Z`로 되돌리고 `Ctrl+Shift+Z`(또는 `Ctrl+Y`)로 다시 실행합니다(연속 입력은 한 단계로 묶음, 최대 300단계).

## 다시 빌드하려면

소스(`manneung-classroom.html`, `src/`)를 수정한 뒤:

```bat
npm run verify                 :: 1) 구문 검사 + 자동 테스트 + 오프라인 HTML 재생성
cmd /c desktop\build.bat       :: 2) exe 재생성 (Windows .NET Framework C# 우선)
```

- 빠르게 테스트만 실행하려면 `npm test`, 오프라인 HTML만 만들려면 `npm run build`를 사용합니다.
- 오프라인 빌드는 `vendor/`의 문서·편집 라이브러리를 HTML에 인라인합니다. 용량이 큰 Pyodide 코어는 인라인하지 않습니다.
- `src/styles.css`와 `src/js/*.js`도 빌드 시 인라인되므로 배포물은 이전처럼 단일 HTML입니다.
- exe 빌드는 `manneung-classroom-offline.html`을 `desktop/app.html`로 복사해 바이너리에 내장합니다.
- `desktop/build.bat`은 Windows 기본 C# 컴파일러가 있으면 모든 로컬 백엔드가 포함된 EXE를 만듭니다. C#이 없을 때의 Go 폴백은 정적 HTML 서버만 제공하므로 자동 복원·로컬 Python·PPT 정확 변환 같은 C# 백엔드 기능이 없습니다.
- 즐겨찾기 상시구동(고정 포트)을 쓰는 중이면, 재빌드 후 `desktop/stop-server.cmd` → `desktop/start-server-hidden.vbs`로 서버를 재시작해야 새 버전이 반영됩니다.

## 알아두실 점 / 한계

- **지원 브라우저(최소 지원선)**: **Chrome/Edge/Whale 등 크로뮴 계열 106 이상, Firefox 110 이상(127 이상 권장), Safari 16.4 이상**에서 동작합니다(컨테이너 쿼리·Pyodide 등 사용 기술 기준). Internet Explorer와 그 이전 버전 브라우저는 지원하지 않습니다. 크로뮴 계열이 모든 기능을 지원하며, Firefox·Safari는 파일 시스템 접근 API(File System Access)가 없어 **원본 파일 덮어쓰기 저장이 다운로드(또는 EXE 저장 폴더)로 대체**되고, 폴더 열기에서 빈 하위 폴더가 표시되지 않으며, 스크롤바 모양 등 일부 표시가 다를 수 있습니다. Firefox 126 이하에서는 PPTX 근사 미리보기 배율이, 124 이하에서는 대용량 코드·이미지 격자 스크롤 성능이 떨어질 수 있습니다.
- **Word·PowerPoint·HWP는 보기 전용**입니다. `.xlsx`는 셀 편집·필터·정렬·행/열 구조 변경과 XLSX/CSV 저장을 지원하지만, 구조를 바꾼 시트는 복잡한 수식·병합이 단순화될 수 있습니다. `.xls`는 보기·내보내기 위주입니다.
- **파이썬 `.py` 실행**은 두 방식으로 동작합니다 — ① `manneung-classroom.exe`로 열고 PC에 파이썬이 설치돼 있으면 **설치된 파이썬으로 실제 실행**(모든 라이브러리·파일 접근 가능, 대화형 `input()`, Matplotlib 그래프 회수, 30분 제한, 첫 실행 시 1회 확인), ② 그 외(오프라인/온라인 HTML 또는 파이썬 미설치)는 **브라우저 안 Pyodide**로 실행(**설치 불필요·샌드박스**). ②에서는 import를 분석해 **Pyodide 공식 패키지 → EXE 내장 wheel → PyPI 순수 Python 패키지** 순서로 자동 설치합니다. Faker는 내장되어 오프라인에서도 동작하고, 다른 패키지는 최초 설치 시 인터넷과 사용자 동의가 필요합니다. 단 **Pyodide용 바이너리가 없는 패키지(예: konlpy·selenium)** 와 OS/`subprocess` 접근은 불가하며, 설치 실패 메시지에서 일반 `.py`의 로컬 Python 실행을 안내합니다. 로컬(①) 실행은 코드가 내 PC에서 그대로 돌므로 **신뢰할 수 있는 `.py`만** 실행하세요.
- **`pip install`은 그 PC에만 설치**되고 git push/pull로 따라가지 않습니다. 그래서 **무설치 배포는 ②(브라우저) 경로**가 답입니다 — 파일(`manneung-classroom-offline.html` 또는 exe)만 나눠주면 패키지가 브라우저에서 자동으로 받아져 돌아갑니다. 로컬 파이썬으로 모든 라이브러리를 쓰려면 각 PC에 직접 설치해야 합니다.
- **로컬 파이썬 실행 시 패키지 자동/수동 설치**(EXE) — 실행 중 `ModuleNotFoundError`가 나면 **"○○ 설치할까요?"** 를 묻고, 동의하면 `pip install` 후 **자동으로 다시 실행**합니다(import명↔pip명 매핑 포함). 실행 바의 **라이브러리** 버튼으로 **데이터 분석 세트(matplotlib·openpyxl·seaborn·scipy) / 크롤링 세트(requests·beautifulsoup4·lxml) / DB 세트(MySQL: pymysql)** 를 한 번에 설치하거나 직접 입력도 가능합니다. **DB 세트는 저장소에 번들된 순수 파이썬 휠(`vendor/wheels/`)을 우선 사용해 인터넷 없이도 한 번에 설치**됩니다(다른 세트는 설치 시 인터넷 필요). 설치된 파이썬이 있어야 하며 파이썬 자체는 설치해주지 못합니다(브라우저 실행에는 불필요).
- **스크립트가 만든 출력 파일**(예: `open('out.csv','w')`·`df.to_csv(...)`)은 **로컬 파이썬(EXE) 실행 시** 결과 패널 아래 **"실행이 만든 파일"** 목록으로 떠서 **[저장] / [열기]**(앱 뷰어로) 할 수 있습니다 — 실행 직후 새로 생기거나 바뀐 파일을 감지하며, 작업폴더는 다운로드를 위해 잠시 보존됩니다(30분 또는 최근 6회분). **브라우저(Pyodide) 실행에서 만든 파일도** 똑같이 목록에 떠서 받을 수 있습니다(가상 파일시스템에서 바로 메모리로 읽어 다운로드/열기).
- **옆 파일 함께 실행** — import 대상 파일이 많은 Python 프로젝트 폴더도 사이드바의 **열기 → 폴더 열기**로 올리거나 탐색기에서 폴더째 드래그하면, 안의 `.py`를 실행할 때 같은 묶음의 옆 파일까지 작업폴더에 함께 풀어서 실행합니다. 압축(zip/tar/gz) 안의 `.py`나 여러 파일을 한 번에 업로드/드롭한 경우도 같은 방식으로 처리합니다. `import 옆모듈`·`open('data.csv')` 등이 동작하고, 스크립트 폴더와 프로젝트 루트가 작업 디렉터리·`sys.path`에 들어갑니다. 예를 들어 `somefolder/test/main.py`에서 `import somefolder.mymath.module`처럼 상위 프로젝트 루트 기준 패키지를 가져올 수 있습니다. 또 따로 저장해 열린 `.py` 탭들도 같은 프로젝트 트리라면 실행 시 함께 묶어 `import`할 수 있습니다. 묶음 합계가 50MB를 넘으면 해당 파일만 단독 실행합니다. **단일 `.py` 하나만** 올린 경우에는 옆 데이터 파일이 포함되지 않으므로 폴더·ZIP 또는 여러 파일을 함께 여세요.
- **PowerPoint**는 EXE에서 Microsoft PowerPoint가 설치되어 있으면 PDF로 정확 변환합니다. 일반 HTML, PowerPoint 미설치, 변환 실패 시에는 PPTXjs 근사 미리보기로 폴백하며 복잡한 레이아웃·애니메이션이 어긋나고 차트가 표시되지 않을 수 있습니다.
- **영상·오디오**는 브라우저가 지원하는 코덱으로 재생합니다. MP4(H.264)·WebM을 권장하며, MKV·AVI·WMV·FLV·MOV처럼 재생이 막히는 영상은 EXE에서 MP4로 변환할 수 있습니다. 변환은 500MB 이하만 지원하고, 처음에는 ffmpeg 설치를 위해 인터넷 연결이 필요할 수 있습니다.
- **HTML 파일**은 격리된(sandbox) iframe으로 보여줍니다. **zip·폴더로 함께 연 경우** 옆 이미지·CSS·JS를 인라인해 **같이 표시**합니다(이미지/폰트=`data:`, CSS=`<style>`, JS=인라인). 단독 HTML 한 장은 내장 리소스·절대경로(`https://…`)만 표시되고, **상대경로 옆 파일은 zip/폴더로 열어야** 나옵니다. CSS `@import`·JS 런타임 `fetch()` 같은 **간접 참조**는 아직 제외(직접 태그 참조 기준).
- **암호 걸린 Word·Excel·PowerPoint(.docx/.xlsx/.pptx)** 는 암호를 입력하면 열립니다(최신 Agile 암호화 기준, 약 1~3초 소요). 단 구형 Standard 암호화, 레거시 이진(`.doc` `.ppt`, 암호 `.xls`), **암호 걸린 PDF**는 아직 미지원입니다.
- **HWPX(신형 한글)는 간이 미리보기**입니다. 압축 안 OWPML XML(`Contents/section*.xml`)을 직접 파싱해 문단·표·그림과 기본 서식만 보여주며, 정확한 모양이 필요하면 한글에서 'PDF로 저장' 후 여세요. **배포용(DRM)·암호 HWPX는 열 수 없어** PDF로 다시 저장해야 합니다.
- **ZIP은 읽기 중심**입니다. 원본 압축 새로고침·덮어쓰기와 빈 폴더 표시는 지원하지 않고 편집 파일은 별도로 저장합니다. 화면에서 여는 파일은 항목당 64MB·해제 합계 256MB 제한이 있으며, Python 실행에 선택된 옆 파일 묶음이 50MB를 넘으면 현재 파일만 단독 실행합니다. 사이드바 ZIP 이름 옆 `ⓘ`에서 이 제한을 다시 확인할 수 있습니다.
- **최근 작업공간 자동 복원**은 EXE C# 백엔드에서 합계 256MB·최대 10,000개 항목까지 저장합니다. ZIP은 압축 파일 크기로 계산되며, 제한을 넘은 묶음도 현재 세션에서 열 수 있지만 다음 실행 자동 복원은 생략됩니다.
- PDF에 추가한 텍스트는 저장 시 이미지로 들어가 선택/검색이 안 됩니다(서명·기입용으로는 일반적인 방식).
- 회전된 PDF 페이지(/Rotate ≠ 0)는 요소 위치가 약간 어긋날 수 있습니다(경고 표시).
- 인증서 기반 전자서명(PKI)이 아니라 **눈에 보이는 서명**입니다.


# HTML 실행 vs EXE 실행 차이

## 한 줄 요약
**HTML 실행은 "브라우저 안 가상 환경", EXE 실행은 "로컬 PC와 연결된 진짜 환경"** 입니다.

## 기능별 차이

| 기능 | `manneung-classroom.html` / `-offline.html` (브라우저) | `manneung-classroom.exe` |
|---|---|---|
| **파이썬 실행 엔진** | Pyodide (WASM, 브라우저 안) | **로컬 PC의 Python** 우선, 없으면 Pyodide |
| **`import os`로 파일 만들기** | 가상 디렉터리에 생성 후 결과 파일로 저장/열기 가능, 앱 종료 시 가상 원본은 사라짐 | 임시 작업 폴더에 생성 후 결과 파일 수집·저장 폴더/작업공간에 이어쓰기 |
| **패키지** | Pyodide 호환 패키지(`numpy`·`pandas`·`matplotlib` 등)를 감지해 로드 | 로컬 pip 패키지 사용·설치 지원 |
| **stdin (`input()`)** | 미리 입력값을 넣어야 함 | **대화형 입력** 그대로 동작 |
| **파일 저장 위치** | Python은 File System Access 지원 시 선택 위치에 저장, 그 외 PDF·이미지·표 내보내기와 함께 다운로드 | Python·Excel 제자리 저장은 **`내 문서\만능교실 저장\`**, PDF·이미지 내보내기는 다운로드 |
| **자동 복원** (다음 실행 시 이전 작업공간 복원) | ✅ 지원 (이 브라우저의 IndexedDB에 저장) | ✅ 지원 (로컬 서버 저장 + 저장 폴더 최신본 동기화) |
| **그래프·변수·생성 파일** | 그래프 최대 8개, 변수 표, 생성 파일 수집(파일당 20MB·합계 50MB) | 그래프 최대 8개, 변수 표, 생성 파일 최대 200개 표시·저장/열기 |
| **문서 라이브러리** | offline 버전은 인라인, 일반 버전은 CDN | 앱 안에 인라인 |
| **오프라인 동작** | offline 버전의 문서 기능은 가능, Pyodide 첫 실행·패키지는 인터넷 필요 | 문서 기능+설치된 로컬 Python은 오프라인. Python 미설치 시 Pyodide 코어 폴더 또는 인터넷 필요 |
| **속도** | Python 첫 실행은 Pyodide 준비 시간이 필요 | 로컬 Python이면 즉시, Pyodide 폴백이면 HTML과 유사 |
| **폴더 안 모듈 import** | 임시 가상 폴더에 복사 후 실행 | 임시 작업 폴더에 복사 후 실행 (같은 원리지만 진짜 로컬 Python이 돌림) |

## 학생 사용 관점 핵심
1. **`os.mkdir`, `open(..., 'w')`, 파일 입출력 학습** → EXE가 훨씬 자연스러움 (HTML은 임시 디렉토리에 생기고 사라짐)
2. **`numpy`/`pandas`/`matplotlib` 학습** → 둘 다 지원. `selenium`·`subprocess`·OS 연동·Pyodide 미지원 네이티브 패키지는 EXE+로컬 Python 필요
3. **`input()` 대화형 입력 연습** → EXE가 자연스러움
4. **단순 print/조건/반복문 등 기초 문법** → 둘 다 동일하게 잘 됨
5. **자동 복원이 필요한 일상 사용** → 둘 다 지원 (EXE는 저장 폴더 최신본 동기화까지, 브라우저는 같은 브라우저로 다시 열 때 복원)

## 정리
- **수업·실습용 배포** = EXE 권장 (로컬 파이썬 환경을 그대로 활용 + 입출력 자연스러움)
- **빠른 한 번 사용·설치 불가 환경** = HTML offline 한 파일 (USB로 들고 다녀도 됨, 저장은 브라우저 파일 선택 또는 다운로드)
- **개발자가 코드 수정 후 즉시 확인** = `manneung-classroom.html`(소스를 `src/js/*.js`로 직접 로드)
