네이버·구글·유튜브 메인처럼 다른 화면 안에 넣는 것을 막아 둔 사이트가 많습니다. 저장 전에 미리보기 · 테스트로 실제로 뜨는지 꼭 확인하세요. 대기 화면에서 페이지가 안 열리면 저장해 둔 영상, 그것도 없으면 시계 애니메이션으로 자동 전환됩니다.

대기 화면 내용기본 애니메이션(시계)영상을 고르면 재생하고(여러 개 선택 시 차례대로 반복), 없으면 시계 애니메이션을 보여줍니다. MP4(H.264)·WebM 권장 — 재생이 안 되는 파일은 저장 전에 걸러 드립니다. 영상은 이 브라우저에만 저장되어 프로그램(exe·HTML) 용량과 무관합니다.

꺼 두더라도 측면 버튼이 브라우저 '뒤로'로 동작해 작업 화면을 벗어나는 것은 항상 막습니다.

ClassDock에 오신 걸 환영해요

설치 없이 PDF·엑셀·이미지·파이썬을 한 창에서 열고 다뤄요. 아래 3가지만 알면 바로 시작할 수 있어요.

  1. 1. 파일 열기시작 화면의 파일 열기를 누르거나 파일을 끌어다 놓아요. 여러 개·폴더째도 한 번에 열려요.
  2. 2. 파이썬 실행코드를 쓰고 ▶ 실행(또는 Ctrl+Enter)을 누르면 바로 결과가 나와요. 파이썬을 설치하지 않아도 돼요.
  3. 3. 저장 상태 확인파일 이름 옆 상태 배지에서 원본·사본 저장 위치와 저장 여부를 함께 확인해요. 저장 버튼은 언제나 저장으로 표시됩니다.

파일은 외부로 전송되지 않고, 이 컴퓨터 안에서만 처리돼요.

도움말

기능 둘러보기
  • 파일 열기 — 끌어다 놓거나 폴더째로. PDF·Word·Excel·PowerPoint·한글·이미지·코드·ZIP을 한꺼번에 열 수 있어요.
  • PDF — 서명·텍스트·날짜·체크·펜 필기, 글자 드래그 선택 → 형광펜 강조, 페이지 썸네일·추출·합치기, 인쇄 / PDF로 저장.
  • Python 실행 — ▶로 바로 실행, 자동완성·정의 이동, 단계 실행으로 변수 추적, 진단과 자동 채점, 라이브러리 설치까지.
  • Jupyter 노트북(.ipynb) — 셀 하나씩 실행(Shift+Enter)하면 변수가 다음 셀로 이어지는 커널 모드.
  • 화이트보드 — 자유 필기·도형·이미지, 수학·과학 도구상자와 스포트라이트·화면 가리개로 판서. 새로 만들기에서 추가.
  • 분할 작업 — 어떤 문서든 참고 화면과 함께 좌우·상하로 보고, 필요할 때 참고 문서를 잠가 분할 비율과 위치를 조절.
  • 임시 메모(Ctrl+M)·이미지 메모(캡처 여러 장 붙여넣기·일괄 저장)·다크 모드·작업공간 자동 복원. 모든 처리는 이 컴퓨터 안에서만 이뤄지고 파일은 외부로 전송되지 않아요.
