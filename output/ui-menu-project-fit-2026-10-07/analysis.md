## 유지할 구조와 디자인
헤더와 탭 줄, 파일 검색과 파일 목록, 하단 + 진입점을 유지한다.
기본 라이트 테마에서도 헤더 #1e293b / 사이드바·탭 줄 #0f172a는 어두운 색이다.
본문은 #eef2f7, 메뉴는 흰색, 강조색은 #4f46e5, 경계선은 #e2e8f0.
메뉴 검색과 카테고리 배치는 새 제안이다. 현재 + 메뉴에는 검색 칸이나 카테고리 UI가 없다.
기존 메뉴에는 문서 생성 외에도 사진첩 열기·리플레이 열기·제출본 검수·시험 채점 동작이 있다.
새 시안에서도 이 이름과 동작의 차이를 보존한다.
즐겨찾기 저장 같은 새 기능을 전제하지 않는다.

## 제안한 5개 시안
1. 압축 검색형 — 좁은 메뉴에 검색·카테고리 칩·그룹 목록·내부 스크롤.
2. 작은 카드형 — 선택 카테고리의 도구를 2열 카드로 표시. 확장자와 짧은 설명.
3. 카테고리 2단형 — 메뉴 안 왼쪽 분류, 오른쪽 도구 목록.
4. 전체 항목 2열형 — 26개 동작을 5개 그룹, 두 열로 배열.
5. 기존 팔레트 연계형 — 기존 Ctrl+K 팔레트의 시각적 패턴을 재사용해 + 메뉴 동작을 검색하는 제안.

카테고리 분류는 설계 제안이며 기존 코드에 이미 존재하는 분류가 아니다.

## 구현 시 고려할 점
- 팝업은 사이드바 폭에 묶이지 않는 기존 화면 레이어를 활용할 수 있다.
- 메뉴 최대 높이와 내부 스크롤을 지정해 긴 메뉴가 화면 밖으로 나가지 않도록 한다.
- 헤더의 전체 기능 검색과 + 메뉴의 26개 동작 검색을 문구로 구분한다.
- 검색 키워드에 표시 이름·확장자·영문 이름을 포함하는 방향이 적절하다.
- 키보드 포커스·Escape 닫기·외부 클릭 닫기를 새 배치에서도 유지한다.
- 작은 화면과 UI 확대에서는 메뉴 폭·높이를 뷰포트에 맞추고 카드/열을 줄여야 한다.
- 기존 한국어/영어 지원과 테마 변수에 맞춰 새 문구·스타일을 추가한다.

## 산출물 성격
실제 HTML/CSS/JS 구조를 읽고 제작한 이미지 생성 도구의 디자인 시안이다.
실행 화면 캡처나 픽셀 단위 재현물이 아니며, 글자·아이콘·일부 비율은 개념 표현이다.
앱 소스 수정, 프로세스 종료, HTML/EXE 재빌드, 브라우저 자동화, 화면 캡처는 수행하지 않았다.
