## 구조에 맞춘 설계 판단
현재 검색창은 문서 생성뿐 아니라 PDF 편집, 코드 실행·진단, 노트북, 파일 작업, 보기와 설정까지 찾는 글로벌 명령 팔레트다. 검색 목적을 가장 먼저 보이게 하고 현재 문서에서 사용할 수 있는 명령만 보여 주는 조건을 유지한다.

긴 목록 앞부분에는 생성 명령이 몰려 있다. 그룹 제목·카테고리·문맥 구분을 추가하면 현재 문서 작업과 앱 설정을 발견하기 쉽다. 사이드바 + 메뉴의 26개 동작과 명령 팔레트의 명령 목록은 완전히 같지 않으므로 26개 목록을 그대로 복사하지 않는다.

시안에서 사용하는 PDF 서명·텍스트·필기 등은 PDF가 열린 장면에서, 코드 실행·단계 실행·진단·자동 채점은 Python 편집기가 열린 장면에서만 표시한다. 단축키는 코드에서 연결이 확인된 기본 조합만 표시한다.

아이콘은 프로젝트 SVG 스타일로 복원하는 제안이다. 카테고리 분류, 짧은 설명, 결과 설명 패널, 문맥 탭, 상단 제목줄의 이동 손잡이는 새 UI 제안이다. 즐겨찾기·최근 명령·AI 기능·수치 대시보드는 전제하지 않는다.

## 산출물과 검증 범위
실제 프로젝트 소스를 읽고 built-in image_gen으로 각각 생성한 디자인 이미지다. 사용자가 제공한 기존 창 이미지와 이전에 선호한 카테고리 시안은 시각적 참고로 사용했다.
이미지의 글자·아이콘·비율은 디자인 표현이며, 실제 실행 화면 캡처나 픽셀 단위 재현물이 아니다.
앱 소스 수정, 프로세스 종료, HTML/EXE 빌드, 브라우저 자동화와 화면 캡처는 수행하지 않는다.
최종 프롬프트는 같은 폴더의 prompts.md에 저장한다.
