A

지금

PDF일 때는 확대·축소가 머리글과 문서 위 알약(오른쪽 위) 두 군데에 있고, 인쇄는 PDF가 아닐 때만 나옵니다. 파일 이름은 가운데와 탭에 두 번 나옵니다.

B

정돈형

앱 전체 일은 왼쪽·오른쪽 끝, 지금 문서 일은 그 사이 한 칸에. 가운데는 기능 검색 칸입니다. 확대·축소와 전체화면은 PDF 알약에 이미 있으므로 머리글에서 뺍니다. 가운데 파일 이름 대신 저장 상태와 인코딩만 오른쪽에 짧게 보입니다. ⋯ 메뉴는 펼쳐 둔 모습입니다.

⋯ 메뉴로 인쇄(PDF 아닐 때) · 전체화면 · 집중 모드 · 저장 폴더 · 이미지 메모 · 도움말 · 테마 · English
열기 하나로 파일 열기·폴더 열기를 한 단추 메뉴로(사이드바 열기 메뉴와 같은 것)
그대로 PDF 편집·PDF 페이지 메뉴(PDF일 때만) · 탭 줄 칠판·지도·+N · 사본 저장 띠 · 펫 집중 타이머(돌 때만)
C

한 줄형

머리글과 탭 줄을 한 줄로 합칩니다. 로고는 D 심볼만 남기고, 저장 상태·인코딩·준비 표시 같은 상태는 맨 아래 상태 줄로 내립니다. 오른쪽 단추가 탭 줄로 올라오므로 같은 창 폭에서 보이는 탭이 줄어듭니다.

⋯ 메뉴로 B의 메뉴 + 파일 열기·폴더 열기
