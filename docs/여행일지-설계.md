# 여행일지(.trip) — 설계 문서

> 작성 2026-09-20 · 상태: **검토 완료, 구현 없음 · 결정 다섯 가지 끝(9장)** · 대상: 여행 기록 · 체험학습 학습지 · 답사 보고서를 **한 문서의 세 갈래**로
> 바탕: 일기장 `src/js/diary.js`(종이·스티커 엔진) · 연대표 `src/js/timeline.js`(여행 일정 모드) · 지도 `src/js/map-viewer.js`
> 관련 문서: `docs/일기장-설계.md` · `docs/과제패키지-설계.md`

## 0. 한 줄 요약

새로 만들 것은 **문서 껍데기와 다리**뿐이다. 종이·스티커·인쇄·암호는 일기장에, 일정은 연대표에, 동선·좌표는 지도에 이미 있다.
갈래(개인 여행 기록 / 체험학습 학습지 / 답사 보고서)는 **자료를 가르지 않고** 말·기본값·접기만 바꾼다 — 연대표가 이미 쓰는 방식이다.

## 2. 결정 제안

| 쟁점 | 제안 | 이유 |
|---|---|---|
| 일기장에 얹나, 새 문서인가 | **새 문서 `.trip`** + 일기장의 종이 그리는 부분만 떼어 함께 쓰기 | 뼈대가 한 단계 다르다. 일기장은 `날짜 → 종이 한 장`(뼈대 = 달력), 여행은 `여행 한 건 → 날 → 장소 여럿`(뼈대 = 여정). 3박 4일짜리 문서에서 1년 달력은 쓸모가 없다 |
| 장소를 스티커로 둘까 | **따로 둔다**(`spots`) | 지도·일정·경비 세 화면이 같은 장소를 읽는다. 스티커는 '종이 위 좌표'라 성격이 다르다 |
| 저장 | **무압축 ZIP + 일기장과 같은 암호 봉투** | 여행 사진은 일기보다 훨씬 많다. 일기장 ZIP·봉투 코드를 그대로 쓴다 |
| 사진 | `assets/<해시>` 를 스티커와 장소가 **함께 가리킨다** | 일기장이 이미 SHA-256 앞 20자리로 중복을 막는다 — 같은 장은 한 벌만 저장된다 |
| 갈래 | **`purpose` 한 필드 + 라벨 표 한 벌.** 자료는 세 갈래의 상위집합 하나 | 갈래 전환이 무손실이어야 한다(3장) |
| 지도 | 편집 중엔 살아 있는 Leaflet 칸, 저장·인쇄 때는 **캡처 PNG 를 굳혀 둔다** | 오프라인 교실에서 타일이 회색으로 뜨는 문제와 인쇄 문제가 한 번에 풀린다 |
| 적용 지역 | **국내 우선 + 해외는 조용히 감춤** — 2026-09-20 결정 | 2.1 |

### 2.1 적용 지역 — 국내 우선, 해외는 감춤 (2026-09-20 결정)

해외 여행에도 쓸 수 있게 하되, **해외 자동 채움 API를 새로 붙이지는 않는다.** 한국 밖 좌표에서는 국내 전용 기능을 **감출 뿐 막지 않는다.**

| 해외에서도 되는 것 | 국내에서만 되는 것 |
|---|---|
| 배경 지도 4종(OSM·OpenTopoMap·CARTO·Esri) — 전 세계 타일 | 기상청 날씨(관측 지점 97곳·격자 nx/ny) |
| Nominatim 장소 검색·역지오코딩 — 전 세계 | 특일(공휴일·24절기) |
| 거리·반경·표시 잇기(직선) | 카카오 길찾기·장소 검색·주변 시설·지역 통계 |
| 사진 EXIF GPS | 색칠 지도(한국 행정경계) |
| **환율** | 평면 좌표 변환(TM·UTM-K) |
| 종이·스티커·인쇄·암호 | 버스·지하철·항공·여객선 |

**판정은 이미 있는 것을 쓴다** — `MNKoreaCoords.inKorea(point)`(32.8~38.9N, 124~132.2E, 독도·마라도 포함, `korea-coords.js:169`). `map-viewer.js` 가 이미 네 군데에서 쓴다. 추가 비용은 60~80줄이다.

**규칙 넷**

1. **판정은 한 곳에서** — `tripIsDomestic(model)`. 문서의 장소 중 좌표가 있는 것들로 정하고, 좌표가 하나도 없으면 **국내로 본다**(학습지·답사가 기본이고, 주소만 적은 문서가 흔하다).
2. **감춤이지 막기가 아니다.** 단추를 지우되 이미 들어 있는 값(해외 문서에 남은 날씨·기분)은 그대로 보여 준다. 부록 B의 `kind` 규칙과 같은 생각이다.
3. **환율은 반대로 움직인다** — 해외 문서에서 **켜진다**. 국내 전용으로 못 박았다면 경비+환율 후보(6장 6순위)와 형식의 `budget.currency` 가 통째로 죽었을 것이다. 이 결정이 살린 것이 그것이다.
4. **갈래와 지역은 상관있다.** 학습지·답사는 사실상 100% 국내다. 해외가 문제 되는 것은 `purpose:"trip"` 한 갈래뿐이라, 감춤 규칙을 시험할 자리도 거기 하나다.

나중에 해외 날씨(키 없는 Open-Meteo 등)를 붙이기로 해도 **이 작업은 버려지지 않는다** — 감춤 자리가 곧 갈아 끼울 자리다.

### 2.2 탭·사이드바 — 배지와 색은 공통 (2026-09-20 결정)

"탭 이름"은 하나가 아니라 넷이고, 넷이 서로 다른 자리에서 정해진다.

| 무엇 | 지금 어디서 정해지나 | 갈래를 따르나 |
|---|---|---|
| 탭에 보이는 **글자** | `d.name` — **파일 이름 그대로**(`documents.js:1990`) | **따른다** — 새로 만들 때의 기본 이름으로 |
| 탭·사이드바 **배지** | `iconFor(kind, name)` — "일기"·"지도"·"연표" | **아니다** — `"여행"` 한 벌 |
| 탭·행 **색** | `extCategory(kind, name)` | **아니다** — `"trip"` 한 벌 |
| 문서 종류 **이름** | 빈 화면·팔레트·검색 | **따른다** — 부록 A `docName` |

**배지를 갈래에 묶지 않는 이유**는 `purpose` 가 ZIP 안에 있기 때문이다. 배지를 그려야 하는데 속을 못 읽는 순간이 실제로 있다.

- **잠긴 문서** — 암호 `.trip` 은 폴더 일괄 열기·작업공간 복원에서 잠긴 탭만 만들고 속은 안 연다(일기장이 이미 그렇다).
- **복원 중** — 탭이 먼저 서고 내용이 나중에 온다.

배지가 갈래를 따르면 같은 파일의 배지가 **열기 전후로 바뀐다.** 사이드바에서 그건 "파일이 바뀐 것"으로 보인다.

**선례가 답을 준다**: `.timeline` 은 여행 일정 모드여도 배지가 그냥 "연표"다. 갈래는 문서 안에서만 드러나고 배지는 공통이며, 그걸로 문제가 없었다.

그리고 탭 글자가 파일 이름이므로, 새로 만들 때 기본 이름을 갈래로 지으면(부록 A `fileBase`) **탭에는 이미 갈래가 보인다** — `여행일지.trip` · `체험학습.trip` · `답사.trip`.

- **사용자가 지은 파일 이름은 갈래를 바꿔도 앱이 갈아 끼우지 않는다.** 기본 이름은 만들 때 한 번 쓰이는 씨앗일 뿐이다(3.4의 '시작 서식'과 같은 성질).
- `iconFor`·`extCategory` 에는 `"trip"` 한 갈래만 더한다. 시그니처를 건드리지 않는다.

### 2.3 지도는 두 겹 — 살아 있는 칸 + 굳힌 그림 (2026-09-20 결정)

편집 중에는 살아 있는 Leaflet 칸, 인쇄·오프라인에는 **굳힌 그림**을 쓴다. 굳힌 그림은 **날마다 한 장 + 여행 전체 한 장**이다.

**이미 있는 것**

`mapCaptureDataUrl(stage, attribution, labels)` — html-to-image, `pixelRatio: 2`. 캡처 때 감출 것(컨트롤·말풍선·이름표·뜬 칸들)이 실측으로 정리돼 있다(`MAP_CAPTURE_HIDDEN_PANES` — 닫은 말풍선이 200ms 남는 함정까지). 그리고 `mapStampCapture` 가 **출처를 PNG 에 직접 찍는다** — 9장 2번(답사 보고서 자료 출처)의 절반이 여기서 풀린다.

**크기**

| | |
|---|---|
| 700×500 칸 → PNG | `pixelRatio 2` 라 1400×1000, **1~2.5MB** |
| 일기장 길로 다시 구우면 | `diaryPrepareImage(blob, 1600)` → JPEG **약 400KB**(사진과 똑같은 길) |
| 4일치 날마다 + 전체 | 약 2MB |

**규칙 다섯**

1. **굳히기는 단추로만 한다.** "저장할 때 자동"은 쓸 수 없다 — 아래 2·3 때문이다.
2. **지도 칸이 접혀 있으면 못 찍는다.** 캡처는 DOM 에 그려진 `stage` 를 찍는다. 단추는 칸이 펴져 있을 때만 켠다.
3. **오프라인에서는 막는다.** 타일이 안 온 상태로 찍으면 **회색 사각형이 파일에 박힌다** — 가장 고약한 결과다. 타일이 실제로 그려졌을 때만 굳힌다(`.map` 의 `/can-proxy-tiles` 프로브·`.map-network-notice` 와 같은 판정).
4. **낡음을 알린다.** 굳힐 때의 서명(`stillKey` = 장소 좌표·순서·색 + basemap + center/zoom)을 함께 저장하고, 지금 서명과 다르면 "지도 그림이 낡았어요 · 다시 굳히기"를 띄운다. **자동으로 다시 굳히지는 않는다**(2·3 때문에 언제나 성공하지 않는다).
5. **굳힌 그림이 없으면 그 자리를 비운다.** 인쇄에 회색 지도를 넣느니 아무것도 안 넣는 쪽이 낫다.

**인쇄에서 어느 것을 쓰나**: 그날 쪽은 `days[].still`, 표지는 `map.still`.

**함정**: 굳힌 그림도 `assets/` 라 **참조 목록(`tripReferencedAssets`)에 넣어야 한다.** 빠뜨리면 다음 저장에서 조용히 사라진다(일기장이 스티커 갈래마다 겪은 그 함정).

### 2.4 학습지 갈래의 꾸미기 — 접되 막지 않는다 (2026-09-20 결정)

`field` 갈래에서 스티커·꾸미기는 **기본으로 접혀 있고, 막히지는 않는다.**

- 막으면 "왜 스티커가 없냐"는 질문이 온다. 접으면 **처음 화면이 조용하고**, 쓰고 싶은 아이는 펴면 된다.
- **접힘은 갈래의 기본값이지 잠금이 아니다.** 사용자가 편 상태는 일기장과 같이 `localStorage` 에만 둔다 — 접었다고 문서가 '저장 안 됨'이 되면 안 된다.
- **"이 학습지에서는 꾸미기를 쓰게 하자"를 선생님이 파일에 담는 필드는 만들지 않는다.** 3장의 자료 층 규칙에 걸리고, 지금은 그걸 원한다는 근거가 없다. 필요해지면 `style` 옆에 한 필드 더하면 된다.

### 2.5 자료 출처 — 앱이 쓴 것은 앱이 박는다 (2026-09-20 결정)

**범위가 틀려 있었다.** 9장에 "답사 보고서의 자료 출처"로 적어 두었지만, 출처 표시는 **지도를 쓰는 모든 갈래의 의무**다. 여행 기록도 OSM 타일을 썼으면 같다.

지금 `.map` 이 하는 것(`map-viewer.js:2260`·`2278`):

| 어디 | 출처가 어떻게 |
|---|---|
| 살아 있는 칸 | Leaflet 저작권 줄(컨트롤) |
| 굳힌 그림 | `mapStampCapture` 가 **그림에 새긴다** — 캡처 전에 컨트롤을 감추기 때문에 그림 자체에 있어야 한다 |
| 색칠 지도 | 경계는 공공누리 제1유형이라 `choropleth` 가 켜졌을 때만 타일 출처 뒤에 덧붙인다 |

**여행일지에서 빠지는 자리는 인쇄 층 하나다.** 인쇄는 화면을 찍지 않고 A4 폭으로 다시 배치하므로(일기장 방식) Leaflet 컨트롤이 따라오지 않는다.

**규칙 넷**

1. **인쇄 층 마지막에 '자료 출처' 한 줄을 앱이 넣는다.** 갈래와 무관하다.
2. **쓴 것만 적는다.** 타일 한 종류만 썼으면 그것만, 색칠 지도를 안 켰으면 경계 출처는 뺀다 — 안 쓴 자료의 출처를 적는 것은 틀린 표시다. `mapCaptureAttribution` 과 같은 방식으로 모은다.
3. **앱이 넣은 줄은 지울 수 없다**(의무). 답사 갈래의 `source` 칸(4장)은 **사용자가 더하는 출처**(면담 대상·참고 문헌)로 성격이 다르고, 인쇄에서 앱 줄 **위**에 함께 나온다.
4. 굳힌 그림에는 이미 새겨져 있으므로 **두 번 적지 않는다** — 그림이 있는 쪽은 그림이 맡고, 인쇄 줄은 그림 밖에서 쓴 자료(색칠 지도·통계)를 맡는다.

### 일기장 코드에서 가져올 수 있는 선

`diary.js` 5,281줄의 경계가 뚜렷하다.

| 범위 | 줄 | 성격 | 재사용 |
|---|---|---|---|
| 1 ~ 1,879 | 약 1,880줄 | 전역 순수 함수 — 형식·ZIP·암호 봉투·원고지 배치·종이 무늬·스티커 정규화·자동 배치·내장 그림 144종 | **그대로 부를 수 있다**(전역 스크립트라 `trip.js` 에서 바로 호출) |
| `mountDiaryEditor` 1,880 ~ 5,281 | 약 3,400줄 | 한 덩어리 클로저 — 달력·카드 목록·종이 렌더·스티커 끌기·인쇄 층이 뒤섞여 있다 | **지금 모양으로는 못 쓴다** |

그래서 선택지는 셋이고, **B′** 를 권한다.

| 안 | 내용 | 평가 |

- `destroyPaper()` — 종이가 `document` 에 직접 건 `selectionchange` 는 종이가 거둔다.

**밟은 함정 셋**

1. **`ctx` 는 이미 쓰는 이름이었다.** 그리기 코드가 캔버스 컨텍스트를 `ctx` 로 쓴다(5곳). 매개변수를 `ctx` 로 지으면 그 함수들 안에서 가려져 `ctx.current is not a function` 이 난다. **eslint 는 못 잡는다.** 게다가 그 예외가 `applyStyle()` 안에서 나는 바람에 뒤따르는 `layout()` 이 안 돌아 **종이 높이가 0** 이 되었고, 증상(그림 칸 단추가 안 눌림)이 원인과 멀리 떨어져 보였다. → 이름은 `paperEnv`.
2. **vm 하네스의 끝 표시가 함수 밖으로 나가면** 잘린 조각에 `return` 이 딸려 와 "Illegal return" 으로 죽는다 → `tests/diary.test.js` 의 끝 표시를 함수 안(`바깥에 내주는 읽기 창구`)으로 옮겼다.
3. 하네스에도 `paperEnv` 창구를 넣어야 한다(`current`·`history`·펜 셋).

## 3. 갈래(purpose) 셋

### 3.1 선례 — 연대표

```js
// timeline.js:848
for (const [value, label] of [["timeline", "일반 연대표"], ["trip", "여행 일정"]]){ … }
// timeline.js:1733
purposeSelect.addEventListener("change", () => {
  model.purpose = timelinePurpose(purposeSelect.value);
  applyPurposeLabels(); history.commit(); touch(); renderAll();
});
```

`purpose` **한 필드**와 `applyPurposeLabels()` **한 함수**로 약 30개 낱말이 한꺼번에 갈린다(사건 → 일정, 분류 → 유형, 유적지 → 장소…). **자료 구조는 한 글자도 안 바뀐다.** 그래서 갈래를 되돌려도 잃는 것이 없고 되돌리기 한 단계로 돌아온다.

### 3.2 '달라진다'를 세 층으로 가른다

| 층 | 예 | 갈래로 가르나 | 이유 |
|---|---|---|---|
| **말** | 첫째 날 / 활동 / 조사 차례 | **예** | 비용 0, 되돌리기 안전 |
| **보이는 것** | 기본 종이, 도구막대 차례, 무엇을 접어 두나, 인쇄 꼴 | **예** | 자료는 그대로 두고 보기만 바꾼다 |
| **자료** | 갈래마다 다른 필드 | **아니오** | 갈래를 바꾸는 순간 자료가 사라진다. `normalize`·`clean`·`isEmpty` 세 곳이 갈래 수만큼 갈라져 터진다 |

### 3.3 갈래별로 바뀌는 것

| | **개인 여행 기록** `trip` | **체험학습 학습지** `field` | **사회과 답사 보고서** `survey` |
|---|---|---|---|
| 문서 이름 | 여행일지 | 체험학습 보고서 | 답사 보고서 |
| 날 부르는 말 | 첫째 날 | 활동 | 조사 차례 |
| 장소 부르는 말 | 들른 곳 | 장소 | 조사 지점 |
| 기본 종이 | 줄 공책 + 종이 효과 **켬** | 줄 공책, 꾸미기 **접음** | 모눈 / 빈 종이 |
| 도구막대 앞자리 | 사진·스티커·꾸미기 | 질문·사진 | 지도·표·자료 출처 |
| 지도 | 동선 잇기 켬 | 굳힌 그림 한 장 | 켬 + 색칠 지도·반경·주변 시설 |
| 질문 칸 | 접음 | **켬** | 접음 |
| 경비 칸 | **켬** + 환율 | 접음 | 접음 |
| 자유 항목 표 | 접음 | 접음 | **켬** |
| 인쇄 머리 | 제목 · 기간 | **학교·학년·반·이름 칸** | 주제 · 조사자 · 조사일 · **자료 출처** |
| 인쇄 꼴 | 사진 큼직하게 | A4 한두 쪽, 답 칸 넉넉히 | 표지 + 지도 + 지점별 쪽 |

질문 칸·경비 칸·자유 항목 표는 **셋 다 공통 필드로 있고, 비어 있으면 저절로 숨는다.** 갈래는 "새로 만들 때 켜져 있나"와 "단추가 앞에 오나"만 정한다.

### 3.4 갈래(purpose)와 시작 서식(template)은 다른 축이다

"셋이 다르다"고 느끼는 것의 절반은 **처음에 어떻게 채워져 있는가**이지 **지금 어떤 갈래인가**가 아니다. 섞으면 사고가 난다.

| | 갈래 `purpose` | 시작 서식 |
|---|---|---|
| 언제 | 언제든 바꾼다 | 만들 때 **한 번** |
| 파일에 | 저장한다 | **저장하지 않는다**(결과만 남는다) |
| 하는 일 | 말·기본값·접기·인쇄 꼴 | 날 3개·질문 5개·머리 칸을 미리 채워 둔다 |
| 바꾸면 | **아무것도 사라지지 않는다** | (바꾸는 것이 아니다) |

안 가르면 "갈래를 답사로 바꿨더니 써 둔 질문이 조사 항목으로 덮어써졌다"가 된다. 일기장이 글감을 별도 필드로 만들지 않고 **본문에 끼워 넣는 문구**로 처리한 것과 같은 판단이다.

## 4. 파일 형식

`.trip` = 무압축(STORE) ZIP. 일기장과 같은 뼈대·같은 암호 봉투.

```
trip.json
assets/<해시>.jpg    사진 바이트(SHA-256 앞 20자리 — 같은 사진은 한 번만)
```

```jsonc
{
  "format":"classdock-trip", "version":1,
  "title":"제주 3박 4일", "createdAt":0, "updatedAt":0,
  "purpose":"trip|field|survey",                        // 갈래. version 1 에 처음부터 넣는다
  "style": { /* 일기장 style 그대로 — 줄 무늬·종이 효과·글꼴 */ },
  "header": [ { "k":"학년", "v":"4" }, { "k":"이름", "v":"" } ],   // 인쇄 머리의 자유 칸
  "map":   { "basemap":"osm", "center":[33.4,126.5], "zoom":9, "route":true,
             "still":"assets/….jpg", "stillKey":"…" },  // 여행 전체 굳힌 그림 + 굳힐 때의 서명(2.3)
  "budget":{ "currency":"KRW", "rate":null },           // 받은 날 환율을 함께 굳힌다
  "days": [
    { "date":"2026-07-20", "title":"첫째 날 — 성산", "text":"…",
      "weather":"", "mood":"", "tags":[], "favorite":false,
      "style":null, "drawing":[], "stickers":[ /* 일기장과 100% 동일 */ ],
      "still":"assets/….jpg", "stillKey":"…",                     // 그날 동선을 굳힌 그림(2.3)
      "prompts":[ { "q":"가장 기억에 남는 것은?", "a":"" } ],       // 학습지 = 선생님이 q, 학생이 a
      "spots": [
        { "id":"sp-…", "at":"09:30", "name":"성산일출봉", "address":"…",
          "lat":33.458, "lng":126.942, "kind":"sight|food|stay|move|shop",
          "note":"", "color":"blue", "photos":["assets/….jpg"],
          "cost":  { "amount":5000, "currency":"KRW" },            // 여행 = 합계·환율 때문에 전용 필드
          "fields":[ { "k":"지형", "v":"현무암 해안" } ] }          // 답사 = 자유 조사 항목

```

- **`spots` 는 스티커와 따로 둔다.** 지도·일정·경비가 함께 읽는 자료다.

- **빈 날은 저장하지 않는다** — 일기장과 같다.

## 부록 A. 갈래 라벨 표 (초안)

3장이 세운 전제 — "갈래는 말만 바꾼다" — 가 정말 맞는지 낱말을 전부 뽑아 확인한 표다. **43줄 중 41줄이 표 하나로 끝나고, 2줄만 표 밖으로 나간다**(A.3).

### A.1 코드 모양

연대표는 낱말마다 삼항 연산자를 썼다(`timeline.js:1080` `applyPurposeLabels`). 갈래가 둘일 땐 읽혔지만 **셋이 되면 못 읽는다.** 그래서 표로 뒤집는다.

```js
// trip.js — 값은 [여행, 학습지, 답사] 차례. 빈 문자열은 '그 갈래에선 감춤'.
const TRIP_PURPOSES = ["trip", "field", "survey"];
const TRIP_WORDS    = { day:["첫째 날", "활동", "조사 차례"], … };
const TRIP_WORDS_EN = { day:["Day", "Activity", "Visit"], … };
function tripWord(purpose, id){            // 짧은 낱말은 여기서만 고른다(공용 사전 금지)
  const at = Math.max(0, TRIP_PURPOSES.indexOf(purpose));
  const table = tripIsEn() ? TRIP_WORDS_EN : TRIP_WORDS;
  return (table[id] || [])[at] || (TRIP_WORDS[id] || [])[0] || id;
}
```

`applyPurposeLabels()` 는 `[요소, 속성, id]` 목록을 한 번 돌기만 한다. 갈래를 넷으로 늘려도 표에 열 하나를 더할 뿐이다.

### A.3 뽑아 보니 드러난 것

| | 줄 수 |
|---|---|
| 전부 | **43** |
| 세 갈래가 같은 말(공통) | 9 |
| 갈래마다 갈리는 말 | 34 |
| 그중 **표 한 장으로 끝나는 것** | **32** |
| 표 밖으로 나가야 하는 것 | **2** |

표가 감당하려면 규칙 **둘**만 더하면 된다.

1. `{n}`·`{sum}` **틀 치환**(`dayNth`·`dayCount`·`costTotal` 3줄). 한국어는 "첫째 날"·"3일"인데 영어는 "Day 1"·"3 days"라 **낱말이 아니라 틀**이어야 한다.
2. **빈 문자열 = 감춤**(`choro`·`prompts`·`promptAnswer`·`cost`·`costTotal`·`fields`·`source` 7줄). 갈래마다 단추를 따로 감추는 코드를 쓰지 않는다.

표 밖으로 나가는 둘은 **이미 4장 형식에 자리가 있다**.

| 밖으로 나가는 것 | 왜 | 어디로 |
|---|---|---|
| `spotKind` **선택지** | 라벨이 아니라 **고르개 목록 자체**가 갈린다 — 여행은 볼거리·먹을거리·잠자리·이동·가게, 학습지는 견학·체험·식사·이동, 답사는 관찰·면담·측정·채집 | `TRIP_SPOT_KINDS[purpose]`, 값은 `spots[].kind` |
| `printHead` | 낱말이 아니라 **머리 칸 구성**이다 | `header[]` 배열의 갈래별 기본값 |

### A.4 이 표가 드러낸 함정

- **`spotKind` 의 저장 값은 세 갈래의 합집합이어야 한다.** 갈래를 답사로 바꿨다고 '볼거리'가 버려지거나 '관찰'로 바뀌면 3장의 무손실 전제가 깨진다. 고르개에 **무엇을 보여 줄지만** 갈래가 정하고, 모르는 값이 들어 있으면 **그 값을 목록 맨 아래에 그대로 덧붙여 보여 준다.**
  - 일기장과 **반대 규칙**이라 헷갈리기 쉽다. `diaryNormalizeSticker` 는 모르는 `art` 이름을 `null` 로 버린다 — 그릴 수 없는 그림이라서다. `kind` 는 **글자로 보여 줄 수 있으므로 버리지 않는다.**
- **짧은 낱말 34개는 전부 `trip.js` 안에 둔다.** "날"·"곳"·"답"·"종류"를 공용 사전에 넣으면 다른 화면의 같은 글자까지 바뀐다(일기장 3단계에서 값을 치른 함정). 공용 사전에 올릴 것은 '아' 묶음의 문장 2개뿐이다.
- **e2e 는 이 표의 글자로 요소를 집으면 안 된다.** 갈래를 바꾸면 32개가 한꺼번에 바뀐다 → 클래스로 집는다(일기장이 `diary-undo-btn` 을 준 것과 같은 이유).
- **`dayNth` 의 한국어 서수는 10을 넘으면 어색하다**("열한째 날"). 10 이상은 "{n}일째"로 넘기는 갈래가 틀 안에 필요하다.
- 시험으로 못 박을 것: **표의 세 열이 모두 같은 키 집합을 가진다**(빠진 칸이 있으면 첫 갈래 말이 새어 나온다). 일기장이 사전 누락을 소스에서 뽑아 검사하는 것과 같은 방식.

### A.5 결론

**"말만 바꾸면 된다"는 34개 중 32개(94%)에서 맞다.** 나머지 둘은 3장이 말한 '보이는 것' 층이고, **자료 층으로 넘어간 것은 하나도 없다** — 갈래 설계의 전제가 유지된다.

### B.3 색은 구분 표시가 아니다

`MAP_MARKER_COLORS` 는 **여섯 색뿐**인데(`map-viewer.js:60`) 한 갈래에 뜨는 갈래는 일곱이다. 그래서 갈래마다 **반드시 한 쌍이 같은 색**이 된다(여행 `activity`·`rest`, 학습지 같은 쌍, 답사 `sight`·`observe`).

이건 고칠 문제가 아니라 **설계 결론**이다.

- 구분은 **아이콘**이 한다. 색은 **처음 찍힐 때의 기본값**일 뿐이고, 표시 색은 지금도 사용자가 따로 고른다(`marker.color`).
- 색으로 갈래를 알아보게 만들면 여섯 갈래를 넘는 순간 설계가 막힌다. 처음부터 그 길로 가지 않는다.

### B.4 코드 모양과 규칙

```js
// [id, 아이콘(DIARY_ART), 기본 색, [여행, 학습지, 답사] 한국어, [영어]]
const TRIP_SPOT_KINDS = [
  ["sight",    "mountain",  "blue",   ["볼거리","견학","지형·시설"], ["Sight","Tour","Landform"]],
  ["food",     "hamburger", "amber",  ["먹을거리","식사",""],        ["Food","Meal",""]],
  …
];
// 그 갈래의 고르개에 뜰 것만. 빈 이름은 뺀다.
function tripSpotKinds(purpose){
  const at = Math.max(0, TRIP_PURPOSES.indexOf(purpose));
  return TRIP_SPOT_KINDS.filter(k => k[3][at]);
}
// 고르개를 그릴 때: 지금 값이 이 갈래 목록에 없으면 맨 아래에 그 값을 덧붙인다(버리지 않는다).
```

**규칙 넷**

1. **모르는 값을 버리지 않는다.** 갈래를 바꿔 고르개에서 사라진 값(답사로 바꿨을 때의 '잠자리')도 파일에 그대로 남고 화면에도 그대로 뜬다. 고르개 맨 아래에 그 값 하나를 덧붙여 다시 고를 수 있게 한다.
   - 일기장과 **반대 규칙**이다. `diaryNormalizeSticker` 는 모르는 `art` 이름을 `null` 로 버린다 — 그릴 수 없는 그림이라서다. `kind` 는 **글자로 보여 줄 수 있으므로 버리지 않는다.**
2. **빈 값(`""`)을 허용하고 그게 기본값이다.** 종류를 고르지 않은 장소가 정상이다. 학습지에서 아이가 종류부터 골라야 다음으로 넘어가면 거기서 막힌다.
3. **아이콘은 새로 그리지 않는다.** 열세 개가 모두 `DIARY_ART` 에 있다 → `diaryArtSvg(id)` 를 그대로 부른다.
4. **낱말은 `trip.js` 안에.** "견학"·"측정"·"채집"을 공용 사전에 넣으면 다른 화면의 같은 글자까지 바뀐다(부록 A와 같은 규칙).

### B.5 이 값이 나가는 곳

| 나가는 곳 | 어디에 | 주의 |
|---|---|---|
| `.timeline`(trip) | **'유형' 열**(`timelineTemplateHeaders` 의 `trip ? "유형" : "분류"`) | 자리가 정확히 맞는다. CSV 왕복에 그대로 쓴다 |
| `.map` | `marker.category` | `.map` 에는 `kind` 가 없다. **한 방향으로만** 보낸다 — 글자로 되살리면 언어·사용자 편집에 깨진다 |
| 경비 합계 | 갈래별 소계 | 여행 갈래에서 "먹을거리 12만 원"이 공짜로 나온다 |
| 지도 표시 | 아이콘 + 기본 색 | 색은 사용자가 바꾼 뒤엔 건드리지 않는다 |
