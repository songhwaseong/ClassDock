# ClassDock 인터넷 서비스 인증키 안내

ClassDock은 **인증키 없이도 대부분의 기능이 됩니다.** 몇몇 실시간 기능만 기관이 무료로 주는 인증키가 있어야 합니다. 이 문서에는 **어떤 기능에 어떤 키가 필요한지**, **어디서 어떻게 받는지**를 모았습니다.

최근 추가한 지도 기능의 신청·승인 안내와 충전요금 연동 상태는 **2026-10-09 기준**이며, **TAGO 열차정보 신청·승인 안내는 2026-10-10 확인 기준**입니다. 각 서비스의 최신 승인 방식과 조회 한도는 연결된 공공데이터포털 상세 화면에서 확인하세요.

> **키는 한 사람이 한 개씩 직접 받아야 합니다.** 배포한 ClassDock에는 키가 들어 있지 않습니다. 키마다 하루 조회 한도가 있어서, 여럿이 같은 키를 쓰면 금방 막힙니다. 받은 키는 남에게 넘기지 마세요.

### 키가 전혀 필요 없는 것
- 지도 바탕(OpenStreetMap 타일), 장소 이름 검색(OpenStreetMap), 🚶 로드뷰 창
- 지도 → **KTX·열차**의 KTX 정차역 위치·주소·노선·역 정보 팝업(앱에 포함된 자료). **시간표용 역 검색·시간표 조회에는 키와 활용 승인이 필요합니다.**
- 환율의 ECB 참고환율, 파이썬(내장 Pyodide), 그 밖의 문서 편집 기능 전부

### 알아 둘 점
- 인증키가 필요한 기능은 모두 **ClassDock.exe로 열었을 때만** 됩니다. 이 기능들은 런처(exe)가 인터넷에서 대신 받아 오기 때문입니다. 오프라인 HTML이나 일반 브라우저로 열면 이 버튼들이 흐리게 보입니다.
- 키는 **ClassDock 런처에만** 전달됩니다. 지도 문서·작업공간·HTML에는 저장되지 않습니다. **'이 Windows 사용자 계정에 암호화하여 기억'**을 켜 두면 Windows 계정 암호화로 PC에 남습니다. 끄면 ClassDock을 끌 때 키도 사라집니다.

## 1. 공공데이터포털 인증키 — 교통·날씨·생활 지도

버스·항공·여객선·열차 시간표·날씨·태풍·공휴일·장날·미세먼지·관광·축제·보호구역·주차요금·전기차 충전은 **같은 일반 인증키 하나**를 씁니다. 다만 **활용신청은 서비스마다 따로** 해야 합니다. 신청하지 않은 서비스는 그 조회만 막힙니다.

**새 기능마다 인증키를 새로 발급받거나 ClassDock에 다시 저장할 필요는 없습니다.** 이미 저장한 키에 사용할 서비스의 활용신청과 승인이 연결되어 있으면 됩니다. 개인 키와 프로젝트 키를 함께 쓰는 계정에서는 각 서비스에 선택한 키가 ClassDock에 저장한 키와 같은지 확인하세요.

### 1-1. 회원가입과 인증키 확인
1. [공공데이터포털](https://www.data.go.kr/)에 가입하고 로그인합니다.
2. 아래 표의 서비스를 하나 신청하면 **마이페이지 → 데이터활용 → Open API → 인증키 발급현황**에 **일반 인증키**가 생깁니다.
   - **인코딩 키와 디코딩 키 어느 쪽을 넣어도 됩니다.** ClassDock이 알아서 맞춥니다.

### 1-2. 활용신청할 서비스

아래 서비스는 무료이며 **쓸 기능에 필요한 것만** 신청하면 됩니다. 개발계정 대부분은 자동승인이지만, **경찰청 보호구역은 심의승인**이 필요합니다. 운영계정은 서비스별로 승인 방식이 다르므로 포털 화면을 확인하세요.

이미 **설정 → 연결 → 공공데이터포털**에 저장한 일반 인증키를 그대로 사용합니다. 이 서비스에 **같은 키로 활용신청하고 승인**받았다면 새 인증키를 발급받거나 ClassDock에 다시 저장할 필요가 없습니다. 승인 직후 조회가 거절되면 마이페이지의 승인 상태와 서비스에 연결한 키를 확인하고 잠시 뒤 다시 시도하세요.

역 목록·차량 종류·도시코드·구간 시간표는 **한 서비스 안의 상세기능**입니다. 서비스를 한 번 활용신청할 때 상세기능을 모두 선택하면 되며, 각 기능마다 별도 서비스나 키를 신청하지 않습니다.

- **역 지도·안내:** 앱에 포함된 KTX 정차역 위치·주소·노선을 사용하므로 인증키·활용신청 없이 표시됩니다.
- **시간표용 역 검색·시간표 조회:** 위 서비스의 활용 승인, 기존 공공데이터포털 키, Windows **ClassDock.exe**와 인터넷 연결이 필요합니다.
- 현재 ClassDock은 **운행 시간표**를 표시합니다. 실시간 KTX 위치·지연·잔여 좌석은 제공하지 않으며, 지도에 표시된 모든 역에 특정 열차가 정차하는 것은 아닙니다.

#### 전기차 충전요금과 추가 신청 여부

현재 연결한 충전소 정보 API에는 **충전요금(원/kWh) 항목이 없습니다.** ClassDock의 전기차 충전 상세에서 보여 주는 **주차 무료/유료**는 주차요금 여부이며 충전요금과 다릅니다. 현재 버전은 충전 단가를 표시하거나 요금순으로 비교하지 않습니다.

[무공해차 통합누리집의 공식 충전요금 안내](https://ev.or.kr/nportal/evcarInfo/initEvcarChargePriceV2.do)에는 사업자별 회원가·비회원가·로밍 요금이 공개되어 있습니다. 이 안내 페이지를 보는 데 공공데이터포털 활용신청이나 인증키는 필요하지 않습니다. 다만 ClassDock의 **자동 요금 연동 방식과 별도 공개 요금 API는 아직 확인·적용되지 않았습니다.**

**현재 추가로 활용신청할 요금 API는 안내하지 않습니다.** 이미 승인된 충전소 정보 서비스를 그대로 사용하면 됩니다. 앞으로 별도 API를 사용하게 되면 그 서비스의 인증키·활용신청 조건을 확인해 이 문서를 갱신합니다. 요금 표시를 추가할 때는 회원·비회원·로밍 조건과 갱신일을 함께 표시해야 하며, 현장 할인·멤버십 등에 따라 실제 결제 금액이 달라질 수 있습니다.

### 1-3. 신청하는 법
1. **PC 브라우저(크롬·엣지)에서 로그인한 뒤** 위 표의 링크를 엽니다. 포털은 활용신청을 PC에서만 받습니다. 링크가 앱 안에서 열려 빈 화면이 나오면, 주소를 복사해 일반 브라우저 창에 붙여 넣으세요. 포털 검색창에 서비스 이름을 쳐서 찾아 들어가도 됩니다.
2. **[활용신청]** 버튼을 누릅니다.
3. **활용목적**은 "수업용 지도에 교통·생활 정보 표시"처럼 짧게 적습니다. **상세기능**은 전부 체크합니다.
4. 서비스키를 고르는 칸(개인·프로젝트)이 나오면 **ClassDock에 넣을 그 키**가 붙는 쪽을 고릅니다. 서비스마다 다른 키에 신청하면 일부 조회가 계속 거절됩니다.
5. **승인 상태**를 확인합니다. 자동승인 서비스는 신청 후 승인이 처리되지만, **경찰청 보호구역은 심의승인을 기다려야** 합니다. 승인 직후에도 API 서버 반영까지 시간이 걸릴 수 있으므로 바로 조회되지 않으면 잠시 뒤 다시 확인합니다. 반영 시간은 서비스별로 다릅니다.
6. ClassDock → ⚙ 설정 → 연결 → **공공데이터포털**에 키를 넣고 **키 저장**을 누릅니다.

> 키 저장은 형식만 확인합니다. 정상 키라도 활용신청하지 않은 서비스는 그 기능을 열 때 거절되며, ClassDock이 필요한 서비스 이름을 안내합니다.

> 포털의 상세기능 이름은 `getBusRouteList`처럼 끝에 `List`·`Item`이 붙은 것도 있습니다. 포털에서 부르는 이름일 뿐이니 신경 쓰지 않아도 됩니다.

### 1-4. 하루 한도
개발계정은 **서비스마다 하루 조회 한도**가 있습니다. 2026-10-09 포털 안내 기준으로 관광·전기차 충전소 정보는 각각 하루 **1,000회**, 보호구역은 **300회**, 전국주차장정보표준데이터는 **10,000회**입니다. 다른 서비스의 한도와 계정별 적용 한도는 상세 화면·마이페이지에서 확인하세요. 여러 페이지를 받는 조회는 페이지마다 호출 횟수를 씁니다.

**TAGO 열차정보**는 [2026-10-10 공공데이터포털 안내](https://www.data.go.kr/data/15098552/openapi.do) 기준 개발계정 **하루 10,000회**입니다. 처음 받는 전국 역 목록도 도시·페이지별 호출 횟수에 포함되며, 실제 계정의 적용 한도는 마이페이지에서 확인하세요.

ClassDock은 같은 자료를 일정 시간 재사용하고, 지도 이동이나 반경·커넥터 필터 변경으로는 API를 다시 부르지 않습니다. 버스는 보고 있는 노선 하나를 30초마다 조회하고, 전기차 충전은 **창이 열려 있을 때만 1분 자동 갱신**합니다. 충전 창을 닫거나 표시를 지우면 자동 갱신이 멈추며 인증키·일일 한도 오류에서도 자동 갱신을 끕니다. 한도를 다 쓰면 서비스의 초기화 시점까지 기다려야 하며, 더 필요하면 포털의 운영계정·트래픽 증설 안내를 확인합니다.

   - ⚠ **'일반 인증키'가 아닙니다.** 두 키는 쓰는 서버가 달라서(일반=openapi, 실시간 지하철=swopenapi), 일반 키를 넣으면 실시간 열차가 되지 않습니다.
3. 받은 키를 ClassDock → ⚙ 설정 → 연결 → **지하철 실시간**에 넣고 **키 저장·연결 시험**을 누릅니다.

하루 한도는 1,000회입니다. ClassDock은 한 번에 한 노선만 15초마다 물어서, 40분 수업 내내 켜 두어도 160회쯤 씁니다.

### 2-1. 서울 열린데이터광장 일반 인증키 — 돌발·통제

1. 같은 **[인증키 신청](https://data.seoul.go.kr/together/mypage/actkeyMain.do)** 화면에서 이번에는 **'일반 인증키 신청'**을 고릅니다. 신청하면 바로 나옵니다.

   - ⚠ 실시간 지하철 인증키를 넣으면 연결 시험에서 "일반 인증키인지 확인해 주세요"가 나옵니다. 두 키는 따로 받아야 합니다.

돌발정보는 서울 전체 목록을 한 번에 받으며, 켜 둔 동안 5분마다 새로 받습니다(런처가 3분 묶어 두어 화면이 여럿이어도 호출이 늘지 않습니다).

## 3. 카카오 REST API 키 — 지도 검색·주변 시설·길찾기

1. [Kakao Developers](https://developers.kakao.com/)에 카카오 계정으로 로그인합니다. **내 애플리케이션 → 애플리케이션 추가하기**로 앱을 하나 만듭니다. 이름은 아무거나 괜찮습니다.
2. 만든 앱의 **앱 키**에서 **REST API 키**를 복사합니다.
   - ⚠ **Admin 키는 절대 넣지 마세요.** ClassDock은 REST API 키만 씁니다.
3. 같은 앱 설정의 **카카오맵 → 사용 설정**에서 상태를 **ON**으로 바꿉니다.
   - 2024년 12월부터 새로 만든 앱은 이걸 켜야 합니다. 안 켜면 연결 시험에서 403 오류(`OPEN_MAP_AND_LOCAL`)가 납니다.
4. ClassDock → ⚙ 설정 → 연결 → **지도 검색**에서 공급자를 **카카오 — 개인 API 키**로 바꿉니다. 키를 넣고 **키 저장·연결 시험**을 누릅니다.

이 키 하나로 되는 것:
- 국내 상세주소·건물 이름 검색, 🏫 주변 시설(반경 검색), 주소 CSV로 좌표 채우기, 주소 자동 채우기
- 🚗 자동차 길찾기(경유지·출발 시각·여러 곳 비교 포함). 카카오모빌리티 길찾기 API도 **같은 REST 키**로 됩니다. 장소 검색과 따로 하루 무료 몫이 있습니다.

## 4. KOSIS 공유서비스 인증키 — 🎨 색칠 지도 통계 가져오기

1. [KOSIS 공유서비스](https://kosis.kr/openapi/)에 가입하고 로그인합니다.
2. **활용신청**을 하면 자동 승인됩니다. 키는 **마이페이지 → 인증키 확인**에 있습니다(회원 한 명에 키 하나, 모든 통계에 씀).
   - ⚠ 키 끝에 `=` 가 붙어 있는 경우가 많습니다. **통째로** 복사하세요.
3. ClassDock → ⚙ 설정 → 연결 → **KOSIS 국가통계**에 넣고 **키 저장·연결 시험**을 누릅니다.

쓰는 법: 지도 → 🎨 **색칠 지도** → **KOSIS에서 가져오기** → 통계와 해를 고르고 **가져오기** → **칠하기**.
시도·시군구 이름은 앱이 알아서 맞춥니다. 받은 값은 붙여넣기 칸에 표로 들어가므로 칠하기 전에 고칠 수도 있습니다.

## 5. NEIS 교육정보 개방 포털 인증키 — 🎓 일기장 '우리 학교'

1. [나이스 교육정보 개방 포털](https://open.neis.go.kr/)에 가입하고 로그인합니다.
2. **마이페이지 → 인증키 신청**에서 키를 받습니다. 키 하나로 학교 정보·급식·학사일정·시간표를 모두 씁니다.
3. ClassDock → ⚙ 설정 → 연결 → **NEIS 교육정보**에 넣고 **키 저장·연결 시험**을 누릅니다.

쓰는 법: 일기장 도구막대의 🎓 **우리 학교** → 학교 이름 일부로 찾기(예: "가락초") → 고르기 → (시간표를 보려면) 학년·반.
- 달력에 학사일정이 밑줄로, 휴업일이 빨간 날로 표시됩니다(매주 오는 토요휴업일은 뺍니다).
- 날짜 아래 줄에 그날 **급식**·**일정**·**시간표**가 나오고, **일기에 넣기**로 급식 메뉴를 본문 끝에 한 줄로 넣습니다.
- 고른 학교는 이 PC 브라우저에만 기억되고 일기장 파일에는 담기지 않습니다.
- 키가 없어도 한 번에 5줄까지는 보입니다(그때는 "일부만 보여요"라고 알립니다).

## 6. 한국수출입은행 환율 API 인증키 — 💱 고시환율 (선택)

키가 없어도 **ECB 참고환율**로 환율 창은 바로 됩니다. 은행 **고시환율**(매매기준율·송금 보낼 때·받을 때)까지 보고 싶을 때만 받으세요.

1. [한국수출입은행 오픈 API](https://www.koreaexim.go.kr/ir/HPHKIR020M01?apino=2&viewtype=C) 페이지의 **인증키 발급** 탭에서 본인 인증을 합니다. 발급신청서를 내면 바로 발급됩니다.
2. ClassDock → ⚙ 설정 → 연결 → **환율**에 넣고 **키 저장·연결 시험**을 누릅니다.

하루 한도는 1,000회입니다. 고시환율은 영업일 오전 11시 무렵에 바뀝니다.

## 7. 한국도로공사 고속도로 공공데이터 인증키 — 지도 휴게소

공공데이터포털(data.go.kr)에도 '한국도로공사_주유소별 가격' 같은 자료가 보이지만 **'LINK' 형**이라 거기서는 활용신청이 되지 않습니다. 키는 도로공사 사이트에서 따로 받습니다.

1. [고속도로 공공데이터 포털](https://data.ex.co.kr/)에 회원 가입하고 로그인한 뒤 오픈API 메뉴에서 **인증키**를 신청합니다. 키는 숫자 10자리였습니다(2026-10-10).
2. 받은 키를 ClassDock → ⚙ 설정 → 연결 → **한국도로공사(고속도로)**에 넣고 **키 저장·연결 시험**을 누릅니다.

ClassDock은 휴게소 위치(약 200곳)·편의시설 목록을 이레 기억하고, 주유 가격은 켜 둔 동안 30분마다, 대표 음식·테마는 휴게소를 누를 때 한 곳씩 받습니다. 도로공사 위치 목록에 없는 새 휴게소 42곳은 카카오 장소 검색으로 찾은 좌표를 앱에 넣어 두었고, 그 뒤에 생긴 휴게소는 **카카오 REST API 키**(3번)가 있으면 그 자리에서 찾아 봅니다.
