# ClassDock 인터넷 서비스 인증키 안내

ClassDock은 **인증키 없이도 대부분의 기능이 됩니다.** 몇몇 실시간 기능만 기관이 무료로 주는 인증키가 있어야 합니다. 이 문서에는 **어떤 기능에 어떤 키가 필요한지**, **어디서 어떻게 받는지**를 모았습니다.

> **키는 한 사람이 한 개씩 직접 받아야 합니다.** 배포한 ClassDock에는 키가 들어 있지 않습니다. 키마다 하루 조회 한도가 있어서, 여럿이 같은 키를 쓰면 금방 막힙니다. 받은 키는 남에게 넘기지 마세요.

---

## 한눈에 보기

| 기능 (어디서 쓰나) | 필요한 키 | 받는 곳 | 키가 없으면 |
|---|---|---|---|
| 지도 → 🚌 **버스** (전국 도시) | 공공데이터포털 일반 인증키 + **TAGO 4종** 활용신청 | [공공데이터포털](https://www.data.go.kr/) | 버스 버튼이 설정 안내만 보여 줌 |
| 지도 → 🚌 **버스** → 서울특별시 | 위와 **같은 키** + **서울시 버스 4종** 활용신청 | [공공데이터포털](https://www.data.go.kr/) | 서울만 안 됨 (다른 도시는 됨) |
| 지도 → ✈ **항공 운항** | 위와 **같은 키** + **한국공항공사 실시간 항공기 운항정보** 활용신청 | [공공데이터포털](https://www.data.go.kr/) | 항공편을 조회하지 못함 |
| 지도 → ⛴ **여객선** | 위와 **같은 키** + **TAGO 국내선박운항정보** 활용신청 | [공공데이터포털](https://www.data.go.kr/) | 여객선 시간표를 조회하지 못함 |
| 지도 → 🚇 **실시간 열차** (서울 지하철) | 서울 열린데이터광장 **실시간 지하철 인증키** | [서울 열린데이터광장](https://data.seoul.go.kr/together/mypage/actkeyMain.do) | 실시간 열차를 못 씀 |
| 지도 → **장소 검색**을 카카오로 · 🏫 주변 시설 · 🚗 길찾기 | 카카오 **REST API 키** (+ 카카오맵 사용 설정) | [Kakao Developers](https://developers.kakao.com/console/app) | OpenStreetMap 검색으로 대신함 · 주변 시설·길찾기 버튼은 흐리게 보임 |
| 💱 **환율** → 고시환율 | 한국수출입은행 **환율 API 인증키** | [수출입은행 오픈 API](https://www.koreaexim.go.kr/ir/HPHKIR020M01?apino=2&viewtype=C) | ECB 참고환율로 바로 씀 |

**키를 넣는 곳은 모두 같습니다: 앱 오른쪽 위 ⚙ 설정 → 연결 탭.** 공공데이터포털 키는 **공공데이터포털 → 키 저장**, 나머지는 각 항목의 **키 저장·연결 시험**을 누릅니다.

### 키가 전혀 필요 없는 것
- 지도 바탕(OpenStreetMap 타일), 장소 이름 검색(OpenStreetMap), 🚶 로드뷰 창
- 환율의 ECB 참고환율, 파이썬(내장 Pyodide), 그 밖의 문서 편집 기능 전부

### 알아 둘 점
- 인증키가 필요한 기능은 모두 **ClassDock.exe로 열었을 때만** 됩니다. 이 기능들은 런처(exe)가 인터넷에서 대신 받아 오기 때문입니다. 오프라인 HTML이나 일반 브라우저로 열면 이 버튼들이 흐리게 보입니다.
- 키는 **ClassDock 런처에만** 전달됩니다. 지도 문서·작업공간·HTML에는 저장되지 않습니다. **'이 Windows 사용자 계정에 암호화하여 기억'**을 켜 두면 Windows 계정 암호화로 PC에 남습니다. 끄면 ClassDock을 끌 때 키도 사라집니다.

## 1. 공공데이터포털 인증키 — 🚌 버스 · ✈ 항공 · ⛴ 여객선

버스·항공·여객선은 **같은 일반 인증키 하나**를 씁니다. 다만 **활용신청은 서비스마다 따로** 해야 합니다. 신청하지 않은 서비스는 그 조회만 막힙니다.

### 1-1. 회원가입과 인증키 확인
1. [공공데이터포털](https://www.data.go.kr/)에 가입하고 로그인합니다.
2. 아래 표의 서비스를 하나 신청하면 **마이페이지 → 데이터활용 → Open API → 인증키 발급현황**에 **일반 인증키**가 생깁니다.
   - **인코딩 키와 디코딩 키 어느 쪽을 넣어도 됩니다.** ClassDock이 알아서 맞춥니다.

### 1-2. 활용신청할 서비스 (모두 무료·자동승인)

**전국 도시(TAGO)** — 서울을 뺀 전국 도시입니다.

| 서비스 이름 | 있으면 되는 것 | 필수? |
|---|---|---|
| [국토교통부_(TAGO)_버스노선정보](https://www.data.go.kr/data/15098529/openapi.do) | 도시 목록, 노선 번호 검색, 노선의 정류장, 노선 목록 최신화 | **필수** |
| [국토교통부_(TAGO)_버스위치정보](https://www.data.go.kr/data/15098533/openapi.do) | 지도 위 버스 실시간 위치 | **필수** |
| [국토교통부_(TAGO)_버스도착정보](https://www.data.go.kr/data/15098530/openapi.do) | 정류장을 눌렀을 때 도착 예정 | 선택 |
| [국토교통부_(TAGO)_버스정류소정보](https://www.data.go.kr/data/15098534/openapi.do) | 📍 지도 가운데 근처 정류장 | 선택 |

**서울특별시** — TAGO에는 서울이 없어서 서울시 서비스를 따로 신청해야 합니다.

| 서비스 이름 | 있으면 되는 것 | 필수? |
|---|---|---|
| [서울특별시_노선정보조회 서비스](https://www.data.go.kr/data/15000193/openapi.do) | 서울 노선 번호 검색, 노선의 정류장, 노선 목록 최신화 | 서울을 쓰려면 **필수** |
| [서울특별시_버스위치정보조회 서비스](https://www.data.go.kr/data/15000332/openapi.do) | 서울 버스 실시간 위치 | 서울을 쓰려면 **필수** |
| [서울특별시_정류소정보조회 서비스](https://www.data.go.kr/data/15000303/openapi.do) | 서울 정류장 도착 예정, 근처 정류장 | 선택 |
| [서울특별시_버스도착정보조회 서비스](https://www.data.go.kr/data/15000314/openapi.do) | (지금은 쓰지 않음. 앞으로를 위해 신청해 두어도 됨) | 선택 |

**항공·여객선** — 쓸 기능만 신청하면 됩니다.

| 서비스 이름 | 있으면 되는 것 | 필수? |
|---|---|---|
| [한국공항공사_실시간 항공기 운항정보 검색·조회](https://www.data.go.kr/data/15158625/openapi.do) | 공항 출발·도착 게시판, 편명 검색 | 항공 운항을 쓰려면 **필수** |
| [국토교통부_(TAGO)_국내선박운항정보](https://www.data.go.kr/data/15098523/openapi.do) | 항구 목록, 날짜별 여객선 시간표 | 여객선을 쓰려면 **필수** |

### 1-3. 신청하는 법
1. **PC 브라우저(크롬·엣지)에서 로그인한 뒤** 위 표의 링크를 엽니다. 포털은 활용신청을 PC에서만 받습니다. 링크가 앱 안에서 열려 빈 화면이 나오면, 주소를 복사해 일반 브라우저 창에 붙여 넣으세요. 포털 검색창에 서비스 이름을 쳐서 찾아 들어가도 됩니다.
2. **[활용신청]** 버튼을 누릅니다.
3. **활용목적**은 "수업용 지도에 교통 정보 표시"처럼 짧게 적습니다. **상세기능**은 전부 체크합니다.
4. 서비스키를 고르는 칸(개인·프로젝트)이 나오면 **ClassDock에 넣을 그 키**가 붙는 쪽을 고릅니다. 서비스마다 다른 키에 신청하면 일부 조회가 계속 거절됩니다.
5. 자동승인이라 바로 승인됩니다. 다만 **실제로 쓰일 때까지 1~2시간쯤** 걸릴 수 있습니다.
6. ClassDock → ⚙ 설정 → 연결 → **공공데이터포털**에 키를 넣고 **키 저장**을 누릅니다.

> 키 저장은 형식만 확인합니다. 정상 키라도 활용신청하지 않은 서비스는 그 기능을 열 때 거절되며, ClassDock이 필요한 서비스 이름을 안내합니다.

> 포털의 상세기능 이름은 `getBusRouteList`처럼 끝에 `List`·`Item`이 붙은 것도 있습니다. 포털에서 부르는 이름일 뿐이니 신경 쓰지 않아도 됩니다.

### 1-4. 하루 한도
개발계정은 **서비스마다 하루 조회 한도**가 있습니다(서울시 서비스는 하루 1,000회). ClassDock은 보고 있는 노선 하나만 30초마다 묻고, 다른 탭을 보는 동안에는 묻지 않습니다. 한도를 다 쓰면 다음 날 풀립니다. 더 필요하면 포털에서 **활용사례를 등록하고 운영계정**으로 올릴 수 있습니다.

## 2. 서울 열린데이터광장 — 🚇 실시간 열차

1. [서울 열린데이터광장](https://data.seoul.go.kr/)에 가입하고 로그인합니다.
2. **[인증키 신청](https://data.seoul.go.kr/together/mypage/actkeyMain.do)**에서 **'실시간 지하철 인증키 신청'**을 고릅니다.
   - ⚠ **'일반 인증키'가 아닙니다.** 두 키는 쓰는 서버가 달라서(일반=openapi, 실시간 지하철=swopenapi), 일반 키를 넣으면 실시간 열차가 되지 않습니다.
3. 받은 키를 ClassDock → ⚙ 설정 → 연결 → **지하철 실시간**에 넣고 **키 저장·연결 시험**을 누릅니다.

하루 한도는 1,000회입니다. ClassDock은 한 번에 한 노선만 15초마다 물어서, 40분 수업 내내 켜 두어도 160회쯤 씁니다.

## 3. 카카오 REST API 키 — 지도 검색·주변 시설·길찾기

1. [Kakao Developers](https://developers.kakao.com/)에 카카오 계정으로 로그인합니다. **내 애플리케이션 → 애플리케이션 추가하기**로 앱을 하나 만듭니다. 이름은 아무거나 괜찮습니다.
2. 만든 앱의 **앱 키**에서 **REST API 키**를 복사합니다.
   - ⚠ **Admin 키는 절대 넣지 마세요.** ClassDock은 REST API 키만 씁니다.
3. 같은 앱 설정의 **카카오맵 → 사용 설정**에서 상태를 **ON**으로 바꿉니다.
   - 2024년 12월부터 새로 만든 앱은 이걸 켜야 합니다. 안 켜면 연결 시험에서 403 오류(`OPEN_MAP_AND_LOCAL`)가 납니다.
4. ClassDock → ⚙ 설정 → 연결 → **지도 검색**에서 공급자를 **카카오 — 개인 API 키**로 바꿉니다. 키를 넣고 **키 저장·연결 시험**을 누릅니다.

이 키 하나로 되는 것:
- 국내 상세주소·건물 이름 검색, 🏫 주변 시설(반경 검색), 주소 CSV로 좌표 채우기, 주소 자동 채우기
- 🚗 자동차 길찾기(경유지·출발 시각·여러 곳 비교 포함). 카카오모빌리티 길찾기 API도 **같은 REST 키**로 됩니다. 장소 검색과 따로 하루 무료 몫이 있습니다.

## 4. 한국수출입은행 환율 API 인증키 — 💱 고시환율 (선택)

키가 없어도 **ECB 참고환율**로 환율 창은 바로 됩니다. 은행 **고시환율**(매매기준율·송금 보낼 때·받을 때)까지 보고 싶을 때만 받으세요.

1. [한국수출입은행 오픈 API](https://www.koreaexim.go.kr/ir/HPHKIR020M01?apino=2&viewtype=C) 페이지의 **인증키 발급** 탭에서 본인 인증을 합니다. 발급신청서를 내면 바로 발급됩니다.
2. ClassDock → ⚙ 설정 → 연결 → **환율**에 넣고 **키 저장·연결 시험**을 누릅니다.

하루 한도는 1,000회입니다. 고시환율은 영업일 오전 11시 무렵에 바뀝니다.

## 문제 해결

| 이렇게 나오면 | 까닭 | 할 일 |
|---|---|---|
| 버스: "인증키가 … 쓰일 수 없어요. '서울특별시_○○ 서비스' 활용신청을 확인해 주세요" | 그 서비스를 신청하지 않았거나, 승인 뒤 아직 반영되지 않음 | 안내에 적힌 서비스를 신청하고 1~2시간 기다림 |
| 버스: 전국 도시는 되는데 서울만 안 됨 | 서울시 서비스는 TAGO와 신청이 따로임 | 1-2의 서울 표 신청 |
| 버스: 위치는 되는데 정류장 도착·근처 정류장만 안 됨 | 도착정보·정류소정보를 신청하지 않음 | 1-2 표의 '선택' 서비스 신청 |
| 항공 또는 여객선만 안 됨 | 그 기능의 서비스를 따로 활용신청하지 않음 | 1-2의 항공·여객선 표에서 해당 서비스 신청 |
| "오늘 조회 한도를 다 썼어요" | 하루 한도 초과 | 다음 날 다시. 자주 막히면 운영계정 신청 |
| 실시간 열차가 안 됨 | 일반 인증키를 넣음 | **실시간 지하철 인증키**를 따로 받아 넣기 |
| 카카오 연결 시험 403 | 카카오맵 사용 설정이 꺼짐 | 3번의 3단계(사용 설정 ON) |
| 버튼이 흐리고 "ClassDock EXE에서…"라고 나옴 | 오프라인 HTML이나 브라우저로 엶 | ClassDock.exe로 다시 열기 |
