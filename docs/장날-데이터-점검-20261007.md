# 지도 장날 데이터 점검 — 2026-10-07

## 점검 범위와 결과

ClassDock이 사용하는 [전국전통시장표준데이터](https://www.data.go.kr/data/15012894/standard.do) API를 기존 런처 함수로 조회했다. 첫 페이지 1,000곳과 두 번째 페이지 393곳을 모두 검사했다. 인증키는 보고서·시험 자료에 저장하지 않았다.

- API 전체 1,393곳 중 날짜형 장날이 있는 시장은 411곳이다.
- 모든 시장개설주기 값은 현재 파서가 처리할 수 있었다. 장날 문자열 해석 실패는 0곳이다.
- 좌표가 없어 지도에 표시되지 않는 시장은 16곳이며, 이 중 9곳은 정기 장날이 있다.
- 지자체 공식 안내와 경기도의 장터 20곳을 대조했다. 김포의 4개 5일장은 API에 없으며, 일산시장은 장날 정보가 빠져 있다.
- 파주 안내의 추가 누락 후보 3곳과 광탄 장날의 자료 충돌도 발견했다.

**전국 모든 실제 5일장에 대한 전수 대조 결과는 아니다.** 전국 API 전체의 데이터 상태를 검사하고, 아래 공식 안내에 있는 20곳을 개별 대조한 결과다. 등록된 전통시장 목록만으로 실제 운영되는 모든 민속 장터를 포괄할 수는 없다.
