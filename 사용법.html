1. 이 프로그램이 뭐예요? ↑ 목차

여러 형식의 파일(PDF·Word·Excel·PowerPoint·이미지·Python 등)을 하나의 창에서 보고 편집하는 오프라인 도구입니다.

  • PDF에 서명·텍스트·필기를 올려 다른 PDF로 저장
  • Excel/CSV 표 보기·편집·통계
  • Python 코드 작성·실행·자동채점 (브라우저 안에서도 동작)
  • 참고 문서 + 작업 문서를 나란히 펴 놓고 공부하고, 필요할 때 참고 문서만 잠금 (분할 작업)
  • 화이트보드(설명용 칠판) 와 PDF·코드 위 필기
  • 수업 리플레이 — 화이트보드·PDF 필기·Python 코드와 실행 결과를 녹화해 되감아 재생(.lesson)
  • 과제 패키지 — 문제·시작 코드·자동채점을 한 파일(.task)로 배포하고 제출본(.taskdone)을 걷어 재채점·성적 CSV
  • 시험지 — 객관식·주관식·이미지 문항을 .exam 한 파일로 배포하고, 학생이 이름·서명해 낸 제출본(.examdone)을 선생님만 열어 일괄 채점·성적 CSV
  • 블록 문서 — 글·표·이미지를 한 문서에 섞어 쓰는 노션형 문서(.mnote)
  • 악보 — 두 성부·가사·표현·반복을 넣고 바로 듣는 악보(.msheet), 조옮김, MusicXML 가져오기·내보내기, MIDI 건반 입력·MIDI/WAV 저장과 참고 이미지 나란히 보기
  • 지도 — 배경지도 위에 표시를 찍어 이름·메모를 붙이는 수업용 지도(.map), 그대로 칠판으로 보내 판서하거나 메모로 보내 나중에 다시 지도로 열기, 런처에서 실제로 본 지역은 자동 보관해 다시 오프라인으로
  • 파일 비교·여러 파일 찾아 바꾸기 — 두 파일의 달라진 곳을 나란히 보고, 열린 파일들(Word 본문 포함)을 한꺼번에 치환

기능이 어디 있는지 모를 땐 Ctrl+K(명령 팔레트) 에 하고 싶은 일을 한국어로 적어 보세요. 지금 화면에서 쓸 수 있는 기능만 추려 보여 주고 바로 실행합니다.

파일은 외부 서버로 올라가지 않습니다. 내 PC 안에서만 처리합니다.

2. 내 PC에 받기 — 두 가지 방법 ↑ 목차

방법 A. Git으로 클론 (개발자·소스 수정할 사람)

  1. Git이 설치돼 있는지 확인 — 명령 프롬프트(cmd)나 PowerShell에서 git --version 입력. 없으면 git-scm.com에서 설치.
  2. 원하는 폴더에서 클론: 
    git clone https://github.com/songhwaseong/myOffice.git
cd myOffice

방법 B. ZIP으로 다운로드 (그냥 쓰고만 싶은 사람)

  1. GitHub 저장소(https://github.com/songhwaseong/myOffice) 접속
  2. 초록색 Code 버튼 → Download ZIP
  3. 받은 ZIP을 원하는 폴더에 압축 해제

이 단계만 끝나면 사용은 가능합니다. 다음 섹션에서 실행 방법을 고르세요.

3. 실행하기 — 세 가지 방법 중 고르기 ↑ 목차

받은 폴더 안에 세 가지 실행 방법이 들어 있습니다. 상황에 맞게 하나만 고르면 됩니다.

방법누가 쓰면 좋아요?더블클릭할 파일
① EXE가장 추천. 자동 복원·로컬 Python·정확한 PPT 변환 등 모든 기능 사용ClassDock.exe
② 오프라인 HTMLUSB로 들고 다니거나 다른 PC에 파일 하나만 주고 싶을 때classdock-offline.html
③ 온라인 HTML개발자가 소스 수정하며 바로 확인할 때classdock.html

① EXE 실행 (가장 추천)

  1. ClassDock.exe 더블클릭
  2. 처음 실행 시 Windows SmartScreen 경고가 뜰 수 있어요 (서명되지 않은 빌드라서). 다음처럼 진행:
    • "Windows의 PC 보호" 창에서 추가 정보 → 실행 클릭
  3. 콘솔창 없이 로컬 서버가 뜨고 기본 브라우저가 자동으로 열립니다.
  4. 끝낼 때는 브라우저 탭만 닫지 말고 트레이/작업관리자에서 ClassDock.exe도 종료하세요. 또는 desktop/stop-server.cmd를 실행.

EXE를 매번 누르기 귀찮으면 §6 매번 EXE 누르기 귀찮을 때 참고.

② 오프라인 HTML 실행

  1. classdock-offline.html 더블클릭 → 기본 브라우저에서 바로 열림
  2. 인터넷이 없어도 PDF·문서 보기·편집은 그대로 동작
  3. 단, Python을 처음 실행할 때는 인터넷이 필요합니다 (Pyodide 런타임 다운로드)

③ 온라인 HTML 실행

  1. 인터넷 연결 상태에서 classdock.html 더블클릭
  2. 라이브러리를 CDN에서 받아오므로 첫 실행은 반드시 인터넷 필요

4. 첫 사용 — 파일 열어 보기 ↑ 목차

처음 열면 파일 열기 → 파이썬 실행 → 저장 3단계를 알려 주는 환영 창이 한 번 뜹니다. ✨ 파이썬 예제로 시작을 누르면 곧장 예제 갤러리가 열려요. 나중에 다시 보려면 헤더 ? → 처음 사용 안내 보기.

파일 열기 (3가지 방법)

  1. 드래그 앤 드롭 — 탐색기에서 파일을 화면으로 끌어다 놓기 (가장 빠름)
  2. 사이드바 하단 [열기] 버튼 → 파일 추가 또는 폴더 열기
  3. Ctrl+O (파일 열기) / Ctrl+Shift+O (폴더 열기)

⚠ 꼭 알아두세요 — 폴더를 여는 방식과 브라우저 권한에 따라 저장 위치가 달라집니다.

  • 사이드바의 열기 → 폴더 열기 또는 Ctrl+Shift+O로 폴더를 열고 쓰기 권한을 허용하면 편집한 파일을 선택한 폴더의 원본에 바로 저장합니다.
  • Chrome·Edge에서는 탐색기에서 폴더를 화면으로 드래그해도 폴더 쓰기 핸들을 받아 원본에 저장합니다. Firefox·Safari처럼 드롭한 폴더의 쓰기 핸들을 제공하지 않는 환경에서는 EXE가 설정 → 일반 → 자동 저장 폴더에, 일반 HTML이 다운로드 사본으로 저장하며 드래그한 원본은 변경하지 않습니다.
  • 화면 위 파일명 옆의 원본 저장/사본 저장 배지에서 현재 저장 대상을 확인할 수 있습니다. 배지에 마우스를 올리면 원본·자동 저장 폴더·다운로드 중 실제 동선을 설명합니다.

여러 파일을 한 번에

  • 폴더째 드래그하거나 ZIP을 열면 안의 파일들이 사이드바에 정리됨
  • 폴더·ZIP을 처음 열면 아무 문서도 자동으로 열리지 않고 빈 화면이 뜹니다. 사이드바가 펼쳐진 채로 기다리므로 볼 파일을 직접 고르세요(사진이 수백 장인 폴더에서 엉뚱한 파일이 열리지 않게 하는 기본값입니다). 예전처럼 첫 파일을 바로 보려면 설정 → 일반 → '폴더·압축을 열 때 첫 파일 자동으로 열기' 를 켭니다. 이 설정과 상관없이 최근 작업공간 자동 복원은 보던 탭을 그대로 되살립니다.
  • 사이드바에서 파일 클릭으로 전환
  • 빈 화면의 최근 연 항목을 누르면 보관된 파일·폴더 핸들로 다시 엽니다. 항목의 ×나 목록 지우기는 목록만 지우고 디스크 파일은 그대로 둡니다.
  • 사이드바 파일을 Ctrl+클릭해 개별 추가하거나 Shift+클릭해 범위 선택한 뒤 파일 닫기 또는 삭제를 실행할 수 있습니다. 삭제는 원본 폴더 핸들이 있는 파일만 디스크에서 영구 삭제하며 한 번 더 확인합니다.
  • 사이드바의 통합 검색(Ctrl+Shift+F)은 파일 이름을 즉시 거르고, 잠시 뒤 텍스트·코드 파일의 내용까지 찾아 줍니다(저장하지 않고 편집 중인 내용도 반영). 스캔 PDF는 글자 인식(OCR)을 한 번 돌리면 본문 검색이 됩니다.
  • 최근 검색어: 찾기·검색창은 지난 검색어를 기억합니다. 통합 검색·편집기·PDF·노트북·표·일괄 바꾸기를 각각 다른 목록으로 이 컴퓨터 안에만 12개까지 남기고, 창을 열면 마지막 검색어를 채워 주며 빈 칸에 포커스가 오면 목록을 펼쳐 보여 줍니다. '바꿀 내용'은 기억하지 않습니다. 여러 사람이 함께 쓰는 컴퓨터라면 설정 → 일반에서 끄거나 한 번에 지우세요.

화면 구성

┌─────────────────────────────────────────────┐ │ 헤더 (파일명·메모·설정) │ ├──────────┬──────────────────────────────────┤ │ │ 탭 (열린 파일들) │ │ 사이드바 ├──────────────────────────────────┤ │ 파일통계 │ │ │ 파일 │ 현재 파일 내용 │ │ 목록 │ │ │ │ │ └──────────┴──────────────────────────────────┘
  • 탭은 파일이 하나만 열려 있어도 표시됩니다. 파일을 더 열어도 화면이 위아래로 밀리지 않습니다.
  • 원본에 바로 저장되는지 사본으로 저장되는지는 파일명 옆 원본 저장 / 사본 저장 배지와, 필요할 때 문서 위에 잠깐 겹쳐 뜨는 노란 안내 띠로 알려 줍니다(안내가 떠도 작업 화면 높이는 그대로입니다).

5. 파일 종류별 사용법 ↑ 목차

📄 PDF — 편집·서명·필기

기본 기능

  • 상단 메뉴 편집 → 서명 / 텍스트 / 날짜 / ✓ 체크로 PDF 위에 요소 추가
  • 요소를 드래그해서 이동, 더블클릭해서 텍스트 수정, 모서리로 크기 조절, Delete로 삭제
  • 다운로드 버튼 → 원본이름_signed.pdf로 저장 (원본은 그대로)

페이지 정리

  • 상단 페이지 → 썸네일 보기, 페이지 추출·삭제·순서 변경·90도 회전
  • PDF 합치기 — 현재 PDF 뒤에 다른 PDF 이어붙이기

목차(책갈피) 만들기·편집

  • 상단 페이지 → 목차를 열면 기존 책갈피를 확인하고, 없는 PDF에도 ＋ 현재 페이지로 새 책갈피를 추가
  • 항목을 선택한 뒤 이름 / 삭제 / ↑ / ↓ / ← / →로 이름·순서·상하 계층 편집(더블클릭으로도 이름 변경)
  • 페이지 순서를 바꿔도 책갈피 목적지는 유지되며, 페이지 삭제 시 해당 책갈피는 제거하고 하위 항목은 보존
  • 목차 변경도 자동 복구와 Ctrl+Z/Ctrl+Y에 포함되고 다운로드한 PDF에 실제 책갈피로 저장

필기 모드(✏️ 필기)

  • 펜·형광펜·지우개로 PDF 위에 직접 판서
  • 필기바의 ● 녹화로 필기 과정을 수업 리플레이로 저장 → 교재 위에서 판서가 되살아남(아래 🎬 참고)
  • 필기바 왼쪽 끝 ⋮⋮ 핸들을 끌어 위치 자유 배치, 좌/우 끝으로 가면 자동 세로 모드
  • 🖱 선택 도구를 누르면 그리기 일시 정지 (페이지 클릭/이동 평소처럼)
  • 필기는 자동 저장돼 같은 PDF를 다시 열면 복원, 다운로드한 PDF에 그대로 구워짐

📊 Excel / CSV

  • 셀·행·열·드래그 범위 선택 후 합계·평균·최소·최대·개수 자동 표시
  • Ctrl+C로 TSV 복사 → 다른 표에 붙여넣기
  • 표 위 검색창에서 셀 찾기
  • .xlsx는 셀 편집·필터·정렬·행/열 추가/삭제·시트 추가·복제·이름 변경·순서 변경·서식 보존 저장
  • 수식 입력(=SUM(A1:A3) 등), 함수 자동완성·Σ 자동합계, 채우기 핸들(숫자·요일·월·1반 패턴), 열 폭·행 높이 조절과 병합/병합 해제 지원
  • 글꼴·색·정렬·표시 형식·채우기·테두리·서식 복사, 목록 드롭다운, 조건부 서식(강조·색조·데이터 막대), 선택 범위 차트와 미니 피벗 지원
  • 선택 범위의 📷 선택→메모로 표 일부를 이미지로 만들어 일반 메모에 보관
  • .csv는 큰 파일도 페이지로 나눠 보기, XLSX로 변환 가능

🐍 Python (.py)

기본 흐름

  1. .py 파일을 열거나 사이드바 새로 만들기 → 새 파이썬 코드
  2. 코드 입력 후 ▶ 버튼 또는 Ctrl+Enter로 실행
  3. 결과가 옆/아래 패널에 표시 (Side/Below 버튼으로 위치 토글). 결과 오른쪽 위 접기 아이콘으로 내용은 유지한 채 숨기고, Side/Below를 누르면 다시 표시

예제 갤러리 — 빈 편집기에는 117개 예제 갤러리가 뜹니다. 난이도 필터 칩(⭐ 입문 / ⭐⭐ 기본 / ⭐⭐⭐ 심화 / ⭐⭐⭐⭐ 응용 / ⭐⭐⭐⭐⭐ 도전) 으로 단계별로 추리고, 검색창에서 제목·설명·개념·파일명으로 찾을 수 있습니다. 응용·도전 단계에는 다익스트라·배낭 DP·N-퀸·만델브로·A* 길찾기 같은 심화 예제가 있어요. 예제를 클릭하면 새 코드로 열려 바로 실행됩니다.

노트북 변환

  1. 노트북으로 본문을 누르면 현재 # %% 경계를 기준으로 즉시 새 노트북 탭이 열립니다.
  2. 경계를 직접 정하려면 ▾ → 셀 나누기를 누르고 편집기 왼쪽 줄번호를 클릭해 경계를 넣거나 뺍니다.
  3. 상단 분할 완료를 누르면 변환합니다. 취소하려면 Esc 또는 ▾ → × 셀 나누기 취소를 누르면 진입 전 코드로 복원됩니다.
  4. ▾ → 자동분할은 빈 줄 뒤의 최상위 문장을 기준으로 # %%을 자동 추가하며, 이후 셀 나누기로 세부 조정할 수 있습니다.

터미널

  • EXE: .py 파일의 작업폴더에서 지속형 PowerShell 실행. 터미널을 열 때 한 번만 준비하므로 ls, dir, cd 같은 짧은 명령이 빠르고 작업폴더·PowerShell 변수·환경변수가 다음 명령에도 유지됨. 중지 또는 Ctrl+C로 실행 중인 명령과 자식 프로세스를 함께 종료하며 다음 명령에서 새 세션을 자동 시작
  • EXE의 열기 → 폴더 열기는 Windows에서 선택한 실제 절대경로를 기억하므로, 자동 저장 폴더 위치와 관계없이 터미널이 원본 .py가 있는 폴더에서 시작합니다. 탐색기에서 화면으로 드래그한 폴더는 브라우저 보안상 절대경로를 알 수 없으므로 실제 경로가 필요한 경우 폴더 열기를 사용하세요.
  • 브라우저: 운영체제 명령 대신 Python 문장·식을 실행. 변수와 import 상태는 이어지며 초기화로 모두 지울 수 있음
  • 실행 중 표시: 명령이 도는 동안 터미널 버튼 왼쪽에 초록 점이 깜빡입니다. 터미널을 닫아도 명령은 계속 돌기 때문에(서버를 띄워 둔 경우 등) 이 점으로 알 수 있고, 다시 열어 중지나 Ctrl+C로 끝냅니다. 터미널이 닫혀 있는 동안에는 Ctrl+C가 평소대로 복사로 동작합니다
  • 여러 파일이 터미널 하나를 함께 사용: 어느 .py에서 열어도 같은 터미널·같은 세션이라 변수·환경변수·명령 기록이 파일을 옮겨도 이어집니다. 다른 파일에서 열면 작업 폴더만 그 파일 폴더로 자동으로 옮기고(작업 폴더를 …로 옮겼습니다 안내), 같은 파일에서 다시 열 때는 직접 cd한 폴더를 그대로 둡니다. 파이썬 파일을 모두 닫으면 세션이 정리됩니다
  • Enter는 실행, Shift+Enter는 여러 줄 입력, ↑/↓는 명령 기록 이동
  • EXE 경로 자동완성: 경로 일부를 입력하고 Tab을 누르면 일치 후보들의 공통 이름까지 먼저 채우며, 다시 누르면 다음 후보로 이동합니다. Shift+Tab은 이전 후보로 이동합니다. cd·Set-Location에서는 폴더만 찾고 공백이 있는 경로는 자동으로 따옴표 처리
  • 로컬 명령은 PC에서 직접 실행되므로 신뢰할 수 있는 명령만 사용

  • 측정(눈금 버튼) — 도형을 고르고 누르면 길이·각도·넓이가 붙습니다. 직선은 길이(cm), 사각형은 가로 × 세로 = 넓이, 원은 반지름과 넓이, 다각형은 넓이, 꺾인 점이 하나뿐인 선은 그 자리의 각도를 잽니다. 붙인 값은 도형이 바뀌면 따라 바뀌고(끌어 크기를 바꾸거나 닮음 변환을 하면 즉시 갱신), 라벨을 끌어 원하는 자리에 두면 그 위치를 지킵니다. 한 번 더 누르면 뗍니다
  • 변환(변환 버튼) — 고른 도형을 선대칭·점대칭·회전·평행이동·닮음으로 바꿉니다. 기준점은 도형의 중심이 기본이고 기준점 찍기로 보드의 아무 자리나 지정할 수 있으며(빨간 ✛ 로 표시), 선대칭 축은 세로축·가로축·자 모서리 중에서 고릅니다. 원본 남기고 사본 만들기를 켜 두면 원본과 나란히 놓여 대응점을 비교할 수 있고, 끄면 그 도형이 바뀝니다(붙여 둔 측정값도 함께 따라갑니다). 글자는 읽을 수 있도록 눕히지 않습니다
  • 화학 탭 — 주기율표(118개 원소)를 족·주기 배치 그대로 보여 주고, 누르면 번호·기호·이름·원자량이 담긴 원소 카드가 들어갑니다. 이름·기호·번호(예: 산소, Na, 26)로 검색할 수 있습니다. 위쪽 칸에 CH4 + O2 -> CO2 + H2O 처럼 적으면 계수를 맞춰(CH₄ + 2O₂ → CO₂ + 2H₂O) 보드에 넣어 줍니다. Ca(OH)2 처럼 괄호가 있어도 되고, 맞출 수 없는 식은 이유를 알려 줍니다
    • 몰 계산(화학량론) — 계수가 맞으면 아래에 계산 줄이 열립니다. 아는 물질을 고르고 양과 단위(g·mol)를 넣으면 나머지 물질의 몰수·질량이 바로 나오고, 몰 계산표 넣기로 물질·계수·몰질량·몰수·질량 표를 보드에 넣습니다(예: CH4 + O2 -> CO2 + H2O 에서 CH₄ 8g → CO₂ 21.95g). 몰질량은 주기율표의 원자량으로 계산합니다
  • 확률 실험(차트 탭 위쪽) — 동전·주사위·주사위 2개·무작위 수·주머니·스피너를 정한 횟수만큼 실제로 굴려 자료를 만들고 평균·최빈값을 알려 줍니다. 그대로 차트 넣기를 누르면 결과 그래프가 보드에 들어갑니다
    • 주머니·스피너는 구성 칸에 빨강 3, 파랑 2 처럼 적습니다. 주머니는 뽑기 개수를 2 이상으로 두면 한 번에 여러 개를 뽑아 빨강1·파랑1 같은 조합을 세고, 되돌려 넣기를 끄면 비복원 추출이 됩니다(파랑이 2개뿐이면 파랑3은 나오지 않습니다). 스피너는 적은 수만큼 넓이(확률) 가 커집니다
    • 누적 그래프를 누르면 방금 한 실험을 다시 굴리면서 누적 상대도수를 꺾은선으로 그리고, 이론값을 아는 실험이면 점선으로 함께 그어 큰 수의 법칙을 눈으로 보여 줍니다
  • 수 모형 탭 — 초등 수업용 모형을 값만 넣어 만듭니다. 분수(3/4, 2/3 처럼 적으면 막대나 원으로 나란히 놓고 크기 비교, 가분수는 전체를 여러 개), 자릿값 블록(천 덩어리·백 판·십 막대·일 칸으로 수를 펼치기), 수직선 뛰어세기(뛰는 크기를 음수로 적으면 거꾸로), 양팔 저울(x 상자와 1 블록으로 등식을 보여 주고 풀 수 있으면 x = 4까지 적기)
  • 과학 계산 탭 — 값을 넣으면 계산해서 그려 줍니다.
    • 렌즈·거울 광선도: 볼록·오목렌즈와 오목·볼록거울에서 1/a + 1/b = 1/f 로 상의 자리를 구해 광선 세 개와 상을 긋고, 상거리·배율·실상/허상·정립/도립·확대/축소를 적습니다(허상은 점선)
    • 퍼넷 사각형: Aa × Aa 는 3 : 1, AaBb × AaBb 는 9 : 3 : 3 : 1 — 배우자를 만들어 칸을 채우고 유전자형·표현형 비율까지 셉니다
    • 회로 계산: 저항을 6, 3, 2 처럼 적고 전압을 넣으면 직렬·병렬 회로 그림과 함께 합성저항·전체 전류, 저항마다의 전압(직렬)·전류(병렬)를 붙입니다
  • 벡터 합성(도구막대·우클릭 메뉴) — 같은 점에서 그린 화살표 두 개 중 하나를 고르고 누르면 평행사변형과 합력 화살표가 붙고 크기(cm)·각도가 적힙니다. 합성에 쓰인 화살표는 끝점에 손잡이가 생겨 끌어 길이·방향을 바꿀 수 있고, 그때마다 합력이 따라 바뀝니다. 원본 화살표를 지우면 합력도 함께 사라지고, 한 번 더 누르면 뗍니다
  • 지도 넣기(도구막대 🗺️) — 지도 고르기 창이 열립니다. 배경지도를 고르고 끌거나 장소 이름·좌표를 적은 뒤 검색(또는 Enter)으로 자리를 잡고 이 화면 넣기를 누르면 지금 보이는 지도가 그림으로 보드에 들어옵니다. 들어온 뒤에는 여느 이미지처럼 옮기고 크기를 바꾸며 그 위에 바로 판서할 수 있습니다. 마지막에 보던 자리를 기억하므로 다음에 열면 거기서 시작합니다. 지도를 계속 고쳐 가며 쓰려면 이 창 대신 지도 문서(.map) 를 만들고 그쪽의 🖊️ 칠판으로를 쓰세요
  • 도구상자 항목은 클릭하면 보드 가운데에, 끌어 놓으면 원하는 위치에 삽입. 교육 도형은 선명한 벡터 그룹으로 한꺼번에 이동·크기 조절하고, 선택 후 분리를 누르면 선·원·글자 같은 구성 요소를 개별 수정
  • 선택·이동 도구로 이미지·직선·화살표·사각형·원·텍스트를 클릭해 옮기고 Delete로 삭제

  • 도구막대 왼쪽 끝 ⋮⋮ 핸들을 끌면 상/우/하/좌 4면 중 가장 가까운 변으로 자동 도킹(우클릭 메뉴의 도구막대 위치에서 골라도 됩니다)
  • 색 버튼 오른쪽 배경색 버튼으로 보드 바탕색 변경 — 흰색·연회색·크림·칠판 초록·검정 프리셋과 직접 고르기. 고른 색은 그 보드에만 적용되고 탭을 닫았다 열어도 유지됩니다. 어두운 배경으로 바꾸면 펜 색이 자동으로 흰색으로 맞춰집니다.

  • Ctrl+Z / Ctrl+Y 되돌리기/다시 실행 (배경색은 보드 속성이라 되돌리기 대상이 아닙니다)

🎬 수업 리플레이 (판서 되감아 보기)

화이트보드에 쓴 판서를 시간 순서대로 녹화해 나중에 되감아 볼 수 있습니다. 영상이 아니라 벡터(선·도형) 기록이라 파일이 작고 인터넷 없이 동작합니다. 화이트보드, PDF 위 필기, Python 코드·실행 결과를 같은 타임라인에 녹화할 수 있습니다.

  1. 화이트보드 도구막대 오른쪽 끝 ● 녹화를 누르고 판서를 시작 (버튼이 ■ 정지로 바뀌며 깜빡임)
  2. 다 쓰면 ■ 정지 → 자동으로 리플레이 화면이 열림
  3. 재생 바에서 ▶/⏸ 재생·정지(스페이스), 탐색 슬라이더로 원하는 순간으로 이동, 0.5~4× 속도, ⟲ 처음부터
    • 재생 중 마지막 획은 실제로 그려지는 것처럼 나타납니다
  4. 💾 저장으로 .lesson 파일 저장 → 결석한 학생에게 전달하거나 다음 수업에서 다시 재생
  5. 저장한 .lesson은 더블클릭·드래그하거나 사이드바 새로 만들기 → 리플레이 열기(.lesson)로 다시 엽니다

펜·형광펜·지우개·도형·텍스트·이미지 삽입·되돌리기까지 모두 기록됩니다. 판서를 안 하고 설명만 하는 시간은 용량을 늘리지 않아 녹화 시간 자체에는 제한이 없습니다(용량은 판서량에 비례).

PDF 교재 위 필기 녹화도 같은 방식입니다.

  1. PDF를 열고 ✏️ 필기로 필기바를 켠 뒤, 필기바 오른쪽 ● 녹화를 누릅니다
  2. 교재에 펜·형광펜으로 설명하며 판서(페이지를 넘겨 가며 여러 쪽도 가능)
  3. ■ 정지를 누르면 교재 페이지 위에서 필기가 되살아나는 리플레이가 열립니다 — 페이지 전환·지우기까지 순서대로 재생
  4. 화이트보드 리플레이와 똑같이 💾 저장으로 .lesson을 남깁니다

PDF 필기 리플레이는 판서한 페이지의 배경 이미지를 함께 담으므로 화이트보드 리플레이보다 파일이 큽니다(페이지 수·해상도에 비례).

Python 코드·실행 결과 녹화도 지원합니다.

  1. Python 편집기 실행 바의 ● 녹화를 누릅니다.
  2. 코드를 고치거나 실행하면 코드 변화, 표준 출력·오류·그래프가 시간순으로 기록됩니다.
  3. ■ 정지 후 열리는 리플레이에서 오른쪽 코드·결과 패널과 판서 타임라인을 함께 되감아 봅니다. Python만 녹화한 경우에도 코드 패널 단독 리플레이로 저장됩니다.

문제 설명 + 시작 코드 + 자동채점 테스트를 .task 한 파일로 묶어 배포하는 기능입니다. 서버·인터넷 없이 USB나 메신저로 파일만 전달하면, 학생은 더블클릭으로 풀고 선생님은 제출본을 다시 채점해 확인합니다.

선생님 — 과제 만들기

  1. 파이썬(.py) 파일을 열고 코드를 작성한 뒤, 실행 바 ⋯ 더보기 → 채점에서 테스트(입력값·기대 출력)를 만듭니다
  2. 채점 창의 [📦 과제로 내보내기] 를 누르면 과제 빌더가 열립니다
  3. 과제 제목 · 출제자 · 문제 설명(마크다운 지원, 미리보기 버튼으로 확인)을 적고, 시작 코드(학생에게 처음 보여줄 코드)를 다듬습니다
  4. 테스트마다 숨김 체크 가능 — 숨김 테스트는 학생에게 통과/실패만 보이고 입력·기대 출력은 가려집니다
  5. 학생 코드가 읽을 데이터 파일(csv·txt 등, 합계 8MB)도 첨부할 수 있습니다 — 시작 코드와 같은 폴더에 있는 것처럼 open('data.csv')로 읽힙니다
  6. [👀 학생 화면 미리보기] 로 학생이 여는 그대로 확인(알림의 [이어서 만들기] 로 빌더 복귀) → [📦 .task 내보내기]
  7. 명령 팔레트(Ctrl+K)의 "과제 파일 만들기 (.task)" 로도 이 흐름에 바로 들어갈 수 있습니다

학생 — 과제 풀기

  1. 받은 .task 파일을 더블클릭·드래그로 엽니다 → 문제 설명은 왼쪽 참고 화면에 고정, 시작 코드는 편집기로 열립니다
  2. 편집기 위 과제 바(📦 제목 · 통과 n/m)에서 진행 상태를 보며 코드를 완성합니다. [문제 보기] 로 닫았던 문제를 다시 띄울 수 있습니다
  3. [✓ 채점] — 과제에 담긴 테스트로 자동 채점되어 테스트별 통과/실패와 출력 비교가 표시됩니다(몇 번이든 다시 채점 가능)
  4. 다 풀면 [📤 제출본 내보내기] → 이름 입력 → 과제제목_이름.taskdone 파일이 만들어집니다(EXE는 저장 폴더에 기록 + [폴더 열기], 브라우저는 다운로드). 채점을 안 했거나 채점 후 코드를 고쳤으면 현재 코드로 자동 재채점 후 내보냅니다
  5. 만들어진 .taskdone 파일을 선생님께 제출(USB·메신저·학급 게시판 등)

선생님 — 제출본 검수

  • 한 명씩: 학생의 .taskdone을 더블클릭하면 검수 화면이 열립니다 — 학생·제출 시각·제출본이 신고한 점수·채점 환경·파일 검사(수정·손상 감지)와 제출 코드를 한눈에. 같은 과제의 원본 .task가 열려 있으면 [🔁 재채점] 이 활성화되어 제출 코드를 선생님 파일의 테스트로 다시 채점하고 신고 점수와의 ✓ 일치 / ⚠ 불일치를 알려줍니다. [새 탭에서 편집기로 열기] 로 학생 코드를 직접 실행·단계 실행해 볼 수도 있습니다
  • 반 전체 한 번에: 새로 만들기 → 제출본 일괄 검수(.taskdone) (명령 팔레트에서도 가능) → [+ 제출본 추가] 로 여러 .taskdone을 한 번에 선택 → 원본 .task를 연 상태에서 [▶ 전체 재채점] → 표에 학생별 재채점 점수와 일치/불일치가 채워집니다 → [⬇ 성적 CSV] 로 엑셀에서 바로 열리는 성적표 내보내기. 각 행의 [자세히] 로 단독 검수 화면을 엽니다

제출본에 적힌 점수는 참고용입니다. 파일 검사(봉인)는 단순 수정·손상만 감지할 수 있어, 확실한 확인은 선생님 컴퓨터에서의 재채점으로 하세요 — 점수를 고친 제출본도 재채점에서 불일치로 드러납니다. 과제 파일을 배포 후 수정했다면 "과제 버전이 다름" 경고가 함께 표시됩니다. 숨김 테스트의 한계: .task는 텍스트(JSON) 파일이라 마음먹은 학생은 내용을 열어볼 수 있습니다. 변별이 중요한 평가라면 숨김 테스트에만 의존하지 마세요. 체험용 샘플이 docs/ 폴더에 있습니다 — 샘플-두수의합.task + 제출본 3종(정답/오답/점수 조작). 과제와 제출본들을 함께 열고 일괄 검수를 눌러 보세요.

📝 시험지 (.exam) — 출제 · 응시 · 채점

객관식·주관식 문항(이미지 포함) 으로 시험지를 만들어 배포하고, 학생이 풀어 이름·서명과 함께 낸 답안을 선생님만 열어 채점하는 기능입니다. 파일 세 종류를 씁니다.

파일무엇누가 가지나
.examkey원본 — 문항 + 정답 + 채점 열쇠. 통째로 선생님 암호로 잠깁니다선생님만
.exam배포본 — 정답이 아예 들어 있지 않은 시험지. 열기 암호를 걸 수 있습니다학생에게 배포
.examdone제출본 — 답안·서명이 봉인된 파일. 선생님 열쇠로만 열립니다학생이 제출

선생님 — 시험지 만들기

  1. 새로 만들기 → 새 시험지 만들기(.exam) (명령 팔레트 Ctrl+K 에서도 가능)
  2. 시험지 제목·출제자를 적고 [＋ 객관식] · [＋ 주관식] 으로 문항을 추가합니다. 모든 문항은 1점입니다
  3. 문항마다 지문을 쓰고 [🖼 이미지 추가] 로 그림·사진을 넣습니다(문항당 4장, 전체 합계 12MB). 보기에도 이미지를 붙일 수 있습니다
  4. 객관식은 보기 왼쪽 동그라미로 정답을 고르고, 주관식은 정답을 적습니다 — 여러 정답은 잎|leaf 처럼 | 로 구분하고, 띄어쓰기·대소문자 무시 옵션을 끌 수 있습니다
  5. [💾 원본 저장(.examkey)] — 처음 저장할 때 8자 이상의 선생님 암호를 정합니다. 이 암호가 정답과 채점 열쇠를 잠그고, 나중에 제출본을 여는 열쇠가 됩니다
  6. [📤 배포본 만들기(.exam)] — 정답을 뺀 학생용 파일을 만듭니다. 최신 원본이 저장되지 않았다면 먼저 저장하며, 이때 열기 암호(시험 시작 때 학생에게 알려줄 암호)를 걸지 물어봅니다
  7. 만든 .exam 만 USB·메신저로 배포하세요. .examkey 는 선생님 컴퓨터에만 두면 됩니다

학생 — 시험 보기

  1. 받은 .exam 을 더블클릭·드래그로 엽니다(열기 암호가 걸려 있으면 입력)
  2. 객관식은 보기를 클릭, 주관식은 직접 입력합니다. 답은 자동으로 임시 저장되고 제출 전까지 몇 번이든 고칠 수 있습니다
  3. 맨 아래에 이름을 적고 서명을 그립니다
  4. [📤 제출하기] → 확인 → 시험제목_이름.examdone 파일이 만들어집니다(EXE는 저장 폴더에 기록 + [폴더 열기], 브라우저는 다운로드)
  5. 그 파일을 선생님께 냅니다

제출하면 그 컴퓨터에서는 시험지가 잠깁니다. 잠금은 파일이 아니라 시험지 단위라서, 같은 시험지의 배포본을 새로 만들어 다시 나눠 줘도 이미 제출한 컴퓨터에서는 계속 "제출이 끝났습니다" 화면만 보입니다. 재시험이나 잘못 낸 제출을 되돌리려면 아래 [🔑 제출 기록 초기화] 를 쓰세요.

제출 기록 초기화 (선생님)

학생 컴퓨터에서 그 시험지를 열면 "제출이 끝났습니다" 화면에 [🔑 제출 기록 초기화] 가 있습니다. 푸는 방법은 두 가지입니다.

  • 초기화 코드로 (선생님이 자리에 없어도 됨) — 배포본을 만들 때 화면에 뜬 8자리 코드(예: ABCD-2345)를 그 학생에게만 불러 주세요. 학생이 [초기화 코드 넣기]에 입력하면 풀립니다. 코드를 잊었으면 채점 화면에서 원본(.examkey)을 연 뒤 [🔓 초기화 코드] 로 다시 볼 수 있습니다(늘 같은 코드입니다)
  • 원본 파일로 — [원본 파일 고르기]에서 그 시험지의 .examkey 를 고르고 선생님 암호를 넣습니다. 둘 다 맞아야 하고, 다른 시험지의 원본으로는 풀리지 않습니다

코드는 다시 풀게 할 학생에게만 불러 주세요. 반 전체가 알면 그 시험지에 한해 학생이 스스로 잠금을 풀 수 있습니다(정답이 새는 것은 아닙니다 — 배포본에는 코드도 정답도 들어 있지 않습니다).

잠금이 풀리면 그 컴퓨터에서 다시 풀고 제출할 수 있습니다. 이미 낸 .examdone 파일과 선생님 PC가 받아 둔 제출은 그대로 남으므로, 다시 제출하면 채점표에 같은 학생의 제출이 두 건으로 보입니다 — 채점할 것만 남기세요.

선생님 PC로 바로 내기 (같은 교실 네트워크)

파일을 옮기지 않고 제출을 선생님 PC로 곧장 보낼 수 있습니다.

  1. 선생님: 채점 화면의 [📡 제출 받기 시작] 을 누릅니다. 처음 켤 때 Windows 방화벽 허용이 필요합니다
  2. 화면에 뜬 주소(예: 192.168.0.12 : 17650) 와 제출 코드 6자리를 학생들에게 불러 줍니다
  3. 학생: 제출 상자에서 [선생님 PC로 바로 보내기] 를 켜고 주소·코드를 입력합니다. [연결 확인] 으로 미리 확인할 수 있습니다
  4. [📤 제출 확정하기] 를 누르면 바로 전송되고 접수번호가 표시됩니다. 선생님 채점표에는 즉시 나타납니다
  5. 받은 제출은 선생님 저장 폴더의 [제출함] 에도 파일로 남습니다

연결이 안 되면 파일로 저장됩니다. 학교 무선망이 단말끼리의 통신을 막아 두는 경우가 있어, 연결에 실패하면 지금까지처럼 .examdone 파일이 만들어집니다 — 그 파일을 선생님께 내면 됩니다. 코드를 잘못 입력한 경우에는 파일을 만들지 않고 다시 입력하도록 알려 줍니다.

선생님 — 채점

  1. 새로 만들기 → 시험 채점(.examdone) (또는 .examdone 파일을 더블클릭)
  2. [🔑 원본 .examkey 열기] → 선생님 암호 입력
  3. [＋ 제출본 추가] 로 반 전체의 .examdone 을 한 번에 선택하면 자동 채점됩니다 — 객관식은 정답 대조, 주관식은 정답 목록과 비교
  4. 표에 학생별 점수 / 확인 필요 문항 수가 나옵니다. [답안 보기] 로 문항별 학생 답·정답·서명을 보고, ○ 정답 / ✗ 오답 을 눌러 직접 고칠 수 있습니다(주관식 표현 차이는 여기서 판단)
  5. 수동 O/X 결과는 제출본별로 자동 저장되어 채점 화면을 닫아도 유지됩니다. [⬇ 성적 CSV]는 현재 시험, [📚 누적 성적 CSV]는 저장된 모든 시험의 학생별 점수를 내보냅니다

제출하면 학생도 답안 파일을 다시 못 엽니다. 제출본은 시험지에 들어 있던 공개키로 봉인되고, 그 짝인 개인키는 선생님 암호로 잠긴 .examkey 안에만 있습니다. 제출 순간 해당 기기의 임시 답안이 지워지고 시험지가 잠깁니다. 브라우저 저장소를 지우거나 다른 기기를 쓰면 재제출할 수 있으므로, 같은 학생의 복수 제출은 채점표에서 확인해야 합니다. 선생님 암호를 잊으면 제출본을 영영 열 수 없습니다 — 복구 경로가 없습니다(있으면 그게 곧 뒷문이라서). 시험지마다 암호를 따로 정했다면 어느 시험지의 암호인지 함께 적어 두세요. 정답은 배포본에 없습니다. 학생이 .exam 을 텍스트로 열어봐도 정답 자체가 파일에 없습니다. 다만 시험 중 화면 캡처·검색 같은 부정행위는 이 도구가 막지 못하니 교실 운영으로 함께 관리하세요. 시험 기능은 EXE(ClassDock)에서 사용하세요. 브라우저가 file:// 로 연 페이지에서는 암호 기능을 막기 때문에 시험지를 만들 수도, 제출할 수도 없습니다.

🖥 대기 화면 (화면보호기)

일정 시간 아무 입력이 없을 때 전체 화면으로 내 영상, 웹 페이지, 시계 애니메이션을 띄우는 기능입니다. 기본은 꺼져 있고, 설정에서 켤 때만 동작합니다.

  1. 헤더의 설정을 열고 대기 화면(화면보호기) 을 체크
  2. 표시까지 대기 시간(1·3·5·10·20분) 선택
  3. 보여줄 내용 선택
    • 영상 · 기본 애니메이션 — 영상 선택으로 지정(없으면 시계 애니메이션). 영상 지우기로 되돌림
    • 웹 주소(URL) — 주소를 넣고 미리보기 · 테스트로 실제로 뜨는지 확인
  4. 저장을 누르면 적용 — 그 시간만큼 입력이 없으면 대기 화면이 뜨고, 아무 키·클릭·마우스 이동에 즉시 사라집니다
  5. ▶ 지금 시작 — 설정에서 바로 누르거나 Ctrl+F12(설정 → 단축키에서 변경 가능)를 누르면 모니터 전체 화면으로 즉시 대기 화면이 켜집니다(쉬는 시간에 영상 틀어두기). 해제하면 전체 화면도 함께 종료. 유휴 자동 표시는 브라우저 보안상 창 안에서만 뜨지만, F11·⛶ 전체화면 상태라면 자동 표시도 모니터 전체를 덮습니다

권장 형식은 MP4(H.264)·WebM 입니다. MOV·MKV·AVI·WMV 등은 브라우저에서 재생이 안 될 수 있어, 고르면 경고가 뜨고 그래도 쓰면 재생 실패 시 시계 애니메이션으로 대체됩니다. 영상은 이 브라우저(앱)에만 저장되어 프로그램(exe·HTML) 용량은 늘지 않습니다. 영상이 없거나 못 읽으면 자동으로 시계 애니메이션을 씁니다. 작업 중에는 뜨지 않습니다: 파이썬·노트북 실행 중, 동영상·오디오 재생 중, 파일 처리 중, 설정 등 대화상자·미리보기(iframe) 사용 중이면 대기 화면을 미룹니다.

⚠ 로그인된 페이지는 넣지 마세요. 대기 화면은 이 컴퓨터 브라우저의 로그인 상태를 그대로 씁니다. 메일·성적·개인 페이지를 걸면 교실 화면에 그 내용이 그대로 뜹니다. 로그인이 필요 없는 공개 페이지만 쓰세요. 안 되는 사이트가 많습니다. 네이버·구글·유튜브 메인처럼 다른 화면 안에 넣는 것을 막아 둔 곳은 열리지 않습니다(성공 여부는 주소마다 다름). 저장 전에 반드시 미리보기 · 테스트 로 확인하세요.

유튜브 영상 틀기 — 유튜브 주소를 그대로 붙여 넣으면 주소칸 옆에 유튜브 → 퍼가기 주소 버튼이 나타납니다. 누르면 열리는 주소로 바꿔 주고, 무엇을 바꿨는지 아래에 알려 줍니다.

  • youtube.com/watch?v=…, youtu.be/…, shorts/…, live/…, playlist?list=… 모두 인식합니다
  • 한 영상 반복은 loop 만으로는 안 되고 자기 자신을 playlist 로 지정해야 하는데, 이걸 대신 붙여 줍니다
  • mute(음소거) 도 켭니다 — 소리가 켜져 있으면 브라우저가 자동재생을 막습니다. 대기 화면은 어차피 무음입니다
  • 주소에 시작 시간(t=1m30s)이 있으면 그대로 옮깁니다

🎵 악보 (.msheet) — 음표를 놓고 바로 들어 보기

  1. 사이드바 새로 만들기 → 새 악보 (또는 Ctrl+K → "새 악보", 폴더 우클릭 메뉴)
  2. 도구상자에서 음표 길이(온·2분·4분·8분·16분)를 고르고 오선 위에 마우스를 올리면 오른쪽에 입력 위치: 솔4 (G4) · 4분음표처럼 실제로 들어갈 계이름이 보입니다. 포인터가 십자선으로 바뀐 자리에서 클릭하면 음표가 들어가며 소리도 함께 납니다. 가득 찬 마디나 음역 밖에서는 붉은 점선·금지 포인터와 이유가 표시됩니다
  3. 피아노 악보는 위쪽의 🎼 단일 오선을 눌러 🎹 피아노 대보표로 바꿉니다. 오른손을 고르면 높은음자리표, 왼손을 고르면 낮은음자리표에 입력됩니다. 한 오선에서 서로 다른 리듬이 겹치면 성부 1·성부 2를 바꿔 각각 입력합니다. 두 손과 두 성부는 같은 마디에서 동시에 재생되며 박자 채움도 성부별로 표시됩니다. 다시 단일 오선으로 바꾸면 왼손 음표를 지울지 먼저 확인합니다
  4. 한 자리에 여러 음을 넣으려면 먼저 기준 음표를 고르고 ＋화음을 켠 뒤, 같은 손·같은 마디의 다른 음높이를 누릅니다. 화음 전체가 한 번에 들립니다. －화음음은 마지막으로 더한 음을 뺍니다. 이어지는 같은 음 두 개 중 앞 음을 고르고 ⌒ 붙임줄을 누르면 길게 이어서 소리 나며, 코드 기호에 Cm7, B♭, E♭/G처럼 입력하면 음표 위에 표시됩니다
  5. 음표를 고른 뒤 ⌒ 이음줄, 가사, 셈여림, 연주 기호(스타카토→악센트→테누토), 3잇단, 운지, 페달을 사용할 수 있습니다. |: 반복 시작, :| 반복 끝, 1·2번 괄호는 현재 마디에 붙으며 재생 순서에도 반영됩니다. 마디 설정에서는 첫 마디의 못갖춘마디 박 수와 이 마디부터 바뀌는 박자·조표·빠르기를 입력합니다
  6. 점(한 번 더 누르면 겹점), 쉼표, ♯ ♭ ♮, 지우개를 도구상자에서 켜고 끕니다. 악보를 마우스 오른쪽 버튼으로 누르면 손·성부 선택, 음표 길이·임시표·쉬운 도레미 입력, 화음·붙임줄·이음줄·가사·표현 기호, 반복·마디 설정, 대보표·마디·오선·초기화, 재생·연습, 저장·내보내기, 편집 도구막대 숨기기·보이기 메뉴를 바로 쓸 수 있습니다. 계이름을 켜면 각 음표 아래에 도·레·미·파♯가 표시됩니다
  7. ＋마디/－마디로 마디를 더하거나 지우고, ＋오선/－오선으로 마지막에 악보 한 단을 추가하거나 제거합니다. 연습 내용을 한꺼번에 지우려면 ↺ 초기화를 누릅니다. 확인 후 빈 1마디로 바뀌지만 제목·빠르기·박자·조표·음색과 대보표 설정은 유지되며 Ctrl+Z로 되돌릴 수 있습니다
  8. 음표를 누르면 음표 또는 화음 전체가 들립니다. 일반 상태에서 위아래로 드래그하거나 ↑/↓를 누르면 오선의 줄·칸에 맞춰 높이가 바뀝니다(Shift와 함께 누르면 한 옥타브). ←/→로 이웃 음표로 이동하고 Delete로 지웁니다. 위치 조정 또는 Alt+드래그로 음표를 좌우로 조금 옮길 수 있습니다

    • 아직 저장하지 않았어도 편집 내용은 잠시 뒤 작업공간에 자동으로 담겨, 실수로 새로고침하거나 창을 닫아도 다음에 열 때 그 지도 탭이 그대로 돌아옵니다. 표시를 찍기 전의 빈 새 지도도 마찬가지입니다. 설정의 자동 저장·복원을 끄면 이 사본도 남기지 않습니다(그때는 새로고침 전에 확인창만 뜹니다)
  16. 🖊️ 칠판으로를 누르면 지금 보이는 지도가 그림으로 굳어 새 화이트보드에 올라갑니다. 표시 이름·거리·면적과 출처가 그림에 함께 새겨지고, 확대·이동 단추와 편집 풍선은 빠집니다. 칠판에서는 그 위에 바로 판서할 수 있고, 지도 문서는 그대로 남아 계속 고칠 수 있습니다. 같은 지도를 두 번 보내면 서로 다른 칠판이 열립니다
  17. 📋 메모로를 누르면 지금 보이는 지도가 그림과 함께 메모장의 그림 블록으로 들어갑니다. 칠판으로 보낼 때와 같은 그림(표시 이름·거리·면적·출처가 새겨진)이지만, 그 안에 지도 자체가 함께 담겨 메모의 ✏️ 지도로를 누르면 새 탭에서 다시 편집할 수 있습니다. 고친 뒤 다시 📋 메모로를 누르면 새 블록이 생기지 않고 그 블록이 제자리에서 바뀝니다(화이트보드·악보와 같은 방식). 사용자 지도 이미지를 넣어 지도가 아주 큰 경우에는 그림만 들어가고 되열기는 되지 않는다고 알려 줍니다. 앱을 껐다 켜도 자동 복원으로 되살아난 지도는 같은 블록으로 돌아갑니다(파일 이름을 바꾸면 연결이 끊겨 다음에는 새 블록이 생깁니다). 그 지도 탭이 이미 열려 있는 채로 메모의 ✏️ 지도로를 누르면 새 탭 대신 그 탭으로 가되 메모 그림과 같은 자리로 옮겨 줍니다 — 그 탭에서 표시를 더 찍어 그림과 내용이 달라졌다면 메모 그림으로 열기 / 열린 탭 보기를 물어봅니다
  18. EXE로 지도를 보면 화면에 실제로 표시된 배경이 자동으로 보관됩니다. 다시 방문한 지역은 받아 둔 타일 범위에서 인터넷 없이 열립니다. 🗂️ 오프라인 지도에서 지금까지 받아 둔 양을 확인하고 비울 수 있습니다. 공개 지도 서버 정책에 따라 보지 않은 지역이나 더 자세한 확대 단계를 미리 일괄 다운로드하지는 않습니다

인터넷이 필요한 곳은 배경지도뿐입니다. 연결이 없으면 배경만 비어 보이고 표시·메모·저장은 그대로 동작합니다. 전에 실제로 보아 자동 보관된 지역이라면 배경도 나옵니다. 내 지도 이미지는 인터넷 없이 항상 표시됩니다. 다만 이미지를 넣을 때 현재 화면의 위·경도 범위에 맞춰 놓는 방식이므로, 평면도처럼 실제 지도 축척과 다른 그림에서 표시되는 거리·면적 값은 참고용입니다. 배경지도는 종류마다 캐시가 따로입니다. 전에 일반 지도로 본 지역이라도 수업에서 처음 위성으로 바꾸면 그 배경은 비어 보일 수 있습니다. 지도를 조금 움직였다고 저장 안 됨(●) 이 켜지지는 않습니다. 표시·이름·배경지도를 바꿀 때만 켜지며, 저장할 때는 그 순간 보고 있던 자리가 함께 담깁니다.

장소 이름 검색에는 인터넷과 ClassDock 런처가 필요합니다(받아 둔 지역이라도 검색은 인터넷을 씁니다). 인터넷이 끊기면 지도 위에 새 지역은 표시할 수 없고 이전에 저장된 지역만 볼 수 있다는 안내가 나타납니다. 연결이 돌아오면 현재 지도를 자동으로 다시 요청합니다. OpenStreetMap 검색은 제공처 정책상 글자를 칠 때마다가 아니라 검색 또는 Enter를 눌렀을 때만 찾고, 잇단 검색 사이에는 1초를 둡니다. HTML을 직접 연 화면에서도 좌표 이동은 그대로 쓸 수 있습니다.

배경지도는 OpenStreetMap(일반·지형)·CARTO(흑백)·Esri(위성)에서 받아 옵니다. 장소 이름 검색은 기본적으로 Nominatim(OpenStreetMap)을 쓰며, 설정하면 카카오 로컬 REST API를 먼저 사용합니다. 만들어진 그림에 출처가 함께 적히는 것은 배경지도의 이용 조건입니다.

  1. 비교할 파일을 둘 다 열어 둔 뒤 Ctrl+K → "두 파일 비교" 로 두 파일을 고릅니다
  2. 지금 고친 내용이 저장된 원본과 어떻게 다른지만 보고 싶다면 Ctrl+K → "저장본과 비교"
  3. 결과는 새 탭에 열리며, 나란히 보기 / 한 줄로 보기를 전환할 수 있습니다
  4. 바뀐 줄 안에서 실제로 달라진 글자만 따로 강조되고, 똑같은 줄이 길게 이어지는 구간은 접어서 차이만 보여 줍니다
  5. 공백 무시 옵션을 켜면 들여쓰기·줄 끝 공백만 다른 줄은 같은 줄로 봅니다

과제 패키지(.task)에서는 학생의 제출 코드와 시작 코드를 바로 비교할 수 있습니다. 비교 화면은 원본에서 언제든 다시 만드는 화면이라 저장 대상이 아니고, 자동 복원에도 남지 않습니다. 파일 하나가 5MB·5만 줄을 넘으면 비교하지 않습니다.

🔁 여러 파일 찾아 바꾸기

  1. 바꿀 파일들을 열어 둔 상태에서 Ctrl+K → "여러 파일 찾아 바꾸기"
  2. 찾을 말과 바꿀 말을 넣습니다 — 대소문자 구분, 정규식(그룹 치환 $1 사용 가능)을 지원합니다
  3. 미리보기에 파일별로 바뀔 줄이 뜹니다. 체크를 풀어 원하지 않는 파일은 빼세요
  4. 적용하면 각 파일의 저장 위치로 대화상자 없이 조용히 저장됩니다
  5. 잘못 바꿨으면 되돌리기 한 번으로 방금 바꾼 내용을 전부 복원합니다

대상은 열려 있는 텍스트·코드 문서와 Word(.docx)·PowerPoint(.pptx) 입니다. PDF·Excel·한글 같은 보기 전용 문서와 노트북은 제외됩니다. 빈 문자열에도 일치하는 정규식(a* 등)은 모든 자리에 끼어들어 위험하므로 막습니다.

Word(.docx)·PowerPoint(.pptx)를 함께 바꿀 때

Word·PowerPoint 파일은 같은 창에서 본문 글자가 함께 바뀝니다. 미리보기는 줄 번호 대신 문단 12(Word)·슬라이드 3(PowerPoint)처럼 보여 주고, 파일 이름 옆에 Word 본문·슬라이드 표시가 붙습니다.

  • 바꾼 자리 말고는 글꼴·색·표·이미지·머리말이 그대로 남고, 원래 그 파일에 제자리로 저장됩니다(사본을 만들지 않습니다). 잘못 바꿨으면 되돌리기로 원래 파일로 돌아갑니다.
  • 머리말·꼬리말·각주(Word)와 발표자 노트(PowerPoint)는 기본적으로 바꾸지 않고, 머리말 2곳은 바꾸지 않아요처럼 개수만 알려 줍니다. 함께 바꾸려면 설정 → 문서 → "머리말·꼬리말·각주·발표자 노트도 함께 바꾸기" 를 켜세요. 이번 한 번만 다르게 하려면 찾아 바꾸기 창의 머리말·꼬리말·노트 포함 체크를 쓰면 됩니다.
  • 메모(검토 의견)·차트·도형 안 글자는 어느 쪽이든 바꾸지 않습니다. 슬라이드 마스터·레이아웃의 "제목을 입력하십시오" 같은 빈 자리 안내문과 자동으로 채워지는 슬라이드 번호도 건드리지 않습니다.
  • 바꿀 수 없는 문서는 목록에서 사라지지 않고 이유와 함께 흐리게 남습니다 — 암호가 걸린 문서, 내용 컨트롤이 연결된 문서, 40MB가 넘는 문서입니다.
  • 변경 내용 추적이 켜진 문서도 기본적으로 건너뜁니다. 이 프로그램이 바꾼 내용은 Word의 변경 이력에 남지 않기 때문입니다. 그래도 바꾸려면 설정 → 문서 → "변경 내용 추적이 켜진 문서도 바꾸기" 를 켜세요.
  • PowerPoint가 설치된 PC(EXE)에서는 .pptx가 PDF로 정확 변환되어 열립니다. 그때 화면에 있는 문서는 PDF라 찾아 바꾸기 대상이 아닙니다. 슬라이드를 바꾸려면 PowerPoint에서 직접 바꾸거나, PowerPoint가 없는 환경(브라우저 등)에서 여세요.
  • 저장할 위치를 찾지 못하면(브라우저로만 연 파일 등) 아무것도 바꾸지 않고 건너뜁니다. Word·PowerPoint 문서는 편집기가 없어서, 화면만 바뀌면 "바뀐 줄 알았는데 파일은 그대로"가 되기 때문입니다.

📝 텍스트·이미지·노트북 셀 메모

  1. 상단 메모 또는 Ctrl+M으로 메모장 열기
  2. 메모가 많아 안이 헷갈리면 탭에 마우스를 올려 본문 앞 세 줄 미리보기를 확인
  3. 메모가 많아지면 탭바의 ▦ 목록으로 모든 메모를 카드로 펼쳐 제목·색·수정 시각·본문 앞부분을 한눈에 확인. 전체 내용 보기를 켜면 모든 메모의 글·이미지·표·노트북 셀을 읽기 전용 세로 흐름으로 이어 확인할 수 있음. 각 카드의 ⤢ 크게 보기는 해당 카드 하나만 화면 가득 펼치고, 같은 버튼의 ⤡ 이전 크기 또는 Esc로 목록에 복귀. 편집이나 카드 제목을 누르면 해당 메모 편집 화면으로 이동. 위쪽 검색창에 치면 제목·본문이 맞는 메모만 남으며 일치한 내용이 강조됨(Enter는 첫 결과로 이동, Esc는 검색어 → 목록 순으로 닫힘). 명령 팔레트(Ctrl+K)의 메모 목록·검색으로도 바로 열림
  4. + 글 블록으로 글 영역을 추가하고 + 이미지로 이미지 파일 삽입
  5. 글·이미지·표·노트북 셀 블록 도구막대의 ⤢를 누르면 해당 블록 하나만 화면 가득 펼쳐 편집·확인. 같은 자리의 ⤡ 또는 Esc로 원래 메모에 복귀
  6. 글 영역에 이미지를 Ctrl+V로 붙여넣거나 로컬 파일·웹 이미지를 메모장에 드롭
  7. 이미지 블록의 ↑ ← → ↓ 버튼으로 설명 글의 위·왼쪽·오른쪽·아래에 즉시 배치
  8. 작게/중간/크게/가득으로 표시 크기를 바꾸고 블록 ↑/↓ 또는 ⋮⋮ 드래그로 문서 순서 변경
  9. 이미지 옆 입력란에 설명 작성. 글·이미지·배치 정보는 이 컴퓨터에 자동 저장
  10. 기존 텍스트 메모는 새 형식으로 자동 이전되며, 텍스트 복사는 이미지 이름을 포함한 읽기 쉬운 텍스트로 복사
  11. 블록 도구막대의 자물쇠 아이콘을 누르면 읽기 전용으로 바뀌어 내용·배치·이동·삭제를 막음. 잠긴 자물쇠 아이콘을 다시 누르면 편집 가능
  12. 이미지 블록의 📋 복사(클립보드 → 다른 프로그램에 붙여넣기), 💾 파일로(EXE는 저장 폴더, 브라우저는 다운로드), ✏️ 편집기로(이미지 편집 탭으로 열어 자르기·표시 후 '📷 메모로'로 다시 넣기)로 메모 속 이미지를 재사용. 잠긴 블록에서도 사용 가능
    • 화이트보드·악보·지도에서 메모로 보낸 그림에는 ✏️ 화이트보드로 · ✏️ 악보로 · ✏️ 지도로 버튼이 함께 붙습니다. 누르면 그림이 아니라 원래 문서가 새 탭으로 되살아나고, 고친 뒤 다시 메모로를 누르면 그 블록이 제자리에서 바뀝니다. 같은 블록을 두 탭으로 열지는 않습니다
    • 지도·악보는 이 연결이 탭 구성과 함께 저장되어, 앱을 껐다 켜고 자동 복원으로 열린 뒤에도 같은 블록으로 돌아갑니다. 가리키던 블록을 지웠다면 다음에 메모로를 누를 때 새 블록이 생깁니다(화이트보드는 파일이 아니라 다시 실행하면 탭 자체가 없고, 전체 백업 복원으로만 되살아납니다)
    • 그 블록과 이어진 지도·악보 탭이 이미 열려 있으면 새 탭을 만들지 않고 그 탭으로 갑니다. 내용이 같으면 지도는 메모 그림과 같은 자리(중심·확대)로 옮겨 그림 속 그곳이 보입니다. 그 탭을 열어 둔 채 다른 곳을 편집해 내용이 그림과 달라졌다면 물어봅니다 — 메모 그림으로 열기(그 탭의 연결을 끊고 그림 속 지도를 새 탭으로, 열려 있던 지도는 그대로 남습니다) 또는 열린 탭 보기
  13. 노트북에서 선택한 셀의 메모 아이콘을 누르거나 ⋮⋮ 손잡이를 메모장에 드롭하면 코드/마크다운/Raw 셀 카드로 별도 저장
  14. 셀 카드의 노트북에 붙여넣기를 누르면 현재 노트북의 선택 셀 아래에 삽입. 카드 손잡이를 노트북 셀 사이에 직접 드롭하면 정확한 위치에 삽입
  15. 셀 카드는 최대 200개까지 보관하며 코드·마크다운 첨부·일반 메타데이터를 유지하고 실행 결과·실행 번호·필기는 저장하지 않음

잠긴 블록이 하나라도 있으면 해당 메모 탭 삭제와 모두 지우기도 차단됩니다. 먼저 각 블록의 잠금을 해제하세요.

🌐 인터넷이 안 되는 환경에서 쓰고 싶어요

  • EXE 사용 가능 — 문서 보기·편집은 완전 오프라인
  • 오프라인 HTML 사용 가능 — 같은 이유
  • 단, Python을 브라우저(Pyodide)로 실행할 때는 첫 실행에 인터넷 필요 (런타임 다운로드)
  • 완전 오프라인 Python을 원하면: EXE + 로컬에 Python 설치 → 로컬 Python으로 실행되므로 인터넷 불필요
  • 오프라인에서도 Pyodide를 쓰려면: EXE 옆 vendor/pyodide/ 폴더에 코어 파일이 미리 있어야 함

🐍 파이썬은 설치하지 않고도 코드를 실행하고 싶어요

  • 브라우저 Pyodide가 자동으로 동작합니다 — 별도 파이썬 설치 불필요
  • numpy·pandas·matplotlib 같은 공식 패키지와 PyPI의 순수 Python 패키지는 첫 실행 시 자동으로 받아옴
  • Faker는 EXE에 내장되어 인터넷 없이도 사용 가능
  • 첫 실행만 인터넷 필요, 이후 캐시
  • 제한: selenium·konlpy 등 Pyodide 미지원 패키지, OS 명령(subprocess)은 사용 불가

💻 학생들에게 배포하려면?

  • 단일 파일 배포 = classdock-offline.html 한 파일만 USB·메신저로 주면 끝
  • 학생이 더블클릭하면 바로 브라우저에서 열림, 파이썬·라이브러리 설치 불필요
  • 더 강력한 기능(로컬 Python 실행·자동 복원·PPT 변환)이 필요하면 ClassDock.exe 배포
  • 숙제·수행평가는 과제 패키지(.task) 로 — 문제·시작 코드·자동채점을 한 파일로 배포하고 제출본(.taskdone)을 걷어 일괄 재채점·성적 CSV까지

📁 input()이 있는 코드를 가르치고 싶어요

  • 자연스러운 대화형 입력이 필요하면 EXE + 로컬 Python이 답
  • 브라우저(Pyodide)에서는 코드 실행 전에 입력값들을 미리 한 줄씩 적어두는 방식

🔄 매번 EXE 누르기 귀찮을 때

EXE를 한 번 띄워두고 브라우저 즐겨찾기로 바로 접속할 수 있어요.

  1. desktop/start-server-hidden.vbs 실행 — 콘솔창 없이 서버만 뜸 (브라우저는 자동으로 열리지 않음)
  2. 브라우저에서 http://127.0.0.1:17645/ 접속 후 즐겨찾기(Ctrl+D)
  3. 그 .vbs를 시작프로그램 폴더(Win+R → shell:startup → 거기에 복사)에 넣어두면 PC 켤 때 자동으로 서버가 뜨고, 즐겨찾기만 누르면 바로 사용 가능
  4. 끄려면 desktop/stop-server.cmd 실행

⚠️ 백그라운드 서버가 뜬 상태에서는 EXE를 직접 더블클릭하지 마세요 (중복 인스턴스가 됨).

📌 작업 표시줄에 고정하고 싶어요

  2. EXE를 마우스 오른쪽 클릭

8. 개발자용 — 소스 수정 후 다시 빌드 ↑ 목차

이 프로젝트의 EXE 빌드는 다음 두 단계로 진행됩니다.

  1. classdock.html, src/, vendor/를 합쳐 classdock-offline.html 생성
  2. 오프라인 HTML을 C# 런처에 내장해 ClassDock.exe 생성

준비물

  • Node.js — node --version으로 확인. 없으면 nodejs.org에서 설치
  • .NET Framework C# 컴파일러 — 일반적인 Windows 환경에서는 아래 위치 중 하나에 있습니다
    • C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe
    • C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe
  • 일반적인 소스 검사·단위 테스트·오프라인 빌드는 추가 npm 패키지 없이 실행됩니다. 단 npm run test:e2e의 Playwright E2E 테스트는 @playwright/test 개발 의존성이 있으므로 새 환경에서는 먼저 npm install이 필요합니다.

권장 빌드 절차

프로젝트 루트에서 PowerShell을 열고 다음 명령을 순서대로 실행합니다.

cd <저장소를 클론한 폴더>       # 예: D:\my

# 실행 중인 기존 EXE가 있다면 종료
Get-Process classdock -ErrorAction SilentlyContinue |
    Stop-Process -Force

# 구문 검사 + 자동 테스트 + 오프라인 HTML 생성 + 배포물 검사
npm.cmd run verify

# 오프라인 HTML을 내장한 EXE 생성
cmd /c desktop\build.bat

PowerShell에서는 실행 정책에 따라 npm이 npm.ps1 오류로 막힐 수 있습니다. 이때 실행 정책을 바꾸지 말고 위 예시처럼 npm.cmd를 사용하면 됩니다.

테스트를 생략하고 빠르게 빌드

코드 검증이 이미 끝난 상태에서 산출물만 다시 만들려면:

cd <저장소를 클론한 폴더>
node build-offline.js
cmd /c desktop\build.bat

node build-offline.js는 이미 만들어져 있는 vendor/를 그대로 씁니다. 처음 클론했거나 맞춤법 사전을 바꿨다면 npm.cmd run build(사전 워커 생성 → 오프라인 HTML)를 한 번 거쳐야 합니다.

개별 검증 명령은 다음과 같습니다.

npm.cmd run check          # 구문 검사만
npm.cmd test               # 자동 테스트만(Node 내장 러너)
npm.cmd run build          # 맞춤법 사전 워커 + 사용법 HTML + 오프라인 HTML 생성
npm.cmd run build:manual   # 사용법.md → 사용법.html 만 다시 생성
npm.cmd run release-check  # 배포 산출물·vendor 해시 검사
npm.cmd run test:e2e       # 화면 흐름 테스트(Playwright, npm install 필요)

자주 발생하는 빌드 오류

  • npm.ps1을 로드할 수 없음: npm 대신 npm.cmd 사용
  • ClassDock.exe 액세스 거부: 실행 중인 EXE를 위의 Stop-Process 명령으로 종료한 뒤 재시도
  • classdock-offline.html이 없음: node build-offline.js 또는 npm.cmd run build를 먼저 실행
  • C# compiler not found: .NET Framework 개발 구성 요소를 설치하거나 Go 1.21 이상을 설치

desktop/build.bat은 C# 컴파일러가 있으면 desktop/launcher.cs를 사용합니다. 컴파일러가 없으면 Go 빌드를 시도하지만, Go 폴백 버전은 PowerPoint 변환 등 일부 로컬 연동 기능이 제한되므로 C# 빌드를 권장합니다.

배포할 때

  • 기본 앱 기능은 ClassDock.exe 하나로 실행할 수 있습니다.
  • 인터넷 없이 브라우저 Python(Pyodide)까지 사용하려면 EXE와 함께 vendor/pyodide/ 폴더를 같은 상대 위치로 배포합니다.
  • 로컬 Python의 번들 패키지 설치까지 오프라인으로 지원하려면 vendor/wheels/도 함께 배포합니다.
  • 자체 코드 서명을 하지 않은 EXE에는 Windows SmartScreen 경고가 표시될 수 있습니다.

즐겨찾기 상시구동 중이라면

  • 재빌드 후 desktop/stop-server.cmd → desktop/start-server-hidden.vbs로 서버 재시작 필요

대기 화면(화면보호기)기본 꺼짐(설정에서 켤 때만). 영상은 브라우저 저장소에 보관(용량 큰 영상은 저장 실패할 수 있음 → 짧은 영상 권장). 유휴 자동 표시는 브라우저 창 안 오버레이(브라우저 보안상 전체화면 자동 전환 불가) — 모니터 전체는 설정의 ▶ 지금 시작 버튼 또는 F11·⛶ 전체화면 상태에서 가능
대기 화면 웹 주소(URL)인터넷 연결 필요. 삽입을 막아 둔 사이트가 많아 주소마다 되는지 다름(저장 전 미리보기 · 테스트 필수). 로그인 상태가 그대로 보이므로 공개 페이지만 사용. 페이지 조작은 불가(보기 전용). 안 열리면 영상 → 시계 애니메이션으로 자동 대체

시험지(.exam)문항 최대 100개(모두 1점)·보기 8개·문항당 이미지 4장·이미지 합계 12MB. 주관식 자동 채점은 정답 목록과의 글자 비교라 표현이 다르면 선생님이 [답안 보기]에서 판단해야 합니다. 암호 기능이 필요해 EXE(또는 https)에서만 동작하고, file://로 연 페이지에서는 막힙니다. 선생님 암호를 잊으면 제출본을 열 수 없습니다(복구 불가). 시험 중 화면 캡처·검색 같은 부정행위는 막지 못합니다
블록 문서(.mnote)표 하나는 50행 × 20열, 이미지 한 장 25MB까지. 이미지가 파일 안에 들어가므로 사진이 많으면 파일이 커짐
악보(.msheet)단일 높은음자리표 또는 피아노 대보표, 오선별 성부 2개, 화음·붙임줄·이음줄·가사·코드·셈여림·연주 기호·셋잇단·운지·페달·반복선과 1·2번 괄호·못갖춘마디·중간 박자/조표/빠르기 변경 지원. 장·단조 조표는 ♯·♭ 7개까지, 오른손 음역 G3~C6·왼손 C2~C5. 조옮김은 위아래 한 옥타브까지이며 새 조표는 임시표가 적은 쪽으로 정해짐(다장조 반음 위 = 내림라장조). MusicXML은 첫 파트와 오선별 두 성부까지 사용하며 고급 표기는 단순화할 수 있음. MIDI 건반 입력과 MIDI·WAV 저장, 참고 이미지 나란히 보기를 제공하지만 이미지 자동 악보 인식과 마이크 녹음은 없음. 기본 음색은 내장 피아노 녹음이며 기타·실로폰·하프·플루트·클라리넷 녹음과 합성음도 선택 가능
지도(.map)배경지도에 인터넷 필요(표시·메모·저장은 오프라인에서도 동작). 장소 이름 검색은 인터넷과 ClassDock 런처 필요. 기본 OpenStreetMap 검색 또는 설정한 개인 카카오 REST API 키로 국내 주소·장소를 찾고, 카카오 검색이 안 되면 기본 검색으로 자동 전환. 좌표 이동은 HTML 직접 실행에서도 가능. 런처는 화면에 실제로 표시된 타일만 자동 보관하고 공개 서버가 금지하는 사전 일괄 다운로드는 하지 않음. 캐시는 이 컴퓨터에 정확히 최대 400MB까지 보관하고 넘치면 오래된 것부터 지우며, 배경지도 종류마다 따로 쌓임. 칠판으로 보낸 지도는 그림이라 그 뒤에는 확대·이동이 안 됨
파일 비교(diff)텍스트·코드만. 파일 하나가 5MB 또는 5만 줄을 넘으면 비교하지 않음. 비교 화면은 저장·자동 복원 대상이 아님
여러 파일 찾아 바꾸기열려 있는 텍스트·코드 문서와 Word(.docx) 본문·PowerPoint(.pptx) 슬라이드(PDF·Excel·한글·노트북 제외). 빈 문자열에도 일치하는 정규식은 거부
Word·PowerPoint 찾아 바꾸기본문 글자만. 문단 추가·삭제나 글꼴 바꾸기는 안 됨. 머리말·꼬리말·각주·발표자 노트는 설정에서 켤 때만, 메모·차트·도형 안 글자와 슬라이드 마스터·레이아웃·자동 슬라이드 번호는 언제나 제외. 암호·내용 컨트롤 연결·40MB 초과 문서는 제외되고, 변경 이력이 켜진 문서는 기본 제외(설정에서 허용 가능 — 바꾼 내용이 Word 변경 이력에 남지 않음). 탭·줄바꿈을 넘나드는 일치는 건너뜀. PowerPoint 설치 PC에서 PDF로 변환되어 열린 .pptx는 대상 아님
맞춤법 검사오프라인 전용. 한국어 사전이 3MB가 넘어 처음 검사할 때 한 번 불러옵니다(못 받아오면 규칙 검사만 동작). 긴 문서는 선택 영역이나 현재 위치 주변만 검사
최근 검색어이 컴퓨터 안에만 구획별 12개까지. '바꿀 내용'은 기억하지 않음. 설정 → 일반에서 끄거나 지울 수 있음

10. 문제 해결 FAQ ↑ 목차

Q1. EXE를 더블클릭했는데 SmartScreen 경고가 떠요

서명되지 않은 빌드라 정상입니다.

→ "Windows의 PC 보호" 창에서 추가 정보 → 실행 클릭

Q2. 브라우저가 자동으로 안 열려요

EXE가 실행됐는데 브라우저가 안 뜨면:

  1. 작업관리자에서 ClassDock.exe 프로세스가 살아 있는지 확인
  2. 살아 있으면 브라우저에서 http://127.0.0.1:17645/ 직접 접속
  3. 17645가 다른 프로그램에 점유돼 있으면 다음 고정 후보 포트(18645 · 19645 · 27645 · 37645 · 47645) 중 하나로 떠 있을 수 있음 → 그 주소로 접속하거나, 콘솔창이 안 보이므로 종료 후 재실행. 한 번 뜬 포트는 기억되어 다음 실행 때 재사용됩니다

Q3. 즐겨찾기로 접속이 안 돼요

  • start-server-hidden.vbs가 실행 중인지 작업관리자에서 확인
  • 안 떠 있으면 다시 실행
  • EXE를 따로 더블클릭한 적이 있으면 중복 인스턴스가 떠서 포트가 어긋날 수 있음 → 모두 종료 후 .vbs만 다시 실행

Q4. Python 실행이 안 돼요 / 너무 느려요

  • 브라우저 첫 실행은 Pyodide 다운로드 때문에 30초~1분 정도 걸립니다. 이후 캐시되어 빨라짐
  • 인터넷이 없으면 첫 실행이 실패할 수 있음 → EXE + 로컬 Python 설치 권장
  • 로컬 Python을 인식하지 못하면 편집기 도구바의 Py Env 클릭해 진단 확인
  • 파이썬을 방금 설치했다면 Py Env → 다시 검사를 누르면 EXE를 껐다 켜지 않아도 인식됩니다
  • PATH에 없어도 레지스트리와 기본 설치 폴더(%LocalAppData%\Programs\Python, Program Files, C:\Python3xx, Anaconda 등)에서 자동으로 찾습니다. 그래도 못 찾으면 기본 위치가 아닌 곳에 설치한 경우이므로 Add python.exe to PATH를 체크해 다시 설치하세요

Q5. PowerPoint 파일이 깨져 보여요

  • EXE + 설치된 Microsoft PowerPoint가 있어야 정확 변환
  • HTML 버전이나 PowerPoint 미설치 시 PPTXjs 근사 미리보기로 폴백 (애니메이션·복잡한 도형이 어긋날 수 있음)

Q6. 저장한 파일이 안 보여요

  • EXE에서 Python·Excel 저장 위치: 내 문서\ClassDock 저장\ 폴더
  • PDF·이미지 내보내기는 브라우저 기본 다운로드 폴더로 떨어짐
  • 편집기 상단에 마지막 저장 경로가 표시됨

Q7. 작업 표시줄의 EXE 아이콘이 동작 안 해요

  • EXE 파일을 다른 위치로 옮기거나 삭제했는지 확인
  • 옮겼다면 작업 표시줄 아이콘을 우클릭 → 작업 표시줄에서 제거 후 새 위치에서 다시 고정

Q8. PDF 위에 한 필기가 사라졌어요

  • PDF 필기는 자동 저장되지만, 다른 작업공간으로 옮기거나 EXE 자동 복원 데이터를 지우면 함께 사라질 수 있음
  • 다운로드한 PDF에는 필기가 그대로 구워지므로, 영구 보존하려면 다운로드 버튼으로 저장

Q9. Python 편집기에서 필기를 켰는데 다시 끄고 싶어요

  • 도구바의 ✏️ 필기 버튼을 한 번 더 누르면 편집 잠금 해제 + 캔버스 OFF
  • 필기는 세션 한정이라 문서를 닫으면 자동으로 사라집니다 (저장되지 않음)

Q10. 지도가 회색으로만 보여요

배경지도는 인터넷에서 받아 옵니다. 표시·메모·저장은 그대로 되지만 배경만 비어 보이는 상태입니다.

  1. 인터넷 연결을 확인합니다
  2. 연결이 안 되는 교실에서 쓸 지역은, 연결되는 곳에서 ClassDock EXE로 실제 수업 때 볼 자리와 확대 단계까지 직접 열어 두세요. 화면에 표시된 타일은 자동 보관되어 다시 방문할 때 인터넷 없이 나옵니다
  3. 전에 본 것 같은데도 비어 보이면 배경지도 종류나 확대 단계가 달라지지 않았는지 확인하세요 — 일반·지형·흑백·위성은 각각 따로 보관됩니다
  4. 🗂️ 오프라인 지도 버튼이 안 보이면 브라우저에서 HTML을 직접 열어 쓰는 중입니다. 자동 디스크 캐시와 현황·비우기는 런처(EXE)에서만 동작합니다
