1. 이 프로그램이 뭐예요? ↑ 목차

여러 형식의 파일(PDF·Word·Excel·PowerPoint·이미지·Python 등)을 하나의 창에서 보고 편집하는 오프라인 도구입니다.

  • PDF에 서명·텍스트·필기를 올려 다른 PDF로 저장
  • Excel/CSV 표 보기·편집·통계
  • Python 코드 작성·실행·자동채점 (브라우저 안에서도 동작)
  • PDF 교재 + Python 코드를 나란히 펴 놓고 공부 (학습 화면)
  • 화이트보드(설명용 칠판)와 PDF·코드 위 필기
  • 수업 리플레이 — 화이트보드·PDF 필기·Python 코드와 실행 결과를 녹화해 되감아 재생(.lesson)
  • 과제 패키지 — 문제·시작 코드·자동채점을 한 파일(.task)로 배포하고 제출본(.taskdone)을 걷어 재채점·성적 CSV

파일은 외부 서버로 올라가지 않습니다. 내 PC 안에서만 처리합니다.

2. 내 PC에 받기 — 두 가지 방법 ↑ 목차

방법 A. Git으로 클론 (개발자·소스 수정할 사람)

  1. Git이 설치돼 있는지 확인 — 명령 프롬프트(cmd)나 PowerShell에서 git --version 입력. 없으면 git-scm.com에서 설치.
  2. 원하는 폴더에서 클론: 
    git clone https://github.com/songhwaseong/myOffice.git
cd myOffice

방법 B. ZIP으로 다운로드 (그냥 쓰고만 싶은 사람)

  1. GitHub 저장소(https://github.com/songhwaseong/myOffice) 접속
  2. 초록색 Code 버튼 → Download ZIP
  3. 받은 ZIP을 원하는 폴더에 압축 해제

이 단계만 끝나면 사용은 가능합니다. 다음 섹션에서 실행 방법을 고르세요.

3. 실행하기 — 세 가지 방법 중 고르기 ↑ 목차

받은 폴더 안에 세 가지 실행 방법이 들어 있습니다. 상황에 맞게 하나만 고르면 됩니다.

방법누가 쓰면 좋아요?더블클릭할 파일
① EXE가장 추천. 자동 복원·로컬 Python·정확한 PPT 변환 등 모든 기능 사용manneung-classroom.exe
② 오프라인 HTMLUSB로 들고 다니거나 다른 PC에 파일 하나만 주고 싶을 때manneung-classroom-offline.html
③ 온라인 HTML개발자가 소스 수정하며 바로 확인할 때manneung-classroom.html

① EXE 실행 (가장 추천)

  1. manneung-classroom.exe 더블클릭
  2. 처음 실행 시 Windows SmartScreen 경고가 뜰 수 있어요 (서명되지 않은 빌드라서):
    • "Windows의 PC 보호" 창에서 추가 정보 → 실행 클릭
  3. 콘솔창 없이 로컬 서버가 뜨고 기본 브라우저가 자동으로 열립니다.
  4. 끝낼 때는 브라우저 탭만 닫지 말고 트레이/작업관리자에서 manneung-classroom.exe도 종료하세요. 또는 desktop/stop-server.cmd 실행.

EXE를 매번 누르기 귀찮으면 §6 매번 EXE 누르기 귀찮을 때 참고.

② 오프라인 HTML 실행

  1. manneung-classroom-offline.html 더블클릭 → 기본 브라우저에서 바로 열림
  2. 인터넷이 없어도 PDF·문서 보기·편집은 그대로 동작
  3. 단, Python을 처음 실행할 때는 인터넷이 필요합니다 (Pyodide 런타임 다운로드)

③ 온라인 HTML 실행

  1. 인터넷 연결 상태에서 manneung-classroom.html 더블클릭
  2. 라이브러리를 CDN에서 받아오므로 첫 실행은 반드시 인터넷 필요

4. 첫 사용 — 파일 열어 보기 ↑ 목차

처음 열면 파일 열기 → 파이썬 실행 → 저장 3단계를 알려 주는 환영 창이 한 번 뜹니다. ✨ 파이썬 예제로 시작을 누르면 곧장 예제 갤러리가 열려요. 나중에 다시 보려면 헤더 ? → 처음 사용 안내 보기.

파일 열기 (3가지 방법)

  1. 드래그 앤 드롭 — 탐색기에서 파일을 화면으로 끌어다 놓기 (가장 빠름)
  2. 사이드바 하단 [열기] 버튼 → 파일 추가 또는 폴더 열기
  3. Ctrl+O (파일 열기) / Ctrl+Shift+O (폴더 열기)

⚠ 꼭 알아두세요 — 폴더를 여는 방식과 브라우저 권한에 따라 저장 위치가 달라집니다.

  • 사이드바의 열기 → 폴더 열기 또는 Ctrl+Shift+O로 폴더를 열고 쓰기 권한을 허용하면 편집한 파일을 선택한 폴더의 원본에 바로 저장합니다.
  • Chrome·Edge에서는 탐색기에서 폴더를 화면으로 드래그해도 폴더 쓰기 핸들을 받아 원본에 저장합니다. Firefox·Safari처럼 드롭한 폴더의 쓰기 핸들을 제공하지 않는 환경에서는 EXE가 설정 → 일반 → 자동 저장 폴더에, 일반 HTML이 다운로드 사본으로 저장하며 드래그한 원본은 변경하지 않습니다.
  • 화면 위 파일명 옆의 원본 저장/사본 저장 배지에서 현재 저장 대상을 확인할 수 있습니다. 배지에 마우스를 올리면 원본·자동 저장 폴더·다운로드 중 실제 동선을 설명합니다.

여러 파일을 한 번에

  • 폴더째 드래그하거나 ZIP을 열면 안의 파일들이 사이드바에 정리됨
  • 사이드바에서 파일 클릭으로 전환
  • 빈 화면의 최근 연 항목을 누르면 보관된 파일·폴더 핸들로 다시 엽니다. 항목의 ×나 목록 지우기는 목록만 지우고 디스크 파일은 그대로 둡니다.
  • 사이드바 파일을 Ctrl+클릭해 개별 추가하거나 Shift+클릭해 범위 선택한 뒤 파일 닫기 또는 삭제를 실행할 수 있습니다. 삭제는 원본 폴더 핸들이 있는 파일만 디스크에서 영구 삭제하며 한 번 더 확인합니다.

5. 파일 종류별 사용법 ↑ 목차

📄 PDF — 편집·서명·필기

기본 기능

  • 상단 메뉴 편집 → 서명 / 텍스트 / 날짜 / ✓ 체크로 PDF 위에 요소 추가
  • 요소를 드래그해서 이동, 더블클릭해서 텍스트 수정, 모서리로 크기 조절, Delete로 삭제
  • 다운로드 버튼 → 원본이름_signed.pdf로 저장 (원본은 그대로)

페이지 정리

  • 상단 페이지 → 썸네일 보기, 페이지 추출·삭제·순서 변경·90도 회전
  • PDF 합치기 — 현재 PDF 뒤에 다른 PDF 이어붙이기

필기 모드 (✏️ 필기)

  • 펜·형광펜·지우개로 PDF 위에 직접 판서
  • 필기바의 ● 녹화로 필기 과정을 수업 리플레이로 저장 → 교재 위에서 판서가 되살아남(아래 🎬 참고)
  • 필기바 왼쪽 끝 ⋮⋮ 핸들을 끌어 위치 자유 배치, 좌/우 끝으로 가면 자동 세로 모드
  • 🖱 선택 도구를 누르면 그리기 일시 정지 (페이지 클릭/이동 평소처럼)
  • 필기는 자동 저장돼 같은 PDF를 다시 열면 복원, 다운로드한 PDF에 그대로 구워짐

📊 Excel / CSV

  • 셀·행·열·드래그 범위 선택 후 합계·평균·최소·최대·개수 자동 표시
  • Ctrl+C로 TSV 복사 → 다른 표에 붙여넣기
  • 표 위 검색창에서 셀 찾기
  • .xlsx는 셀 편집·필터·정렬·행/열 추가/삭제·시트 추가·복제·이름 변경·순서 변경·서식 보존 저장
  • 수식 입력(=SUM(A1:A3) 등), 함수 자동완성·Σ 자동합계, 채우기 핸들(숫자·요일·월·1반 패턴), 열 폭·행 높이 조절과 병합/병합 해제 지원
  • 글꼴·색·정렬·표시 형식·채우기·테두리·서식 복사, 목록 드롭다운, 조건부 서식(강조·색조·데이터 막대), 선택 범위 차트와 미니 피벗 지원
  • 선택 범위의 📷 선택→메모로 표 일부를 이미지로 만들어 일반 메모에 보관
  • .csv는 큰 파일도 페이지로 나눠 보기, XLSX로 변환 가능

🐍 Python (.py)

기본 흐름

  1. .py 파일을 열거나 사이드바 새로 만들기 → 새 파이썬 코드
  2. 코드 입력 후 ▶ 버튼 또는 Ctrl+Enter로 실행
  3. 결과가 옆/아래 패널에 표시 (Side/Below 버튼으로 위치 토글). 결과 오른쪽 위 접기 아이콘으로 내용은 유지한 채 숨기고, Side/Below를 누르면 다시 표시
예제 갤러리 — 빈 편집기에는 117개 예제 갤러리가 뜹니다. 난이도 필터 칩(⭐ 입문 / ⭐⭐ 기본 / ⭐⭐⭐ 심화 / ⭐⭐⭐⭐ 응용 / ⭐⭐⭐⭐⭐ 도전)으로 단계별로 추리고, 검색창에서 제목·설명·개념·파일명으로 찾을 수 있습니다. 응용·도전 단계에는 다익스트라·배낭 DP·N-퀸·만델브로·A* 길찾기 같은 심화 예제가 있어요. 예제를 클릭하면 새 코드로 열려 바로 실행됩니다.

도구바 버튼들

  • ▶ 실행 — 코드 실행. 실행 중에는 빨간 ■ 버튼으로 바뀌어 무한 반복이나 오래 걸리는 코드를 바로 멈출 수 있음
  • 단계 실행 — 줄별 변수 변화를 최대 300단계까지 기록 (디버깅용)
  • 진단 — 실행 없이 문법·자주 하는 실수 검사
  • 채점 — 여러 테스트의 입력/기대 출력으로 자동 채점
  • .py 저장 — 코드 저장. 폴더 열기와 Chrome·Edge에서 드래그해 원본 권한을 받은 폴더는 원본에 반영하고, 권한이 없는 환경은 자동 저장 폴더/다운로드 사본에 저장
  • 편집 파일 자동 저장 — 설정 → 문서에서 켜면 Python을 포함한 편집 가능한 텍스트 기반 코드·문서를 입력이 멈춘 지 3초 뒤 원본에 저장. 이름 없는 새 파일은 첫 수동 저장으로 이름을 정한 뒤부터 동작하며, ZIP 내부 파일과 쓰기 권한이 없는 브라우저 파일은 로컬 초안 복구만 사용. 실패하면 내용을 그대로 유지하고 지금 저장을 안내
  • ↩ 원본 — 편집 전 원본으로 되돌리기
  • PDF에 핀 — 현재 코드 줄을 PDF 위치에 연결
  • ✏️ 필기 — 편집 잠그고 코드·실행결과 위에 필기 (세션 한정, 문서 닫으면 사라짐)
  • 라이브러리 — 데이터분석·크롤링·DB 세트 원클릭 설치 (EXE+로컬 Python)
  • 결과 / 터미널 — 실행 결과와 명령창을 전환. EXE에서는 현재 작업폴더를 유지하는 로컬 PowerShell, 일반 브라우저에서는 변수가 유지되는 Pyodide Python 콘솔로 동작
  • 노트북으로 ▾ — 본문을 누르면 현재 코드를 바로 노트북으로 변환. ▾에서 셀 나누기(줄번호 클릭으로 # %% 경계 조정) 또는 자동분할 선택
  • A− / A+ — 코드와 실행 결과의 문자 크기를 함께 조절. 표준 출력·오류·표·변수·진단 글자에 적용되고 그래프·이미지 크기는 유지

노트북 변환

  1. 노트북으로 본문을 누르면 현재 # %% 경계를 기준으로 즉시 새 노트북 탭이 열립니다.
  2. 경계를 직접 정하려면 ▾ → 셀 나누기를 누르고 편집기 왼쪽 줄번호를 클릭해 경계를 넣거나 뺍니다.
  3. 상단 분할 완료를 누르면 변환합니다. 취소하려면 Esc 또는 ▾ → × 셀 나누기 취소를 누르면 진입 전 코드로 복원됩니다.
  4. ▾ → 자동분할은 빈 줄 뒤의 최상위 문장을 기준으로 # %%을 자동 추가하며, 이후 셀 나누기로 세부 조정할 수 있습니다.

입력값(input()) 처리

  • EXE + 로컬 Python: 결과 창에 입력 커서가 떠서 대화형으로 입력
  • 브라우저(Pyodide): input("이름: ")처럼 순서가 고정된 입력은 프롬프트 문구를 라벨로 단 개별 입력칸이 떠서 채우면 됩니다. 칸에서 Enter로 다음 칸, 마지막 칸에서 Enter면 바로 실행돼요. 반복문·조건문 안처럼 값 개수가 달라질 수 있으면 한 줄에 하나씩 적는 자유 입력칸으로 자동 전환됩니다.

터미널

  • EXE: .py 파일의 작업폴더에서 지속형 PowerShell 실행. 터미널을 열 때 한 번만 준비하므로 ls, dir, cd 같은 짧은 명령이 빠르고 작업폴더·PowerShell 변수·환경변수가 다음 명령에도 유지됨. 중지 또는 Ctrl+C로 실행 중인 명령과 자식 프로세스를 함께 종료하며 다음 명령에서 새 세션을 자동 시작

📦 과제 패키지 (.task) — 만들고 · 풀고 · 검수하기

문제 설명 + 시작 코드 + 자동채점 테스트를 .task 한 파일로 묶어 배포하는 기능입니다. 서버·인터넷 없이 USB나 메신저로 파일만 전달하면, 학생은 더블클릭으로 풀고 선생님은 제출본을 다시 채점해 확인합니다.

선생님 — 과제 만들기

  1. 파이썬(.py) 파일을 열고 코드를 작성한 뒤, 실행 바 ⋯ 더보기 → 채점에서 테스트(입력값·기대 출력)를 만듭니다
  2. 채점 창의 [📦 과제로 내보내기]를 누르면 과제 빌더가 열립니다
  3. 과제 제목 · 출제자 · 문제 설명(마크다운 지원, 미리보기 버튼으로 확인)을 적고, 시작 코드(학생에게 처음 보여줄 코드)를 다듬습니다
  4. 테스트마다 숨김 체크 가능 — 숨김 테스트는 학생에게 통과/실패만 보이고 입력·기대 출력은 가려집니다
  5. 학생 코드가 읽을 데이터 파일(csv·txt 등, 합계 8MB)도 첨부할 수 있습니다 — 시작 코드와 같은 폴더에 있는 것처럼 open('data.csv')로 읽힙니다
  6. [👀 학생 화면 미리보기]로 학생이 여는 그대로 확인(알림의 [이어서 만들기]로 빌더 복귀) → [📦 .task 내보내기]
  7. 명령 팔레트(Ctrl+K)의 "과제 파일 만들기 (.task)"로도 이 흐름에 바로 들어갈 수 있습니다

학생 — 과제 풀기

  1. 받은 .task 파일을 더블클릭·드래그로 엽니다 → 문제 설명은 왼쪽 참고 화면에 고정, 시작 코드는 편집기로 열립니다
  2. 편집기 위 과제 바(📦 제목 · 통과 n/m)에서 진행 상태를 보며 코드를 완성합니다. [문제 보기]로 닫았던 문제를 다시 띄울 수 있습니다
  3. [✓ 채점] — 과제에 담긴 테스트로 자동 채점되어 테스트별 통과/실패와 출력 비교가 표시됩니다(몇 번이든 다시 채점 가능)
  4. 다 풀면 [📤 제출본 내보내기] → 이름 입력 → 과제제목_이름.taskdone 파일이 만들어집니다(EXE는 저장 폴더에 기록 + [폴더 열기], 브라우저는 다운로드). 채점을 안 했거나 채점 후 코드를 고쳤으면 현재 코드로 자동 재채점 후 내보냅니다
  5. 만들어진 .taskdone 파일을 선생님께 제출(USB·메신저·학급 게시판 등)

선생님 — 제출본 검수

  • 한 명씩: 학생의 .taskdone을 더블클릭하면 검수 화면이 열립니다 — 학생·제출 시각·제출본이 신고한 점수·채점 환경·파일 검사(수정·손상 감지)와 제출 코드를 한눈에. 같은 과제의 원본 .task가 열려 있으면 [🔁 재채점]이 활성화되어 제출 코드를 선생님 파일의 테스트로 다시 채점하고 신고 점수와의 ✓ 일치 / ⚠ 불일치를 알려줍니다. [새 탭에서 편집기로 열기]로 학생 코드를 직접 실행·단계 실행해 볼 수도 있습니다
  • 반 전체 한 번에: 새로 만들기 → 제출본 일괄 검수(.taskdone) (명령 팔레트에서도 가능) → [+ 제출본 추가]로 여러 .taskdone을 한 번에 선택 → 원본 .task를 연 상태에서 [▶ 전체 재채점] → 표에 학생별 재채점 점수와 일치/불일치가 채워집니다 → [⬇ 성적 CSV]로 엑셀에서 바로 열리는 성적표 내보내기. 각 행의 [자세히]로 단독 검수 화면을 엽니다
제출본에 적힌 점수는 참고용입니다. 파일 검사(봉인)는 단순 수정·손상만 감지할 수 있어, 확실한 확인은 선생님 컴퓨터에서의 재채점으로 하세요 — 점수를 고친 제출본도 재채점에서 불일치로 드러납니다. 과제 파일을 배포 후 수정했다면 "과제 버전이 다름" 경고가 함께 표시됩니다.
숨김 테스트의 한계: .task는 텍스트(JSON) 파일이라 마음먹은 학생은 내용을 열어볼 수 있습니다. 변별이 중요한 평가라면 숨김 테스트에만 의존하지 마세요.
체험용 샘플이 docs/ 폴더에 있습니다 — 샘플-두수의합.task + 제출본 3종(정답/오답/점수 조작). 과제와 제출본들을 함께 열고 일괄 검수를 눌러 보세요.

🖥 대기 화면 (화면보호기)

일정 시간 아무 입력이 없을 때 전체 화면으로 내 영상이나 시계 애니메이션을 띄우는 기능입니다. 기본은 꺼져 있고, 설정에서 켤 때만 동작합니다.

  1. 헤더의 설정을 열고 대기 화면(화면보호기)을 체크
  2. 표시까지 대기 시간(1·3·5·10·20분) 선택
  3. 원하는 영상이 있으면 영상 선택으로 지정(없으면 시계 애니메이션). 영상 지우기로 되돌림
  4. 저장을 누르면 적용 — 그 시간만큼 입력이 없으면 대기 화면이 뜨고, 아무 키·클릭·마우스 이동에 즉시 사라집니다
권장 형식은 MP4(H.264)·WebM입니다. MOV·MKV·AVI·WMV 등은 브라우저에서 재생이 안 될 수 있어, 고르면 경고가 뜨고 그래도 쓰면 재생 실패 시 시계 애니메이션으로 대체됩니다.
영상은 이 브라우저(앱)에만 저장되어 프로그램(exe·HTML) 용량은 늘지 않습니다. 영상이 없거나 못 읽으면 자동으로 시계 애니메이션을 씁니다.
작업 중에는 뜨지 않습니다: 파이썬·노트북 실행 중, 동영상·오디오 재생 중, 파일 처리 중, 설정 등 대화상자·미리보기(iframe) 사용 중이면 대기 화면을 미룹니다.

📝 텍스트·이미지·노트북 셀 메모

  1. 상단 메모 또는 Ctrl+M으로 메모장 열기
  2. + 글 블록으로 글 영역을 추가하고 + 이미지로 이미지 파일 삽입
  3. 글 영역에 이미지를 Ctrl+V로 붙여넣거나 로컬 파일·웹 이미지를 메모장에 드롭
  4. 이미지 블록의 ↑ ← → ↓ 버튼으로 설명 글의 위·왼쪽·오른쪽·아래에 즉시 배치
  5. 작게/중간/크게/가득으로 표시 크기를 바꾸고 블록 ↑/↓ 또는 ⋮⋮ 드래그로 문서 순서 변경
  6. 이미지 옆 입력란에 설명 작성. 글·이미지·배치 정보는 이 컴퓨터에 자동 저장
  7. 기존 텍스트 메모는 새 형식으로 자동 이전되며, 텍스트 복사는 이미지 이름을 포함한 읽기 쉬운 텍스트로 복사
  8. 블록 도구막대의 자물쇠 아이콘을 누르면 읽기 전용으로 바뀌어 내용·배치·이동·삭제를 막음. 잠긴 자물쇠 아이콘을 다시 누르면 편집 가능
  9. 이미지 블록의 📋 복사(클립보드 → 다른 프로그램에 붙여넣기), 💾 파일로(EXE는 저장 폴더, 브라우저는 다운로드), ✏️ 편집기로(이미지 편집 탭으로 열어 자르기·표시 후 ‘📷 메모로’로 다시 넣기)로 메모 속 이미지를 재사용. 잠긴 블록에서도 사용 가능
  10. 노트북에서 선택한 셀의 메모 아이콘을 누르거나 ⋮⋮ 손잡이를 메모장에 드롭하면 코드/마크다운/Raw 셀 카드로 별도 저장
  11. 셀 카드의 노트북에 붙여넣기를 누르면 현재 노트북의 선택 셀 아래에 삽입. 카드 손잡이를 노트북 셀 사이에 직접 드롭하면 정확한 위치에 삽입
  12. 셀 카드는 최대 200개까지 보관하며 코드·마크다운 첨부·일반 메타데이터를 유지하고 실행 결과·실행 번호·필기는 저장하지 않음

맞춤법 검사: 글 블록과 이미지 설명의 맞춤법 버튼을 누르면 외부 서버 전송 없이 현재 내용을 검사합니다. 제안 표현을 눌러 교정하고, 이번만 무시하거나 고유명사를 사용자 사전에 추가할 수 있습니다. TXT·Markdown 편집기와 노트북 마크다운 셀에서도 같은 기능을 사용할 수 있으며, 코드 파일은 주석과 문자열만 검사합니다.

잠긴 블록이 하나라도 있으면 해당 메모 탭 삭제와 모두 지우기도 차단됩니다. 먼저 각 블록의 잠금을 해제하세요.

웹 이미지가 사이트 보안 정책(CORS·로그인·blob: 주소) 때문에 드롭되지 않으면 웹에서 이미지 복사 후 메모장에서 Ctrl+V를 사용하세요.

📸 이미지 메모

  1. 상단 이미지 메모를 눌러 창 열기
  2. 화면을 캡처한 뒤 Ctrl+V로 붙여넣기 — 같은 창에 여러 장을 계속 추가할 수 있음
  3. 이미지 메모 창 어디에나 이미지 파일이나 웹 이미지를 드롭 가능. 필요 없는 이미지는 카드 오른쪽 위 ×로 삭제
  4. 기본으로 켜진 자동 저장이 붙여넣기·드롭 후 1.4초 뒤 동작
    • EXE: 자동 저장 폴더 아래 이미지메모/날짜_시간/에 개별 이미지로 실제 저장
    • 일반 브라우저: IndexedDB에 임시복구본을 저장하고 다음 실행 때 복원
    • 실패한 이미지는 미저장 상태로 남겨 자동 재시도
  5. EXE에서는 자동저장 실패 또는 자동저장을 끈 경우에만 다시 시도/지금 저장 버튼 표시. 일반 브라우저의 파일로 다운로드는 한 장은 이미지, 여러 장은 ZIP으로 저장
  6. EXE를 다시 실행하면 현재 자동 저장 폴더의 최근 이미지 메모를 자동으로 불러옴
    • 저장된 카드의 ×는 저장된 이미지 파일도 함께 삭제
  7. 이미지 카드를 클릭하면 큰 미리보기로 확인
    • 마우스 휠 또는 −/+로 확대·축소
    • 확대된 이미지를 드래그해 이동
    • 화면 맞춤, 100%, 더블클릭 전환과 Esc 닫기 지원
  8. 카드의 현재 메모로 보내기를 누르면 일반 메모의 현재 탭에 같은 이미지를 넣고 설명·배치를 추가할 수 있음

📚 참고 문서 + 작업 문서 같이 보기 (분할 작업)

  1. 참고할 PDF·코드·표·문서·이미지 등을 열고 상단 분할 작업 클릭
  2. 사이드바에서 .py·노트북·표 등 작업할 파일 선택 → 참고 문서와 작업 화면이 함께 표시
  3. 넓은 화면에서는 분할 경계의 ↕/↔ 버튼으로 좌우·상하 방향을 전환하고 분할바로 방향별 비율 조정. 가운데 교체 버튼 또는 분할바 더블클릭으로 좌우·위아래 위치 전환. 좁은 화면에서는 위/아래로 분할
  4. 각 칸 왼쪽 위의 역할 칩에서 참고·작업과 파일명을 확인
  5. 참고 문서를 보기 전용으로 쓰려면 참고 칩의 잠금 사용. 잠금 중에도 보기·스크롤·텍스트 및 표 선택·복사 가능
  6. 참고와 작업 역할을 서로 바꾸려면 두 칸 사이의 ⇄ 버튼 사용
  7. 사이드바·상단 탭에서 고른 파일은 마지막으로 클릭한 칸에 열림. 파일을 본문으로 끌면 좌우 모드에서는 왼쪽/오른쪽, 상하 모드에서는 위쪽/아래쪽 칸에 바로 배치. 반대 칸에 떠 있는 파일을 고르면 두 문서의 역할이 교체됨

  • 회전·좌우/상하 뒤집기·자르기·PNG/JPG/PDF 저장, 되돌리기/다시 실행(50단계)
  • ✏️ 표시 — 펜·형광펜·화살표·사각형·텍스트로 이미지 위에 표시, ▦ 모자이크로 개인정보(이름·얼굴) 가리기. 표시는 저장할 때 이미지에 그대로 구워짐
  • 🖱 선택 — 그린 표시를 클릭해 드래그로 이동, Delete 삭제, 텍스트 더블클릭으로 수정. 텍스트는 넣자마자 자동 선택되어 바로 위치 조정 가능
  • 자르기 — 영역을 드래그한 뒤 모서리 핸들로 조절·안쪽 드래그로 이동, 자유·1:1·4:3·16:9 비율 프리셋
  • 보정 — 자동보정·밝기·대비·채도·선명도·노이즈완화 + 크기 줄이기(½·⅓·폭 입력) + JPG 품질 슬라이더 + 2x/4x 고화질 확대
  • 📷 메모로 — 현재 편집본을 일반 메모에 이미지 블록으로 넣기. 자르기 영역을 선택해 두면 그 부분만 발췌(원본은 그대로), 표시·모자이크·보정 포함
  • EXE에서는 저장 시 권한 팝업 없이 저장 폴더(내 문서\만능교실 저장)에 기록되고 완료 알림에서 바로 폴더 열기 가능 (일반 브라우저는 다운로드)

🎞 영상·오디오·자막

  • 영상(.mp4·.webm·.mov·.mkv·.avi 등)과 오디오(.mp3·.wav·.m4a·.flac 등)를 일반 문서처럼 탭에서 재생합니다. 브라우저 기본 재생 컨트롤로 탐색·배속·전체화면을 사용하세요.
  • 영상 도구바의 📷 장면 캡처는 현재 프레임을 일반 메모에 넣고, 메모를 쓸 수 없으면 PNG 파일로 저장합니다.
  • .srt·.vtt·.smi 자막은 같은 이름의 영상과 자동 연결됩니다. 영상 탭의 자막 열기로 직접 고를 수도 있고, 표시/숨기기와 글자 크기 조절을 지원합니다.
  • MP4(H.264)·WebM을 권장합니다. MKV·AVI·WMV·FLV·MOV처럼 재생이 안 되는 영상은 EXE에서 MP4로 변환할 수 있으며, 폴더 메뉴의 영상 일괄 MP4 변환도 지원합니다. 변환은 500MB 이하만 가능하고 처음에는 ffmpeg 설치를 위해 인터넷이 필요할 수 있습니다.

▦ 폴더 이미지·PDF 모아보기

  • 열기 → 폴더 열기로 연 폴더에서 폴더 이름을 우클릭하면 이미지 모아보기와 PDF 모아보기가 나타납니다.
  • 같은 메뉴 위쪽에서 새 Python 코드·새 노트북·새 빈 표·새 텍스트 파일·새 블록 문서를 우클릭한 폴더 안에 바로 만들 수 있습니다. 첫 저장(Ctrl+S) 때 파일 이름을 물어보고, 원본 저장으로 연 폴더라면 정한 이름으로 그 폴더에 파일이 만들어집니다. 같은 이름이 있으면 번호가 붙습니다. (화이트보드는 파일로 저장하는 형식이 없어 사이드바의 새로 만들기에서만 만듭니다.)
  • 쓰기 권한을 허용해 연 폴더에서는 새 폴더를 선택해 우클릭한 위치의 실제 디스크에 빈 폴더를 만들 수 있습니다. ZIP·읽기 전용 폴더에는 이 메뉴가 나타나지 않습니다.
  • 현재 폴더만 또는 하위 폴더까지 포함해 썸네일 격자로 보고, 항목을 누르면 원래 이미지 편집기 또는 PDF 탭으로 바로 이동합니다.

🐾 픽셀 펫·집중 모드

  • 설정에서 픽셀 펫을 켜면 1~12마리의 작은 캐릭터가 화면과 창 위를 돌아다닙니다. 클릭해 말을 듣거나 붙잡아 던질 수 있습니다.
  • 설정의 대사 편집과 나만의 펫 만들기에서 펫별 대사와 그림·움직임·색 조합을 저장할 수 있습니다.
  • 헤더의 집중에서 1~180분 집중과 1~60분 휴식 시간을 정해 타이머를 시작합니다. 완료 횟수와 진행 중인 세션은 앱을 닫았다 다시 열어도 이어집니다.
  • 라이트 모드에서는 설정의 라이트 모드 배경에서 쿨 그레이·웜·민트·라벤더·스카이 프리셋을 고를 수 있습니다.

6. 상황별 가이드 ↑ 목차

🌐 인터넷이 안 되는 환경에서 쓰고 싶어요

  • EXE 사용 가능 — 문서 보기·편집은 완전 오프라인
  • 오프라인 HTML 사용 가능 — 같은 이유
  • 단, Python을 브라우저(Pyodide)로 실행할 때는 첫 실행에 인터넷 필요 (런타임 다운로드)
  • 완전 오프라인 Python을 원하면: EXE + 로컬에 Python 설치 → 로컬 Python으로 실행되므로 인터넷 불필요
  • 오프라인에서도 Pyodide를 쓰려면: EXE 옆 vendor/pyodide/ 폴더에 코어 파일이 미리 있어야 함

🐍 파이썬은 설치하지 않고도 코드를 실행하고 싶어요

  • 브라우저 Pyodide가 자동으로 동작합니다 — 별도 파이썬 설치 불필요
  • numpy·pandas·matplotlib 같은 공식 패키지와 PyPI의 순수 Python 패키지는 첫 실행 시 자동으로 받아옴
  • Faker는 EXE에 내장되어 인터넷 없이도 사용 가능
  • 첫 실행만 인터넷 필요, 이후 캐시
  • 제한: selenium·konlpy 등 Pyodide 미지원 패키지, OS 명령(subprocess)은 사용 불가

💻 학생들에게 배포하려면?

  • 브라우저(Pyodide)에서는 코드 실행 전에 입력값들을 미리 한 줄씩 적어두는 방식

🔄 매번 EXE 누르기 귀찮을 때

EXE를 한 번 띄워두고 브라우저 즐겨찾기로 바로 접속할 수 있어요.

  1. desktop/start-server-hidden.vbs 실행 — 콘솔창 없이 서버만 뜸 (브라우저는 자동으로 열리지 않음)
  2. 브라우저에서 http://127.0.0.1:17645/ 접속 후 즐겨찾기(Ctrl+D)
  3. 그 .vbs를 시작프로그램 폴더(Win+R → shell:startup → 거기에 복사)에 넣어두면 PC 켤 때 자동으로 서버가 뜨고, 즐겨찾기만 누르면 바로 사용 가능
  4. 끄려면 desktop/stop-server.cmd 실행
⚠️ 백그라운드 서버가 뜬 상태에서는 EXE를 직접 더블클릭하지 마세요 (중복 인스턴스가 됨).

  • 다른 PC에서는 파일·폴더 쓰기 권한을 다시 받아야 함. Python 실행 변수·되돌리기 기록·OCR 캐시는 백업 제외

8. 개발자용 — 소스 수정 후 다시 빌드 ↑ 목차

이 프로젝트의 EXE 빌드는 다음 두 단계로 진행됩니다.

  1. manneung-classroom.html, src/, vendor/를 합쳐 manneung-classroom-offline.html 생성
  2. 오프라인 HTML을 C# 런처에 내장해 manneung-classroom.exe 생성

준비물

  • Node.js — node --version으로 확인. 없으면 nodejs.org에서 설치
  • .NET Framework C# 컴파일러 — 일반적인 Windows 환경에서는 아래 위치 중 하나에 있습니다
    • C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe
    • C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe
  • 일반적인 소스 검사·단위 테스트·오프라인 빌드는 추가 npm 패키지 없이 실행됩니다. 단 npm run test:e2e의 Playwright E2E 테스트는 @playwright/test 개발 의존성이 있으므로 새 환경에서는 먼저 npm install이 필요합니다.

권장 빌드 절차

프로젝트 루트에서 PowerShell을 열고 다음 명령을 순서대로 실행합니다.

cd D:\my\myOffice

# 실행 중인 기존 EXE가 있다면 종료
Get-Process manneung-classroom -ErrorAction SilentlyContinue |
    Stop-Process -Force

# 구문 검사 + 자동 테스트 + 오프라인 HTML 생성
npm.cmd run verify

# 오프라인 HTML을 내장한 EXE 생성
cmd /c desktop\build.bat

PowerShell에서는 실행 정책에 따라 npm이 npm.ps1 오류로 막힐 수 있습니다. 이때 실행 정책을 바꾸지 말고 위 예시처럼 npm.cmd를 사용하면 됩니다.

테스트를 생략하고 빠르게 빌드

코드 검증이 이미 끝난 상태에서 산출물만 다시 만들려면:

cd D:\my\myOffice
node build-offline.js
cmd /c desktop\build.bat

개별 검증 명령은 다음과 같습니다.

npm.cmd run check    # 구문 검사만
npm.cmd test         # 자동 테스트만
npm.cmd run build    # 오프라인 HTML만 생성

자주 발생하는 빌드 오류

  • npm.ps1을 로드할 수 없음: npm 대신 npm.cmd 사용
  • manneung-classroom.exe 액세스 거부: 실행 중인 EXE를 위의 Stop-Process 명령으로 종료한 뒤 재시도
  • manneung-classroom-offline.html이 없음: node build-offline.js 또는 npm.cmd run build를 먼저 실행
  • C# compiler not found: .NET Framework 개발 구성 요소를 설치하거나 Go 1.21 이상을 설치

desktop/build.bat은 C# 컴파일러가 있으면 desktop/launcher.cs를 사용합니다. 컴파일러가 없으면 Go 빌드를 시도하지만, Go 폴백 버전은 PowerPoint 변환 등 일부 로컬 연동 기능이 제한되므로 C# 빌드를 권장합니다.

배포할 때

  • 기본 앱 기능은 manneung-classroom.exe 하나로 실행할 수 있습니다.
  • 인터넷 없이 브라우저 Python(Pyodide)까지 사용하려면 EXE와 함께 vendor/pyodide/ 폴더를 같은 상대 위치로 배포합니다.
  • 로컬 Python의 번들 패키지 설치까지 오프라인으로 지원하려면 vendor/wheels/도 함께 배포합니다.
  • 자체 코드 서명을 하지 않은 EXE에는 Windows SmartScreen 경고가 표시될 수 있습니다.

10. 문제 해결 FAQ ↑ 목차

Q1. EXE를 더블클릭했는데 SmartScreen 경고가 떠요

서명되지 않은 빌드라 정상입니다.

→ "Windows의 PC 보호" 창에서 추가 정보 → 실행 클릭

Q2. 브라우저가 자동으로 안 열려요

EXE가 실행됐는데 브라우저가 안 뜨면:

  1. 작업관리자에서 manneung-classroom.exe 프로세스가 살아 있는지 확인
  2. 살아 있으면 브라우저에서 http://127.0.0.1:17645/ 직접 접속
  3. 17645가 다른 프로그램에 점유돼 있으면 다음 고정 후보 포트(18645 · 19645 · 27645 · 37645 · 47645) 중 하나로 떠 있을 수 있음 → 그 주소로 접속하거나, 콘솔창이 안 보이므로 종료 후 재실행. 한 번 뜬 포트는 기억되어 다음 실행 때 재사용됩니다

Q3. 즐겨찾기로 접속이 안 돼요

  • start-server-hidden.vbs가 실행 중인지 작업관리자에서 확인
  • 안 떠 있으면 다시 실행
  • EXE를 따로 더블클릭한 적이 있으면 중복 인스턴스가 떠서 포트가 어긋날 수 있음 → 모두 종료 후 .vbs만 다시 실행

Q4. Python 실행이 안 돼요 / 너무 느려요

  • 브라우저 첫 실행은 Pyodide 다운로드 때문에 30초~1분 정도 걸립니다. 이후 캐시되어 빨라짐
  • 인터넷이 없으면 첫 실행이 실패할 수 있음 → EXE + 로컬 Python 설치 권장
  • 로컬 Python을 인식하지 못하면 편집기 도구바의 Py Env 클릭해 진단 확인
  • 파이썬을 방금 설치했다면 Py Env → 다시 검사를 누르면 EXE를 껐다 켜지 않아도 인식됩니다
  • PATH에 없어도 레지스트리와 기본 설치 폴더(%LocalAppData%\Programs\Python, Program Files, C:\Python3xx, Anaconda 등)에서 자동으로 찾습니다. 그래도 못 찾으면 기본 위치가 아닌 곳에 설치한 경우이므로 Add python.exe to PATH를 체크해 다시 설치하세요

Q5. PowerPoint 파일이 깨져 보여요

  • EXE + 설치된 Microsoft PowerPoint가 있어야 정확 변환
  • HTML 버전이나 PowerPoint 미설치 시 PPTXjs 근사 미리보기로 폴백 (애니메이션·복잡한 도형이 어긋날 수 있음)

Q6. 저장한 파일이 안 보여요

  • EXE에서 Python·Excel 저장 위치: 내 문서\만능교실 저장\ 폴더
  • PDF·이미지 내보내기는 브라우저 기본 다운로드 폴더로 떨어짐
  • 편집기 상단에 마지막 저장 경로가 표시됨

Q7. 작업 표시줄의 EXE 아이콘이 동작 안 해요

  • EXE 파일을 다른 위치로 옮기거나 삭제했는지 확인
  • 옮겼다면 작업 표시줄 아이콘을 우클릭 → 작업 표시줄에서 제거 후 새 위치에서 다시 고정

Q8. PDF 위에 한 필기가 사라졌어요

  • PDF 필기는 자동 저장되지만, 다른 작업공간으로 옮기거나 EXE 자동 복원 데이터를 지우면 함께 사라질 수 있음
  • 다운로드한 PDF에는 필기가 그대로 구워지므로, 영구 보존하려면 다운로드 버튼으로 저장

Q9. Python 편집기에서 필기를 켰는데 다시 끄고 싶어요

  • 도구바의 ✏️ 필기 버튼을 한 번 더 누르면 편집 잠금 해제 + 캔버스 OFF
  • 필기는 세션 한정이라 문서를 닫으면 자동으로 사라집니다 (저장되지 않음)
